# Prompt CAD Studio 3.0.1

선택 부품의 속성 또는 **조립 → 기계 기능 · 체결 / 관절 / 액추에이터**에서 볼트·너트·고정 핀, 수동 관절 지지 구조, 실제 모터·액추에이터, 동력 전달 부품을 구분합니다. 여러 부품은 기본적으로 각자의 기능을 유지합니다. 기존 파일은 미지정으로 열리며 이름·색상·원통 모양만으로 구동기로 판단하지 않습니다.

기계 기능 지정은 부품 역할/색상, 조립 구속, 전장 등록과 별도로 저장됩니다. 취소·실행 취소·다시 실행·프로젝트 저장을 지원합니다. 관절 구조 생성기의 하우징·부시는 수동 지지부, 축·출력부는 전달 부품으로 기록됩니다. 구동기 지정이나 관절 상태 색상은 실제 제품, 전기/토크 정격 또는 실제 구동을 인증하지 않습니다.

전장 노드 한도를 512개로 확대하고 STM32 NUCLEO-G474RE의 선택 가능한 GPIO 16개를 추가했습니다. 기존 6개 신호 핀과 전원/참조 핀은 유지하며 커넥터·핀 번호, 솔더 브리지·BOOT0·PA9/PB6 조건을 표시합니다. 실제 보드 리비전과 장착된 브리지 상태는 따로 확인해야 합니다. 연결선이 핀 위에 겹쳐도 핀 중심을 클릭할 수 있습니다.

큰 조립품 미리보기의 한 번의 작업 안에서 만든 형상을 재사용하여 부품 수가 형상 캐시 한도를 넘을 때 발생하던 중복 생성 경로를 줄였습니다. 기존 치수·상대 몸체 연산·배치·간섭 검증은 유지합니다. 실제 열기·저장·재열기 결과는 배포 검증 기록에 기재합니다.

조립 위치와 작업 이력을 검증하는 회전 계산을 스칼라 계산으로 교체했습니다. 기존 계산과 581개 회전 행렬·1,426개 역변환을 비교하고 특이 각도 부근의 기존 작업 이력도 확인했습니다. 회전 순서와 이력 허용 오차는 유지합니다. 이 변경만으로 메모리 오류가 해결됐다고 판단하지 않습니다.

AI 설계 요청은 기존 설계의 독립적인 복사본을 검증합니다. 폐루프 관절을 다시 계산하면서 원본의 각도 값이 미세하게 변하던 요청 준비 경로를 수정했습니다. 검증에 실패한 요청도 원본을 보존하며, 관절·형상·작업 이력 검사를 생략하거나 허용 오차를 확대하지 않습니다.

큰 파일을 반복 검사할 때 주기적 네이티브 스택 수집을 켠 검사는 메모리 오류로 종료됐지만, 같은 코드와 파일에서 이를 끈 검사는 전체 이력을 12회 검증했습니다. 검사 도구의 주기적 스택 수집을 Python 방식으로 교체하며 파일·형상·구속 검증과 오류 발생 시 로그는 유지합니다. 이는 해당 검사 조건의 관찰이며 모든 네이티브 오류가 제거됐다는 의미는 아닙니다.

생성된 펌웨어와 외부 라이브러리는 검토할 소스입니다. 소스/배선 연결 확인과 대상 SDK 빌드, 실제 보드·모터 동작 검증을 구분하며 자동 실행·플래시·장비 구동을 하지 않습니다.
