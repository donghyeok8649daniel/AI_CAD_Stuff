# 힘 계측과 환경 센서 참고 검토

`도면 / 해석 → 하중 측정 / 교정 연결…`에서 회로에 등록한 여자 전원, 로드셀, ADC, 수집 MCU/MPU를 선택합니다. 사양 버튼에서 실제 제품 자료와 선택한 gain·출력률·전압·교정값을 입력합니다. 빈 칸은 미확인으로 유지합니다. 부품의 CAD 형상은 교체하지 않습니다.

작은 창에서는 설정 폼만 스크롤하고 하단 검토·저장 버튼은 계속 표시합니다. 정확한 카탈로그 SKU의 제조사 감도 범위를 수정해도 입력 여유 검토에는 원래 제조사 상한이 포함되며 출처 불일치가 표시됩니다. 일련번호 실측 감도와 N/count 교정은 별도로 보존하고 수동 제품의 참고 범위는 편집할 수 있습니다.

실제 연결은 회로도에서 단자와 핀에 전선을 연결합니다. 계측 창의 `역할=실제단자`는 이미 있는 단자가 무슨 역할을 하는지 설명하며 배선을 생성하지 않습니다. `port:AIN0P` 같은 ADC 단자와 `pin:PA6` 같은 MCU 신호 핀을 구분합니다. 실제 보드 GND는 `supply:GND_CN5_7` 등의 물리 단자로 지정하며 별도의 DC 부하 A/B 모델과 자동으로 같다고 가정하지 않습니다.

검토는 로드셀 용량·반복 하중 참고값, 여자 전압, 차동 입력 여유, ADC 각 입력의 공통모드, 선택 gain·클록·OSR·출력률, 실제 핀 도통 및 환경 센서 전원 범위를 확인합니다. `오류`는 모순이나 허용 범위 위반이며 `미확인`은 사양·구성·시험 자료가 더 필요하다는 뜻입니다. 불완전한 설정도 프로젝트에 저장할 수 있지만 실물 동작 성공으로 표시하지 않습니다. 결과의 `hardware_verified`와 `firmware_executed`는 항상 false입니다.

## 등록 제품과 출처

- [HBK U10M 자료 B01444, 2025-08-22](https://www.hbm.com/fileadmin/mediapool/hbmdoc/technical/B01444.pdf): passive 25 kN, 표준 동적 교정 변형의 참고 프로필입니다. 공칭 감도와 비조정 감도 범위를 분리하고 일련번호 교정값은 미입력으로 둡니다. 기능 단자는 표시하되 선택한 케이블의 선 색과 커넥터 번호는 추정하지 않습니다. 어댑터 포함 주문 코드와 어댑터 없는 본체 구성을 구분합니다. 센서 고유진동수는 시스템 대역폭에 넣지 않습니다.
- [TI ADS131M04 SBAS890D](https://www.ti.com/lit/ds/symlink/ads131m04.pdf): PW TSSOP-20 핀 기능입니다. gain 8 이상에서 각 입력의 상한은 AVDD−1.8 V입니다. AVDD 3.3 V와 균형 3.3 V/5 V 브리지 직결은 오류입니다. 2.5 V 여자도 배선·회로·교정이 검증된 완성 설계는 아닙니다. CLKIN은 SPI SCLK와 별개 발진 부품으로 지정합니다. 여자 감시 분압도 별도 채널 gain과 차동 입력 범위로 확인합니다.
- [TI ADS1232 SBAS350H](https://www.ti.com/lit/ds/symlink/ads1232.pdf): PW TSSOP-24 참고입니다. 출력률은 10/80 SPS이며 Rev H 필터 대역폭은 2.4/19 Hz입니다. 사용 대역폭이나 폐루프 제어 대역과 같다고 표시하지 않습니다.
- [AVIA HX711 원문, SparkFun 제공](https://cdn.sparkfun.com/datasheets/Sensors/ForceFlex/hx711_english.pdf): SOP-16 IC입니다. 채널 A 설정과 내부 클록 10/80 SPS를 구분하며 임의 브레이크아웃 핀 순서를 대입하지 않습니다. 저속 데이터 출력만으로 고주파 힘 제어를 승인하지 않습니다.
- [Sensirion SHT3x-DIS V7](https://sensirion.com/media/documents/213E6A3B/63A5A569/Datasheet_SHT3x_DIS.pdf), [SHT4x V7.3](https://sensirion.com/media/documents/33FD6951/6A7C10A0/HT_DS_Datasheet_SHT4x_V7.3.pdf): SHT31-DIS-B와 SHT45-AD1B 칩 핀 기능과 전원 참고입니다. 히터/측정 모드별 소비전류는 미입력입니다. SHT45에 5 V 직결은 오류입니다. I²C 주소·풀업·실제 보드를 확인해야 합니다.
- [ST UM2505 Rev 7](https://www.st.com/resource/en/user_manual/um2505-stm32g4-nucleo64-boards-mb1367-stmicroelectronics.pdf): NUCLEO-G474RE의 선택 CN5/CN6/CN9 헤더만 제공합니다. PA5는 LD2와 SB6 연결 조건을 검토해야 합니다. 별도 DAQ 보드 핀을 B-G431B-ESC1의 전류 피드백 핀에 적용하지 않습니다.
- [maxon 667065 공식 페이지](https://www.maxongroup.com/maxon/view/product/667065): 3상 Hall 모터 후보의 기능 단자를 제공합니다. 현재 페이지와 2025 카탈로그의 수치를 혼합하지 않으며 NRND를 표시합니다. Hall 전압·실제 커넥터와 냉각/전류 정의는 추가 확인 대상입니다. 제품 정격에서 시험기 15 kN, FOC 또는 소비전류 모델을 추정하지 않습니다.

## 교정·주파수와 남은 검증

실측 `ADC count, 하중 N` 점을 두 개 이상 입력하면 선형 최소제곱 N/count 계수와 잔차를 계산합니다. 이는 사용자 실측의 변환계수이며 인증서 검증이 아닙니다. 교정 전에는 count를 N으로 변환하지 않습니다. 출력 SPS, 주기당 샘플 수, ADC 필터 대역, 로드셀 장착 대역, 실제 수집 지연을 분리합니다. 기본 주기당 20개 샘플은 편집 가능한 참고 검토 기준이며 규격값이 아닙니다.

실물 계측, GPIO 방향, 프로토콜, SPI CRC/DRDY, 펌웨어, 힘 폐루프, 동기 기록, 입력 보호, 안티앨리어싱, 레귤레이터 노이즈와 실제 배선 손실은 실행하지 않습니다. 온습도는 환경 기록 항목이며 검증된 재료·센서 모델 없이 힘·피로 보정값을 생성하지 않습니다. AC 전원, 회생 에너지와 STO도 이 계측 참고 검토 범위가 아닙니다.

ADS131M04의 CLKIN 권장 범위는 0.3 MHz 이상이며 HR/LP/VLP 상한은 8.4/4.15/2.08 MHz입니다. 8.192/4.096/2.048 MHz는 공칭 조건으로 상한과 구분합니다. OSR 64는 Turbo Mode 설정이 필요하며 실제 출력률은 CLKIN/(2·OSR)로 확인합니다. 64 kSPS 표시만으로 실제 선택 모드나 시스템 대역폭을 정하지 않습니다. ADC DVDD가 보드 GPIO 전압보다 높은 직결은 오류로 표시하며 레벨 변환기 실물 검증을 대신하지 않습니다.
