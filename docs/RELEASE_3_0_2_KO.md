# Prompt CAD Studio v3.0.2

관절 한계 / 모션 연결 창에서 기존 연결을 선택하고 **선택한 연결 수정**으로 편집할 수 있습니다. 비율·오프셋·운동 한계 입력은 저장된 숫자의 정밀도를 유지합니다. 예를 들어 5 mm/rev 나사축의 `5/360` 비율이 소수점 다섯 자리로 잘리지 않습니다. 입력은 숫자로 하며 지수 표기도 지원합니다.

기존 연결을 변경 없이 확인하거나 취소하면 설계값과 작업 기록을 보존합니다. 명시적으로 수정한 연결은 프로젝트 저장과 작업 기록 복원에 반영됩니다.

이번 변경은 입력·편집 동작의 수정입니다. 실제 베어링·커플링·모터의 하중 정격, 강도, 펌웨어 빌드 또는 실물 구동을 검증한 업데이트는 아닙니다. 피로시험기 물리 설계 후보는 별도의 검토 자료로 전달합니다.
