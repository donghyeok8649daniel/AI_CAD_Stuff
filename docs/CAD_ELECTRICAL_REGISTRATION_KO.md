# CAD 부품의 전장 모델과 모식도 등록

설계한 3D 부품에 실제 보드·모터·센서 모델을 등록하면 CAD 부품 ID, 전장 회로 항목, 제품 자료와 핀·단자 모식도가 연결됩니다. 등록 정보는 해당 부품의 작업 피처로 프로젝트에 함께 저장됩니다. 단순히 노란색을 지정하거나 전장 역할로 분류하는 것과는 별개의 작업입니다.

먼저 3D 부품을 하나 선택하고 전장 모델 등록 창을 엽니다. 정확한 모델 또는 사용자 정의 부품 종류를 선택하고 회로에서 사용할 이름을 정합니다. 기본 설정은 **정격 입력 전 · DC 계산 제외** 상태입니다. 실제 전원 입력 전압과 해당 운전 조건의 소비전류를 알 때만 DC 계산을 켜고 값을 입력합니다. 저장한 후 해당 부품 아래 등록 피처를 열어 모델과 모식도를 다시 확인하거나 편집할 수 있습니다.

**도면 / 해석 → CAD 부품 · 전장 등록 / 모식도…**로 열거나 선택 부품의 속성에서 전장 등록을 선택합니다. **전장 등록 · 미리보기**로 사본을 확인한 뒤 **설계에 저장**하면 반영됩니다. **정격 / 전원 · 신호 단자 편집…**은 수치와 배선을 편집하고, **MCU 핀 연결…**은 물리 핀 연결 편집기를 엽니다. 부품 아래 **전장 피처**를 더블클릭해 다시 열 수 있습니다.

등록은 형상을 바꾸는 CAD 가공 피처가 아닙니다. 등록·모식도 편집은 기존 형상, 조립 위치와 그룹을 보존합니다. 사용자가 지정한 부품 색은 기본적으로 유지하며, 원하는 경우 전장 기본색을 적용합니다. 취소는 열린 창의 변경을 반영하지 않습니다. 저장한 등록 변경은 일반 작업 기록의 실행 취소·다시 실행과 `.cad.json` 프로젝트 저장·다시 열기에 포함됩니다.

## 전원과 신호를 연결하는 순서

1. 모델을 등록한 후 전장 회로에서 배터리·공급 전원, 스위치, 공급 전선과 귀환 경로를 실제 배선대로 입력합니다. 모델 등록만으로 전원이 자동 인가되지는 않습니다.
2. MCU는 정확한 보드의 물리 헤더 핀을 모식도에서 고릅니다. 모터·센서·드라이버는 지원되는 제품 단자 모식도 또는 직접 입력한 신호 단자를 사용합니다. 같은 모델명이더라도 칩과 판매 모듈의 단자 배치는 다를 수 있습니다.
3. 연결할 회로 부품의 단자 또는 다른 MCU의 신호 핀을 고릅니다. 전원 단자와 신호 단자는 별도로 표시합니다. 공급·귀환 노드는 실제 사용한 전원 경로에 맞게 입력하세요. 등록한 제조사 단자도 자동으로 같은 전압 레일에 연결하지 않습니다.
4. 모식도와 회로에서 저장한 후 설계에 반영합니다. 핀 연결 및 취소·저장 단계는 [MCU 핀 연결 안내](MCU_PIN_CONNECTIONS_KO.md)를 참고하세요.

## 수치 확인 전 상태

정확한 소비전류나 공급 조건이 없는 모델도 참고자료와 단자 정보로 등록할 수 있습니다. 이 상태를 **계산 완료**, **정상 구동** 또는 **0 A 부하**로 해석하지 않습니다. 소비전류를 제조사 권장 어댑터 전류로 대체하거나 모터의 정격·기동·스톨 전류를 서로 같은 값으로 취급하지 않습니다. DC 분석을 사용할 때는 해당 시나리오의 실제 입력값을 지정해야 합니다.

제조사의 자료를 등록했다고 모든 소자에 동일한 저항 모델이 적용되는 것은 아닙니다. H 브리지 드라이버·다이오드·엔코더는 제품 단자 참고자료를 제공하며 드라이버 제어, 다이오드 비선형 특성이나 엔코더 파형을 계산하지 않습니다. 지원하지 않는 소자는 검증되지 않은 동작 모델로 자동 변환하지 않습니다.

## 공식 모델 모식도 범위

MCU 보드는 [핀 자료의 공식 출처와 적용 범위](MCU_PIN_SOURCES.md)를 따릅니다. 추가 제품 모식도는 정확한 주문 코드와 공식 자료를 보존합니다. SOIC 칩의 핀 번호, 캐리어 보드의 단자 이름, 모터 배선의 색과 다이오드 극성은 서로 다른 표현이며 서로 바꾸어 쓰지 않습니다. 등록된 모델에 없는 임의의 물리 핀 번호나 치수를 만들어 넣지 않습니다.

| 추가 제품 | 확인 가능한 모식도 |
| --- | --- |
| ams AS5600-ASOT | 정확한 SOIC-8 칩의 8핀. 출처가 불분명한 AS5600 모듈 헤더와 구분 |
| Pololu #2130 DRV8833 캐리어 | 공식 단자명 15개. 보드의 16개 패드 물리 순서·번호를 추정하지 않음 |
| Pololu #4755 모터·엔코더 | 공식 6개 전선 색과 기능. 모터 전원과 엔코더 전원은 별개 |
| Vishay 1N5819 | 애노드와 띠 표시 캐소드. 임의 핀 1·2를 붙이지 않음 |
| ST B-G431B-ESC1 | 배터리·BEC/UART/PWM·CAN·U/V/W·Hall/엔코더의 외부 단자 19개. 미확인 패드 순서와 소비전류를 만들지 않음 |

[제품 단자 공식 자료와 적용 조건](ELECTRONIC_PRODUCT_DIAGRAM_SOURCES.md)을 확인하세요. AS5600의 두 전원 핀은 전원 모드별 연결이 다르고, #4755 엔코더 출력은 엔코더 공급 전압까지 올라가므로 3.3 V MCU와 자동 호환된다고 보지 않습니다.

제품 신호 핀과 MCU를 연결하면 모식도 아래 해당 신호의 전압·풀업 조건을 표시합니다. 예를 들어 #4755 엔코더는 모터 전원과 별도로 3.5–20 V를 사용하고 A/B 출력이 엔코더 공급 전압까지 올라간다는 경고가 보입니다. 실제 전압과 입력 허용값을 확인하고 필요하면 레벨 변환 회로를 설계하세요. 다른 모델로 바꿀 때 기존 연결을 해제하는 확인은 그 변경에만 적용됩니다.

모식도는 연결 관계를 확인하는 도식입니다. 실제 PCB 외곽·커넥터 위치·장착 치수·케이블 경로를 생성하거나 전체 장치의 동작을 인증하지 않습니다. 핀 연결 검토는 저장된 배선의 수동 도통과 지원하는 DC 입력의 초기 검토 범위입니다. MCU 코드, 통신 프로토콜과 기구 구동의 연동은 포함하지 않습니다.

## 2.19.0 배선 화면

상단 부품 색상 옆 **회로도**를 누르면 별도 창에서 **실물 배선**을 봅니다. 작업 공간 목록의 **회로도**는 메인 공간에서 같은 저장 회로를 표시합니다. 보드·배터리·모터·저항·스위치를 소형 도식으로 배치하고 **회로 기호** 보기로 전환할 수 있습니다. 보드 외형은 배선 안내이며 실제 PCB 제작 치수가 아닙니다.

**회로 편집… → 핀 연결**에서 시작 단자와 대상 단자를 클릭합니다. MCU의 신호 핀, 문서화된 제품 단자와 직접 등록한 단자를 연결하며, MCU의 실제 전원/GND 핀은 별도의 명시적 전원 핀 연결로 저장합니다. 같은 전원 레일로 이미 연결한 별칭은 일관되게 유지하지만 연결하지 않은 다른 전원 핀을 자동 배선하지 않습니다. 물리 전원 핀과 DC 계산의 A/B는 자동으로 같은 노드가 되지 않으므로 실제 공급 경로를 각각 지정하세요.

시작 단자를 다른 노드로 옮겨도 기존 노드의 다른 부품은 그대로입니다. **Esc**는 진행 중인 연결만 취소합니다. 연결된 핀을 선택한 뒤 **선택 핀 연결 해제**로 해당 핀의 배선을 지웁니다. 부품 드래그 위치와 연결은 **회로도 변경 저장**으로 반영하고 `.cad.json` 프로젝트에 저장합니다. **CAD 부품 보기** 또는 실물 배선의 부품 몸체 클릭은 연결된 3D 부품을 선택합니다. 선의 화면 길이와 색은 배선 표시이며 전선의 실제 길이·정격이나 전기적 호환성을 대신하지 않습니다.

B-G431B-ESC1은 STM32가 내장된 ESC 제품의 단자 참고 모델입니다. 일반 STM32 GPIO 보드처럼 취급하지 않으며, FOC·스위칭·펌웨어를 실행하거나 소비전류를 만들어 DC 부하로 넣지 않습니다. 정확한 적용 조건은 [공식 자료 기록](ELECTRONIC_PRODUCT_DIAGRAM_SOURCES.md)을 따릅니다.
