# Prompt CAD Studio 2.16.0 · 전원 연결·규격 자료·최적화

**도면 / 해석 → 전원 연결 설계…**에서 배터리 + → 스위치 → 공급선 → 부하 → 리턴선 → 배터리 −를 작성합니다. 전압, 동작점 전류, 두 전선의 실제 길이와 단면적을 입력해야 미리보기와 추가가 가능합니다. 실제 CAD 배터리·부하 부품에 연결할 수 있으며 기존 회로는 유지됩니다. 같은 도구는 **전장 회로** 창에도 있습니다.

미리보기는 부하 단자 전압, 공급선/리턴선 전압강하, 배터리·전선·스위치 손실과 DC 전력 회계를 보여줍니다. 입력한 허용 전류와 모터 기동 전류를 따로 비교합니다. 미입력 정격은 **미검증**으로 남습니다. Belden 전선 품번을 고르면 제조사 명목 DC 저항을 사용하고 출처를 저장합니다. 자유공기 전류를 밀폐 하네스 허용값으로 자동 사용하지 않습니다. **회로도 미리보기…**는 별도 창으로 열립니다.

**모델링 / 도면·해석 → 기계 · 전원 규격 DB…**에서 정확한 커넥터·DC 잭·전선 품번과 볼트 관통홀/머리 외경을 검색합니다. 21개 자료에 치수·조건·공식 출처·확인일을 함께 보관합니다. **선택**하면 사용자가 쓰던 AI 요청에 사양을 추가합니다. 제조사 도면에 없는 패널 가공 구멍, 체결 강도, 피로 수명은 채우지 않습니다. [등록 자료와 범위](MECHANICAL_CATALOG_KO.md).

평평한 면을 선택하고 **구멍 뚫기 → 규격 관통홀 선택…**에서 M4/M5/M6/M8 ISO 273 medium 치수를 고르면 실제 관통 절삭을 미리 볼 수 있습니다. 출처와 기준 치수를 작업 기록에 남기며, 직접 치수를 바꾼 경우 변경 여부도 남깁니다. 프린터 치수 보정은 별도 기능입니다. 볼트 관통홀은 탭 하공과 다릅니다.

3D 화면의 **전체 / 전장만 / 구조만 / 동력만**으로 표시와 선택 대상을 좁힙니다. 임시 역할 색은 노란색/흰색/초록색이며 **전체**로 돌아가면 저장한 색과 이전 숨김 상태를 복원합니다. **전장 회로 → 회로도 보기…**와 선택 배터리 출력 ON/OFF도 제공합니다. 작은 창에서는 역할 버튼과 부품 보기 도구가 한 줄을 공유하며 덜 쓰는 보기 도구는 Qt의 펼침 메뉴로 접근합니다.

이름·색·역할·회로만 바뀌면 이미 검사한 CAD 메시와 VTK 화면 객체를 재사용합니다. 치수·위치·스케치·피처·구속·변수·가져온 형상은 정상적으로 다시 계산합니다. 12개 원통의 이름·색 변경에서 형상 미리보기 계산 중앙값은 174 ms → 0.52 ms였으며, 앱 전체 속도에 대한 수치는 아닙니다. [측정 범위](PERFORMANCE_2_16_0.md).

프로젝트·그룹·관절·작업 기록과 STEP/STL 내보내기를 유지합니다. 외부 STL을 가져온 뒤 `.cad.json`으로 저장하면 가져온 형상은 프로젝트 안에 보관되므로 원본 STL을 옮겨도 다시 열 수 있습니다. STL에서 원래의 파라메트릭 스케치·피처가 복원되는 것은 아닙니다.

전장 계산은 DC 저항 등가와 회로 연결 검사입니다. MCU 펌웨어 실행, 스위칭/주파수/전자기장·열 연성 해석과 기계 정격 인증은 제공하지 않습니다. 기존 사용자 데이터와 실행 중인 CAD 작업을 보호하며, 앱이 열려 있으면 제자리 업데이트를 보류합니다.

**도면 / 해석 → 볼트 축방향 검토…**에서 M4–M8 보통 피치·8.8/10.9 등급 볼트의 정적 축인장을 Bossard 공식 표의 증명하중과 비교합니다. 실제 하중·개수·안전계수와 균등 분담/머리 형상 가정을 직접 확인해야 합니다. M8의 감소 증명하중 예외도 확인합니다. 결과는 나사부의 순수 정적 축인장만 다루며 기계·조립체의 피로·전단·뽑힘·FDM 강도 인증이 아닙니다. [계산 범위와 출처](FASTENER_AXIAL_CHECK_KO.md).

AI의 전원 계획에서 필수 전압·전류·전선 수치가 없거나 0이면 무제한 검증을 반복하지 않고 **전원 수치 입력 필요**를 안내합니다. 확인한 값을 프롬프트 또는 전원 연결 설계 창에 넣은 뒤 다시 진행합니다. 연결 상태와 기존 설계·보존한 초안은 유지합니다. 양수 검사만으로 AI가 제시한 숫자의 출처가 증명되지는 않으므로 적용 전 실제 동작값과 제조사 조건을 확인하세요.
