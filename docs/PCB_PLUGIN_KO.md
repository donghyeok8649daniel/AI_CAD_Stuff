# PCB 모드

작업 공간 목록의 `PCB` 또는 공학 메뉴의 `PCB 설계 · 배선 / 시뮬레이션 / BOM`을 선택합니다. 기존 CAD의 형상과 독립적인 PCB 초안을 편집합니다. `CAD에 PCB 저장`은 PCB 필드를 현재 문서에 명시적으로 적용해 저장·Undo·Redo 대상으로 만듭니다. PCB만 저장해도 CAD의 형상·구속·기존 전장은 보존됩니다.

1. `빈 보드` 또는 `분압 예제`로 시작합니다. 보드 폭·높이와 GND를 포함한 net 목록을 입력하고 `보드 조건 적용`을 누릅니다.
2. 저항·커패시터·전압원·수동 커넥터(`none`)·미지원 IC(`unsupported`)를 추가합니다. `핀 / 모델 / 가격 편집`에서 핀 번호, net, 원형 패드의 부품 중심 상대 좌표(mm), 직경, 층을 선언합니다. 제품 사양을 확인한 경우 출처를 저장합니다. 단순 선언은 검증된 실제 풋프린트가 아닙니다.
3. 부품을 드래그하거나 좌표를 편집합니다. `수동 배선`을 켜고 같은 층의 시작 패드, 원하는 꺾임점, 같은 net의 끝 패드를 차례로 클릭합니다. 우클릭 또는 Esc로 배선을 취소합니다. F.Cu/B.Cu는 다층 패드만 연결하며 비아는 지원하지 않습니다.
4. `배치 / 구리 연결 검사`로 경계·패드 간격·다른 net 간 배선 충돌·실제 구리 연결을 점검합니다. 검사 통과는 제조·정격 승인이나 실제 도통 증거가 아닙니다. 수동 배치 좌표나 부품 몸체 표시는 CAD 3D 부품을 생성하지 않습니다.
5. `시뮬레이션 / AI`에서 DC 또는 단일 주파수 AC를 명시 실행합니다. 저항(Ω), 커패시터(F), 이상 전압원(DC V, AC peak V와 위상 °)만 지원합니다. DC에서 커패시터는 개방됩니다. AC 저항 평균전력은 peak 전류의 제곱에 R/2를 곱합니다. 논리 netlist를 계산하며 배선 저항·기생성분·동적 firmware·ADC·MCU·반도체·과도응답·열·노이즈·실물 상태는 계산하지 않습니다. `unsupported`인 실장 부품, 미접속 모델 핀, 떠 있는 net, 모순된 전압원, 누락 runtime은 명시 차단됩니다.
6. `Codex PCB 설계 자문`은 CAD AI 패널의 기존 ChatGPT 계정·선택 모델·강도를 사용합니다. 명시 클릭 때 PCB/BOM 입력을 전송하고 기존 연결·모델 검사·취소·180초 활성 대기시간 경로를 이용합니다. 유료 API로 전환하지 않습니다. 답변은 텍스트 자문이며 자동 편집·형상 승인·회로 적용은 하지 않습니다. 설계·CAD 문서·모델 설정이 변경되거나 취소된 응답은 폐기합니다. 실제 계정 호출은 이 인계 검증에서 실행하지 않았습니다.
7. 가격 편집에서 `unknown`은 금액 없이 저장합니다. `reference` 또는 `quoted`에는 금액·통화·기준일·판매처·HTTPS 출처가 모두 필요합니다. 이는 저장된 참조/입력 견적이며 실시간 가격 확인이 아닙니다. BOM은 실장 부품을 묶고 보드 수량·최소 구매수량·묶음수량을 계산합니다. 통화별 확인된 소계를 별도로 표시하며 미확인 가격과 다른 통화가 있으면 예산 판정은 `incomplete`입니다. 환율을 생성하지 않고 PCB 제조·조립·배송·세금은 합계에서 제외합니다. CSV 수식 문자열은 일반 텍스트로 내보냅니다.
8. `PCB + 전장에 명시 적용`은 배치 오류가 없는 초안을 `pcb_` 이름 공간으로 기존 전장에 추가합니다. 기존 회로·등록·firmware를 보존합니다. 양의 DC 전압원·저항·커패시터만 기존 DC 모델로 변환하고 미지원 IC/커넥터는 analysis disabled인 수동 단자로 적용합니다. 동일 `pcb_` ID의 재적용은 충돌로 차단합니다. 논리 연결 반영은 배선 제작이나 하드웨어 구동이 아닙니다.

PCB 파일은 선언적 JSON인 `.pcbp`로 열고 저장합니다(2 MiB 한도). PCB 저장 이전의 로컬 초안은 CAD 파일에 포함되지 않습니다. 초안을 버리지 않으려면 저장 또는 내보내기 후 문서를 전환하십시오. 현재 문서가 다른 편집에서 변경되면 오래된 적용을 차단하고 초안을 보존합니다. 새 문서/앱 종료 시 저장되지 않은 PCB 초안을 버릴지 앱에서 확인합니다.

지원 한도는 부품 64개, 패드 512개, net 192개, 배선 256개/선분 1024개, 보드 500×500 mm입니다. 구리 면, 비아, 드릴, 일반 KiCad 가져오기, Gerber 제조 출력, 자동 라우터는 지원하지 않습니다. 원 ADS131M04 KiCad 프로젝트와 피로시험기 firmware/정격 자료를 자동으로 변환하거나 변경하지 않습니다.

## 오프라인 명령

CAD Python runtime에서 `python -m cadstudio.pcb_cli example --output divider.pcbp`로 예제를 만듭니다. 이어서 `layout divider.pcbp`, `simulate divider.pcbp`, `bom divider.pcbp`, `spice divider.pcbp`를 실행합니다. `manifest`, `schema`도 JSON으로 내보낼 수 있습니다. 지원되지 않은 backend는 exit 2와 명시적인 `blocked` 결과를 반환합니다. 요청 없이 외부 simulator나 helper를 실행하지 않습니다.

## 기준과 출처

- [ngspice 공식 튜토리얼](https://ngspice.sourceforge.io/ngspice-tutorial.html): 논리 netlist, 동작점과 AC의 의미 참고. 이 플러그인은 ngspice를 실행하거나 동등한 SPICE 지원을 주장하지 않습니다.
- [TI ADS131M04IRUKR 공식 구매 페이지](https://www.ti.com/product/ADS131M04/part-details/ADS131M04IRUKR): 2026-10-14 확인 응답에는 숫자 가격이 제공되지 않았으므로 새 실제 가격을 생성하지 않았습니다. 테스트의 example.com 가격은 산술 fixture이며 실제 견적이 아닙니다.

검증은 실제 로컬 NumPy 계산, offscreen Qt 작업공간, 문서 이력/저장, 작은 CAD 솔리드 및 기존 MainWindow의 PCB 진입 메서드와 제한된 QWidget host를 사용합니다. 일반 native MainWindow/VTK/GPU, 최종 EXE, 사용자 화면, 실제 Codex 계정 및 실제 하드웨어 검수는 포함하지 않습니다.
