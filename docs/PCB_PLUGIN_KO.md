# PCB 모드

작업 공간 목록의 `PCB` 또는 공학 메뉴의 `PCB 설계 · 배선 / 시뮬레이션 / BOM`을 선택합니다. 기존 CAD의 형상과 독립적인 PCB 초안을 편집합니다. `CAD에 PCB 저장`은 PCB 필드를 현재 문서에 명시적으로 적용해 저장·Undo·Redo 대상으로 만듭니다. PCB만 저장해도 CAD의 형상·구속·기존 전장은 보존됩니다.

1. `빈 보드` 또는 `분압 예제`로 시작합니다. 보드 폭·높이, 구리 층 수(2층 또는 4층), GND를 포함한 net 목록을 입력하고 `보드 조건 적용`을 누릅니다. 2층은 `F.Cu, B.Cu`, 4층은 앞면부터 `F.Cu, In1.Cu, In2.Cu, B.Cu` 순서입니다. 내층을 참조하는 패드·배선·비아·영역이 남아 있으면 2층으로 변경할 수 없습니다.
2. 저항·커패시터·전압원·수동 커넥터(`none`)·미지원 IC(`unsupported`)를 추가합니다. `핀 / 모델 / 가격 편집`에서 핀 번호, net, 부품 중심 상대 좌표(mm), `circle / rect / oval / roundrect` 형상, X/Y 크기, 회전, 층을 선언합니다. 원형 패드의 X/Y 크기를 비워 두면 기존 직경을 사용하고, 다른 형상에는 두 크기가 모두 필요합니다. `roundrect`의 모서리 반지름 비율은 짧은 변의 0~0.5입니다. 드릴은 0이면 없고, 양수이면 패드의 짧은 변보다 작은 원형 홀입니다. 타원·슬롯 드릴은 지원하지 않으며 원형으로 대체하지 않습니다. 제품 사양을 확인한 경우 출처를 저장합니다. 단순 선언은 검증된 실제 풋프린트가 아닙니다.
3. 부품을 드래그하거나 좌표를 편집합니다. `수동 배선`을 켜고 활성 층의 시작 패드 또는 비아, 원하는 꺾임점, 같은 net의 끝 패드 또는 비아를 차례로 클릭합니다. 우클릭 또는 Esc로 배선을 취소합니다. `비아 / 구리 영역` 탭에서 비아를 추가·편집·삭제할 수 있습니다. 비아의 구리 직경보다 작은 양의 원형 드릴과 앞면에서 뒷면 순서의 연결 층을 지정합니다. 시작/끝 층 쌍은 그 사이의 활성 구리층까지 포함하며, 전체 층을 입력할 때에는 연속된 순서여야 합니다. 다층 패드나 해당 층을 연결하는 비아에서 층을 바꾸어 배선합니다.
4. `배치 / 구리 연결 검사`로 패드의 실제 형상·회전, 직선 배선, 비아의 연결 층, 저장된 채움 구리를 점검합니다. 결과의 `needs_edit`는 기하 오류, `partial_checks`는 일부 검사 또는 연결 근거의 한계, `geometric_checks_passed`는 제공된 기본 기하 검사에서 오류가 없음을 뜻합니다. 원형 홀의 도금·환형링·홀 간격, 제조 적합성, 정격, 임피던스, 허용 전류와 열은 판정하지 않습니다. 비아만 있거나 같은 net 이름만 지정되어 있다고 연결된 보드로 판정하지 않습니다. 검사 통과는 제조·정격 승인이나 실제 도통 증거가 아닙니다. 수동 배치 좌표나 부품 몸체 표시는 CAD 3D 부품을 생성하지 않습니다.
5. `시뮬레이션 / AI`에서 DC 또는 단일 주파수 AC를 명시 실행합니다. 저항(Ω), 커패시터(F), 이상 전압원(DC V, AC peak V와 위상 °)만 지원합니다. DC에서 커패시터는 개방됩니다. AC 저항 평균전력은 peak 전류의 제곱에 R/2를 곱합니다. 논리 netlist를 계산하며 배선 저항·기생성분·동적 firmware·ADC·MCU·반도체·과도응답·열·노이즈·실물 상태는 계산하지 않습니다. `unsupported`인 실장 부품, 미접속 모델 핀, 떠 있는 net, 모순된 전압원, 누락 runtime은 명시 차단됩니다.
6. `Codex PCB 설계 자문`은 CAD AI 패널의 기존 ChatGPT 계정·선택 모델·강도를 사용합니다. 명시 클릭 때 PCB/BOM 입력을 전송하고 기존 연결·모델 검사·취소·180초 활성 대기시간 경로를 이용합니다. 유료 API로 전환하지 않습니다. 답변은 텍스트 자문이며 자동 편집·형상 승인·회로 적용은 하지 않습니다. 설계·CAD 문서·모델 설정이 변경되거나 취소된 응답은 폐기합니다. 실제 계정 호출은 이 인계 검증에서 실행하지 않았습니다.
7. 가격 편집에서 `unknown`은 금액 없이 저장합니다. `reference` 또는 `quoted`에는 금액·통화·기준일·판매처·HTTPS 출처가 모두 필요합니다. 이는 저장된 참조/입력 견적이며 실시간 가격 확인이 아닙니다. BOM은 실장 부품을 묶고 보드 수량·최소 구매수량·묶음수량을 계산합니다. 통화별 확인된 소계를 별도로 표시하며 미확인 가격과 다른 통화가 있으면 예산 판정은 `incomplete`입니다. 환율을 생성하지 않고 PCB 제조·조립·배송·세금은 합계에서 제외합니다. CSV 수식 문자열은 일반 텍스트로 내보냅니다.
8. `PCB + 전장에 명시 적용`은 배치 오류가 없는 초안을 `pcb_` 이름 공간으로 기존 전장에 추가합니다. 기존 회로·등록·firmware를 보존합니다. 양의 DC 전압원·저항·커패시터만 기존 DC 모델로 변환하고 미지원 IC/커넥터는 analysis disabled인 수동 단자로 적용합니다. 동일 `pcb_` ID의 재적용은 충돌로 차단합니다. 논리 연결 반영은 배선 제작이나 하드웨어 구동이 아닙니다.

구리 영역은 선언한 `outline`과 `holes`, 실제 저장된 `filled_polygons`를 별도로 보존합니다. `비아 / 구리 영역` 탭과 캔버스에서 채움 상태를 확인할 수 있습니다. 채움이 없으면 `outline / 미채움`과 점선 경계로 표시하며, 외곽선만으로 구리 면·연결·검사 통과를 추정하지 않습니다. 채움은 저장된 형상을 표시하고 검사하며 자동으로 다시 계산하지 않습니다. 반복된 브리지·슬릿 점을 가진 분할 채움 윤곽은 좌표와 순서를 보존하지만, 그 표현상 선을 실제 연결 구리로 취급하거나 구리 간격을 확정하지 않습니다. 이 경우 연결·간격 검사는 `partial_checks`이며 확인되지 않은 경로는 경고로 남습니다.

PCB 파일은 선언적 JSON인 `.pcbp`로 열고 저장합니다(2 MiB 한도). 기존 2층 원형 패드 데이터의 직경과 F.Cu/B.Cu 선언을 유지하며, 변경하지 않은 기본값은 기존 저장·Undo·Redo 이력과 호환되도록 보존합니다. 새 형상·드릴·비아·채움·4층 선언은 명시 데이터로 저장됩니다. 선택적 `net_labels`는 등록된 내부 net ID의 사람이 읽는 이름을 보존하며, 같은 표시 이름이 서로 다른 net을 합치거나 연결하지 않습니다. PCB 저장 이전의 로컬 초안은 CAD 파일에 포함되지 않습니다. 초안을 버리지 않으려면 저장 또는 내보내기 후 문서를 전환하십시오. 현재 문서가 다른 편집에서 변경되면 오래된 적용을 차단하고 초안을 보존합니다. 새 문서/앱 종료 시 저장되지 않은 PCB 초안을 버릴지 앱에서 확인합니다.

지원 한도는 부품 64개, 패드 512개, net 192개, 배선 1024개/전체 직선 선분 1024개, 비아 512개, 구리 영역 64개, 보드 500×500 mm입니다. 저장된 채움 polygon 하나는 최대 8192점을 보존합니다. 일반 KiCad 가져오기, Gerber 제조 출력, 자동 라우터와 구리 영역의 자동 재채움은 지원하지 않습니다. 구리 층 수는 제조용 적층·재료·층간 두께를 지정하지 않습니다. 원 ADS131M04 KiCad 프로젝트와 피로시험기 firmware/정격 자료를 자동으로 변환하거나 변경하지 않습니다.

## 오프라인 명령

CAD Python runtime에서 `python -m cadstudio.pcb_cli example --output divider.pcbp`로 예제를 만듭니다. 이어서 `layout divider.pcbp`, `simulate divider.pcbp`, `bom divider.pcbp`, `spice divider.pcbp`를 실행합니다. `manifest`, `schema`도 JSON으로 내보낼 수 있습니다. 지원되지 않은 backend는 exit 2와 명시적인 `blocked` 결과를 반환합니다. 요청 없이 외부 simulator나 helper를 실행하지 않습니다.

## 기준과 출처

- [ngspice 공식 튜토리얼](https://ngspice.sourceforge.io/ngspice-tutorial.html): 논리 netlist, 동작점과 AC의 의미 참고. 이 플러그인은 ngspice를 실행하거나 동등한 SPICE 지원을 주장하지 않습니다.
- [TI ADS131M04IRUKR 공식 구매 페이지](https://www.ti.com/product/ADS131M04/part-details/ADS131M04IRUKR): 2026-10-14 확인 응답에는 숫자 가격이 제공되지 않았으므로 새 실제 가격을 생성하지 않았습니다. 테스트의 example.com 가격은 산술 fixture이며 실제 견적이 아닙니다.

이 모드는 저장된 선언 데이터, 논리 회로 계산과 기본 평면 기하 검토를 제공합니다. `manufacturing_qualified`는 항상 false이며, 일반 native MainWindow/VTK/GPU, 최종 EXE, 실제 Codex 계정 호출이나 하드웨어·제조 검수를 이 검사 결과로 확인할 수 없습니다.
