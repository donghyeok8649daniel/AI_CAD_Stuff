# Prompt CAD Studio v3.1.0

선택한 부품의 3D 프린팅 미리보기와 여러 출력판 STL 내보내기를 추가했습니다. 출력 배치는 사본에서 처리하며 원래 부품 위치·관절·전장·작업 이력을 바꾸지 않습니다.

## 사용법

1. CAD에서 원하는 부품을 선택한 뒤 **파일 → 3D 프린팅 · STL 미리보기…**를 엽니다. 상단 작업 공간을 **3D 프린팅**으로 바꾸면 출력 도구도 표시됩니다. CAD에서 아무 부품도 선택하지 않았으면 전체 부품이 처음 체크되므로 출력할 대상을 확인하세요.
2. **현재 선택 / 전체 선택 / 선택 해제**와 부품별 체크로 출력 대상을 정합니다. **볼트·너트 제외**를 체크하면 제외 대상과 판별 근거가 표시됩니다. 와셔·핀과 종류를 알 수 없는 부품은 자동 제외하지 않습니다. 제품 정보에 종류가 없으면 이름의 볼트·너트 단어가 선택 보조 단서로 쓰이며, 실제 제품 확인을 뜻하지 않습니다.
3. **프린터 / 자동 배치 설정**에서 출력 영역 X/Y/Z(mm)와 부품 간격을 입력합니다. 기본 영역은 220×220×250 mm입니다. 부품이 많으면 여러 출력판으로 나눕니다.
4. **자동 자세·배치 (서포트 최소)**를 누르면 실제 형상의 후보 자세를 비교하여 서포트 부담과 바닥 접촉·무게중심 안정성, 출력 영역 적합성을 함께 고려하고 여러 판에 배치합니다. **자동 자세 검토값**을 펼치면 현재 부품의 추천 회전, 전후 서포트 추정값·접촉 면적·안정성·출력 영역 적합성을 확인할 수 있습니다. 추천 근거는 형상 기반 추정이며 실제 슬라이서의 서포트 체적이나 출력 성공을 보장하는 값은 아닙니다.
5. **미리볼 출력판**에서 판을 고릅니다. 부품별 X/Y 위치와 XYZ 회전을 입력하거나 상면에서 부품을 드래그합니다. 자동 추천 후에도 직접 돌리거나 옮길 수 있습니다. **이 부품의 출력판**으로 다른 판이나 새 판에 옮길 수 있습니다. 자동 자세 버튼을 다시 누르면 새 추천과 배치를 적용하며, 일반 미리보기 갱신은 수동 자세를 유지합니다. **전체 자동 배치 / 방향 초기화**는 출력용 수동 배치를 초기화합니다.
6. 현재 판만 필요하면 **현재 출력판 STL 저장**, 여러 판을 함께 저장하려면 **전체 출력판 STL · ZIP 저장**을 사용합니다. ZIP에는 `plate-001.stl` 등 판별 STL과 상대 경로의 `print-index.json`이 들어갑니다. 내보내기는 마지막으로 검증된 미리보기 형상을 사용합니다.

[밤부 스튜디오의 자동 자세·자동 배치·여러 판 관리 흐름](https://github.com/bambulab/BambuStudio/blob/master/README.md)을 참고했습니다. CAD의 자동 추천은 이 앱의 형상 비교 기능이며, 프린터·재료·서포트·레이어 설정을 사용한 최종 슬라이싱은 밤부 스튜디오 등의 슬라이서에서 확인하세요.

한 부품이 출력 영역보다 크거나 판에서 겹치면 경고하고 해당 판과 전체 ZIP 내보내기를 막습니다. 문제가 없는 다른 판은 **현재 출력판 STL 저장**으로 따로 저장할 수 있습니다. 큰 단일 부품을 자동으로 잘라 조립 구조를 만들지는 않습니다. 방향·프린터 크기·선택 부품을 바꿔 해결하세요. 서포트·인필·레이어와 G-code는 슬라이서에서 설정합니다. 프린터 공차 보정은 중복 적용하지 않습니다.

검사 중 설정을 바꾸면 이전 미리보기는 무효화됩니다. 저장창을 취소하거나 내보내기 도중 창을 닫으면 원본 프로젝트를 보존하고, 취소 확인 전까지 기존 STL/ZIP을 교체하지 않습니다.

## 모션 연결 편집

비율·오프셋·관절 한계 입력은 저장된 실수 정밀도를 유지합니다. 기존 연결을 선택해 **선택한 연결 수정**으로 편집합니다. 불완전한 한계 입력·수정되지 않은 비율·이전 미리보기가 잘못 적용되는 경로를 차단했습니다. 이는 실제 액추에이터 정격·나사 리드·강도 검증을 대신하지 않습니다.

## 검증 기록

실제 소스 검사와 네이티브 EXE 미리보기·선택·다중판·STL/ZIP 저장·취소 결과는 저장소의 `VALIDATION.md`와 `docs/native310-validation.json`에 기록합니다. 다른 버전의 전체 검사 수를 이번 검사 수로 표시하지 않습니다. 합성 출력 부품 검사와 실제 연구용 시험기·드론의 제작 승인은 별도입니다.
