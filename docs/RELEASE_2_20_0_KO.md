# 2.20.0 · 시편 챔버, 소재와 하중 측정

## 어디에서 사용하는가

상단 작업 공간을 **시편**으로 바꾸면 **시편 습도 챔버 / 편집**, **하중 측정 / 교정 연결**, **부품 재질 / 물성 목록**이 나타납니다. 모두 **도면 / 해석** 메뉴와 Ctrl+K 도구 검색에서도 찾을 수 있습니다.

### 챔버

시편·그립을 선택한 뒤 챔버 도구를 열어 보호 영역을 가져옵니다. 가져오는 값은 현재 자세의 바운딩 박스이며 전체 구동 범위는 사용자가 포함해야 합니다. X/Y/Z 최소·최대와 여유, 벽, 창, 정적 포트, 로드 지름과 벨로즈 길이/스트로크를 명시합니다. 케이스·도어·창·가스켓·체결부·관통 포트·정적 O-ring 홈·벨로즈를 별도의 닫힌 CAD 솔리드로 생성합니다.

새 체적 간섭이나 선언한 이동 영역의 장애물이 있으면 적용을 막습니다. 공구 접근 공간은 별도 경고로 표시합니다. **전면 도어 분리해 내부 보기**는 표시만 변경합니다. 적용 후 생성 부품의 속성 또는 타임라인의 챔버 기록에서 다시 편집합니다. 저장한 전체 생성 부품 ID 집합을 유지하며 이름·사용자 색·재질·제품 정보·외부 구속을 보존합니다. 구성품 종류/ID를 바꾸는 편집은 참조를 몰래 삭제하지 않고 거절하므로 새 챔버로 추가해야 합니다. 실행 취소 뒤에는 현재 분기까지의 설정만 사용합니다.

외부 구속이 새 보호영역의 위치·회전을 되돌리는 편집은 적용하지 않습니다. 보호영역 중심을 유지해 크기를 바꾸거나, 구속 기준을 먼저 조정한 뒤 편집해야 합니다. 요구 치수의 위치와 실제 조립 위치가 다르게 검증되는 것을 방지합니다.

공급사 압축/신장 길이, 압력차·유효 면적·스프링 강성·씰 마찰·프리로드가 미확인이면 계산값을 만들어내지 않습니다. 벨로즈 CAD 자세는 기하학적 미리보기이며 누설률·습도 균일도·내압·피로 수명을 인증하지 않습니다. 상부 정적 씰은 움직이지 않는 로드에만 사용합니다.

일반 관절 구동은 벨로즈를 자동 변형하지 않습니다. 벨로즈 길이와 이동 칼라의 자세를 함께 맞춰 검토해야 하며, 별도 자세에서 형상을 다시 생성한 검사는 연속적인 물리 변형 시뮬레이션이 아닙니다.

### 재질

여러 부품을 선택해 출처가 있는 소재 후보를 명시적으로 적용합니다. 기존 사용자 입력은 교체 확인 없이 바뀌지 않습니다. 공칭·대표값·하한·범위와 시험 조건을 구분하며 물성이 없는 필드는 미확인으로 남습니다. 복합 전장부품, 베어링, 시험 시편의 합금/열처리를 이름이나 색만으로 추정하지 않습니다. 소재 변경은 검증된 동일 형상의 메시를 재사용하며 질량과 해석은 현재 지정값을 읽습니다.

시편 응력/변형 창의 **선택 시편의 재질값 가져오기**는 사용자가 누른 경우에만 완전한 등방성 E/ν/항복강도 값을 가져옵니다. Si 방향성 물성이나 비선형 씰을 등방성 선형 시편으로 자동 바꾸지 않습니다. 소재 목록은 실제 납품 재료의 성적서와 다릅니다.

### 하중 측정과 환경 센서

먼저 CAD 부품에 실제 제품 모델을 전장으로 등록하고 회로도에서 단자·핀 배선을 연결합니다. 하중 측정 도구의 역할 입력은 단자의 역할 설명이며 전선을 자동 생성하지 않습니다. ADC 각 입력 공통모드와 차동 풀스케일, gain·CLKIN·OSR·Turbo·SPS, 보드 전압, 실제 핀 도통, 로드셀 여자 전압·용량과 교정 상태를 확인합니다.

HBK U10M 25 kN passive 변형, TI ADS131M04/ADS1232, AVIA HX711, Sensirion SHT31/SHT45, 별도 NUCLEO-G474RE DAQ와 maxon EC-i 52 667065 후보를 참고합니다. **B-G431B-ESC1의 전류 측정 핀을 별도 DAQ 핀으로 사용하지 않습니다.** ADS131M04의 CLKIN은 SPI SCLK와 별도 발진 부품이어야 합니다. 3.3 V AVDD/high gain에 3.3 V 또는 5 V 균형 브리지를 직결하면 허용 공통모드를 벗어납니다. 2.5 V 여자 후보도 실제 회로·장착·교정 검증이 필요합니다.

실측 count/N 교정점을 입력해 선형 변환과 잔차를 계산합니다. 인증서나 시스템 대역폭이 확인되지 않으면 미확인으로 표시하며 펌웨어·FOC·실물 수집을 실행한 것으로 표시하지 않습니다. AC 전원 보호·STO·회생 에너지·실제 하중 정격은 별도 설계/시운전 대상입니다. 하중과 반복 주파수 미입력은 미정으로 남습니다.

AI에는 현재 저장된 계측 역할·수치·실제 전원 단자와 제한된 검토 결과를 함께 전달합니다. 제조사 감도 범위와 일련번호 교정은 별도로 다룹니다. 교정 날짜와 출처 확인 날짜도 작업 기록과 함께 저장됩니다. 작은 화면에서는 설정 영역만 스크롤하여 검사·저장 버튼을 사용할 수 있습니다.

## 저장·안정성과 범위

기존 CAD JSON의 전체 작업 이력과 기존 재질·회로·사용자 색상을 보존합니다. 사용자 프로젝트나 연구 자료는 공개 배포에 포함하지 않습니다. 비동기 형상 계산이 화면 표시보다 먼저 끝나도 렌더링은 표시된 살아 있는 초기화 완료 뷰에서만 수행합니다. 이 수정은 재현한 초기화/종료 경로를 보호하며 모든 그래픽 드라이버 오류가 제거됐다는 의미는 아닙니다.
