# 회전 검사 작업 분할

회전 창의 형상·간섭 검사는 요청한 종료 각도와 최대 2도 간격을 유지하며, 완료된 작업부터 자동으로 나누어 계속 계산한다. 전체 초기 부품 쌍과 각 표본에서 변한 부품을 포함하는 쌍을 실제 솔리드 교집합으로 검사한다. 정확히 같은 자세·지역 형상이 보장된 정적 쌍만 기존 검사 결과를 재사용한다. 그룹·표시 상태로 간섭을 숨기지 않는다.

형상 엔진 대기와 실제 계산은 별도다. 대기는 최대 120초이며, 약 0.1초마다 취소를 확인한다. 검사 작업 단위의 제한은 기존 120초 또는 256개 초과 부품에서 180초를 유지한다. 완료한 쌍·자세·계산 단계 경계에서 작업 단위를 나눈다. 전체 검사 시간에는 단일 180초 상한을 적용하지 않으므로 큰 설계는 더 오래 걸릴 수 있다. 작업량은 고정된 초기 쌍·최대 721개 표본 범위이며, 같은 실패 작업을 무한 재시도하지 않는다.

화면은 대기 시간, 전체 실제 계산 시간, 현재 작업 단위 시간, 표본 번호를 표시한다. ‘검사 시간·단계 기록’에서 단계별 시간을 확인할 수 있다. 모든 표본과 마지막 검사한 자세의 메시 준비가 끝나야 재생이 가능하다. 부분 검사·취소·실패는 성공이나 간섭 없음으로 처리하지 않는다. 결과를 받을 때와 재생할 때 원본 설계가 바뀌었으면 폐기한다.

체크포인트는 현재 프로세스의 검사 진행을 이어가는 용도다. 앱 종료 뒤 복구하는 저장 파일은 아니며, 취소한 결과는 다시 검사한다. 검사 중에는 커널 잠금을 유지한다. 다른 형상 작업은 대기할 수 있다. 네이티브 교집합·테셀레이션 하나는 실행 중간에 취소하지 못하고, 다음 경계에서 취소 및 한도를 확인한다. 한 계산이 작업 단위 한도를 넘으면 재생을 허용하지 않는다.

직접 호출하는 `compile_joint_playback`은 기본 `segmented=False`로 전체 검사 시간 한도를 유지한다. UI 작업자가 명시적으로 `segmented=True`를 사용한다. 공차, 표본 사이 연속 충돌, 실제 모터 RPM·힘·전기·열·강도·비행은 이 표본 검사로 검증되지 않는다. 단일 스레드 Boolean 후보는 실제 신규 계측에서 실패하여 배포 소스에 포함하지 않는다.
