# 2.24.1 · PCAD 파일 연결 보정

새 프로젝트는 `.pcad`로 저장합니다. 설치는 전용 확장자만 등록하며, 기본 앱이 지정되지 않은 일반 `.json`까지 CAD가 자동 선택되던 Windows 동작을 수정했습니다. 2.24.0에서 등록한 일반 JSON 후보 항목은 앱이 만든 값과 일치할 때만 제거합니다. 기존 기본 앱·UserChoice·사용자가 바꾼 값은 보존합니다.

이전 `.cad.json`은 계속 읽을 수 있고 파일명에 한정된 우클릭 열기를 제공합니다. 같은 폴더에서 `.pcad`로 이름이 바뀐 파일은 이전 최근 파일 경로에서도 찾습니다. 이름 변경은 내용·부품·작업 기록·업로드 코드를 변환하지 않습니다.

BOM 설계, Codex 펌웨어 생성·검토·프로젝트 저장, 전장 작업과 기존 기능은 유지합니다. [2.24.0 사용법](RELEASE_2_24_0_KO.md), [Windows 연결 안내](FILE_ASSOCIATIONS_KO.md).

기존 설치는 업데이트 EXE로 같은 경로를 갱신합니다. 열려 있는 작업을 저장하고 앱을 종료하세요. 검증 수치는 [기록](native2241-validation.json)에 제공합니다.
