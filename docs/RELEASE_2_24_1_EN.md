# 2.24.1 · dedicated PCAD association correction

New projects use `.pcad`. Registration now advertises only that extension. Windows could infer CAD as the default for otherwise unassigned ordinary JSON from the generic OpenWith entry in2.24.0. This release retires only unchanged app-owned legacy values and preserves existing defaults, protected UserChoice and user edits.

Legacy `.cad.json` projects remain readable and retain their filename-filtered context action. Missing recent legacy paths resolve to the renamed `.pcad` counterpart in the same folder. The rename preserves the original bytes and all embedded project data.

BOM design, Codex firmware review, saved sources and existing electrical/CAD features remain. [Usage](RELEASE_2_24_0_EN.md), [aggregate verification](native2241-validation.json).
