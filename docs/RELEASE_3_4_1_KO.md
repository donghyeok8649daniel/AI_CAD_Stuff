# Prompt CAD Studio 3.4.1 후보 변경

이 문서는 후속 후보의 구현 범위입니다. 공개 릴리스와 정식 설치 여부는 별도 배포 검증 기록을 따릅니다. 현재 공개·설치 버전은 3.4.0이며, 이 후보의 실제 Windows 화면 검증은 아직 완료되지 않았습니다.

설치와 업데이트는 `%LOCALAPPDATA%\Programs\PromptCADStudio`의 앱 한 곳을 사용합니다. 기존 프로젝트, 전체 작업 이력, 설정, 로그인 자료와 알 수 없는 사용자 파일을 보존합니다. 실행 중인 CAD가 있으면 교체를 보류합니다.

설치·업데이트 후 `.pcad`의 기존 Prompt CAD Studio 연결 경로를 갱신합니다. Windows가 만든 `pcad_auto_file` 경로도 기존 앱의 소유 근거가 확인되면 같은 정식 실행 파일을 가리키도록 갱신합니다. Windows의 보호된 사용자 선택과 일반 `.json` 연결, 다른 앱의 파일 연결은 보존합니다. 소유 근거가 없는 선택은 자동 변경하지 않고 필요한 사용자 선택을 알립니다. 파일 설치 성공과 연결 완료를 구분하므로, 연결이 미완료이면 완료로 표시하지 않습니다.

설계 이력을 이어서 적용할 때 기존 이력 전체를 중복 복사하는 작업을 줄였습니다. 적용이나 다른 파일 열기 중 이력 생성·최종 복사·경로 처리에 실패하면 기존 문서와 이력을 함께 보존합니다. 문서 생성이 성공한 뒤 발생하는 모든 화면·렌더링 오류까지 복구한다는 의미는 아닙니다.

새 경로 처리는 가상 레지스트리와 임시 파일로 검사했습니다. 이력 변경과 파일 열기 실패는 주입 오류·저장 재열기 검사로 확인했습니다. 이 검사는 실제 Windows 연결 변경, 새 실행 파일의 화면 확인, 사용자 프로젝트의 렌더링이나 실물 장비 동작을 대신하지 않습니다. 실제 앱·업데이터 화면과 새 버전의 파일 열기를 확인한 뒤 공개·설치 검증을 마무리합니다.
