# 검증 기록 · 2.1.2 Native

## 업데이트 GUI 누락 수정

2.1.1 업데이터의 파일 교체 시험은 통과했으나, 빌드 환경의 Tcl 초기화 실패로 PyInstaller가 tkinter를 제외한 문제가 실제 사용에서 발견됐습니다. 2.1.2는 Tcl/Tk 라이브러리와 데이터 파일을 함께 포함합니다. `Updater.spec`는 Tcl 검사·tkinter 모듈·init.tcl 포함 검사 중 하나라도 실패하면 빌드를 중단합니다.

수정한 배포 EXE에 `--gui-smoke <report.json> --install-dir <existing-install>`을 실행해 실제 업데이트 창 표시, 버튼 활성화, Tcl 8.6.12 로드, 정상 종료를 확인했습니다. 이 시험은 네트워크나 실제 업데이트를 실행하지 않습니다. 수정 EXE의 임시 복사·자체 교체·사용자 프로젝트 보존·정리 시험도 다시 통과했습니다.

## 기존 설치 업데이트

`tests/test_updater.py`는 기존 폴더 교체, 변경 없는 라이브러리 재사용, 이전 프로그램 파일 삭제, 사용자 프로젝트·편집 예제 보존, SHA256 오류, Windows 경로 탈출, ZIP 파일 목록 오류, 교체 중 오류 롤백, 중단된 교체 복구, 용량 부족, 다운그레이드 거절, 통신 실패 정리, 사용자 파일 충돌, 반복 적용, 소유하지 않은 임시 폴더 보존을 검증합니다.

2.1.1 전체 Python 테스트 **157개 통과**. 추가 Qt 테스트는 미완료 스케치 중 업데이트 비활성화, 저장 취소 시 업데이트 취소, 저장 확인을 반복하지 않는 종료를 확인했습니다. 약 9 MB의 배포용 업데이트 EXE를 실제 실행해 자체 임시 복사, 실행 파일 교체, 프로젝트 보존, 이전 라이브러리 삭제, 임시 실행 파일 자동 삭제도 확인했습니다.

2026-09-23, Windows 64비트 / Python 3.12.14 / Qt 6.10.2 / VTK 9.6.2 / CadQuery 2.8.0 / Open CASCADE 7.9.3.

## 자동 시험

- Python 시험 130개 통과. 기존 110개와 Qt 스케치 상호작용 15개, 조립/시편 작업 흐름 5개입니다.
- 820×560, 1024×600, 1280×720, 1600×900 논리 픽셀 창에서 종료 버튼이 보이는지 검사했습니다. 별도 `QT_SCALE_FACTOR=1.5` 실행에서도 스케치 회귀 시험을 확인했습니다.
- 실제 Qt 마우스 클릭으로 끝점 선택, 같은 선의 두 점 선택, 추천 위치 클릭과 점-곡선 구속, 열린 스케치 종료, 단위, 치수 편집, 전체 선택/삭제/실행 취소를 검사했습니다. Windows의 전역 커서를 움직이는 대신 앱 자신의 위젯에 Qt 마우스 이동 이벤트를 보내 추천점 표시를 검사합니다.
- 면 조인트의 두 면 위치/법선 정렬, 회전된 부모 좌표계, 부모 높이 변경에 따른 자식 이동, 프로젝트/기록 재열기를 검사했습니다.
- 로봇 링크 치수 변경 후 핀 위치·길이 갱신과 다른 부품 보존, 관절 각도 변경 후 하위 링크/핀 전파, 잘못된 시편 치수 거부와 수정 후 회복을 검사했습니다.
- Starlette anyio 별칭 및 VTK SetCells의 폐기 예정 경고가 있습니다. 시험 실패는 아닙니다.

## 배포 EXE 시험

`PromptCADStudio.exe --smoke-test report.json`은 앱 자체의 Qt 위젯/이벤트 루프와 네이티브 OpenGL을 실행합니다.

1. 작은 창에서 클릭으로 열린 선 작성 → 상단 종료 버튼 → 독립 스케치 저장/재열기.
2. 끝점 클릭 선택 → 사각형/원 작성 → 추천점 표시 → 닫힌 스케치 종료 → 별도 돌출.
3. 정확한 체적 18,571.681469 mm³ 비교 → OpenGL 면 피킹 → 면 스케치 저장 → 재열기 → 포켓 절삭.
4. 선택 면/이전 피처/스케치 도구 작업 기록 → CAD JSON 재열기 → STEP 내보내기 → 실행 취소/다시 실행.
5. 5부품 로봇과 4개 조인트 → 관절 구동 미리보기 → 하위 링크 회전 검사 → 자세 적용.
6. 기존 로봇을 보존하며 평판 시편 치수 미리보기/적용 → 단면적/그립 길이 표시.
7. 두 부품의 실제 면 좌표계를 사용한 조인트 미리보기/적용 → 간격 검사 → 면 조인트와 전체 작업 기록 저장/재열기.
8. 이전 포켓 설계로 타임라인 복원 → OpenGL 렌더링 검사.

결과는 [네이티브 시험 보고서](docs/native-smoke-report.json)에 보존합니다. 이미지들은 앱 자신의 Qt 위젯 캡처에 해당 VTK 자식 창의 실제 프레임버퍼를 같은 위치에 넣은 테스트 화면입니다. 외부 데스크톱 앱의 화면을 수집하지 않습니다. 외부 컴퓨터 제어로 모든 메뉴/파일 대화상자를 조작한 시험은 아닙니다.

## 범위

OpenAI 유료 요청, 실제 Ollama 추론, Autodesk 내부 F3D/IPT 변환은 실행하지 않았습니다. F3D/IPT 변환 패키지는 STEP 솔리드 전달용이며 Autodesk 타임라인을 재구성하지 않습니다.

면 조인트는 평면 중심/법선 또는 형상 기준점을 사용합니다. 영구 위상 추적, 폐루프 조립, 동역학, 모터 제어, 자동 충돌 회피와 시험 규격 인증은 지원하지 않습니다. 편집 중 아직 종료하지 않은 스케치의 충돌 복구는 지원하지 않습니다.
