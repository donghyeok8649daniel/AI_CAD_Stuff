# BOM 보고 설계

메인 AI 패널의 **BOM 보고 설계…** 또는 **파일 → BOM 보고 설계…**에서 부품표를 가져옵니다. CSV, TSV, TXT, Markdown 표, XLSX와 표 붙여넣기를 지원합니다. XLSX에 여러 시트가 있으면 시트 이름을 지정합니다. 셀 수식은 계산하거나 실행하지 않으며, 값으로 바꿔 가져와야 합니다.

다음과 같은 열을 사용할 수 있습니다. 한 물리 부품은 수량 하나에 대응합니다. 길이 단위는 명시하며 가져온 값은 mm로 변환합니다.

```csv
부품명,수량,단위,길이(mm),너비(mm),두께(mm),역할,모델,구매링크
지지판,2,ea,80,60,4,구조,,
제어 보드,1,ea,,,,전장,4 Model B,
```

1. 파일 또는 붙여넣은 표를 읽고 수량·정확한 제품 모델·역할·치수를 검토합니다. 외형 치수와 구멍 위치, 보드 동작 정격은 서로 다른 정보입니다. `80×60`처럼 축이 불분명한 치수는 직접 축별로 입력합니다.
2. 카탈로그가 정확히 일치하는 제품 후보를 보여주면 직접 선택합니다. 제품군·묶음 상품·비슷한 이름을 하나의 정확한 SKU로 취급하지 않습니다. 빈 값은 확인 필요 항목으로 남습니다.
3. **BOM 저장**으로 프로젝트에 반영합니다. 준비된 AI 요청에 필요한 조립 동작, 장착 간격, 공차를 덧붙인 뒤 **초안 생성**을 누릅니다. Codex, Ollama 또는 OpenAI가 필요합니다.
4. AI가 `bom_bind` 작업으로 생성한 실제 CAD 부품을 원본 BOM 행에 연결합니다. **미리보기 → BOM 대조**에서 실제 수량, 명시 모델·치수의 일치 여부, 연결된 부품과 확인 항목을 봅니다. 불일치는 자동 수정 대상이며, 수정 전에는 적용할 수 없습니다.
5. 이미 만든 부품은 여러 개를 선택한 뒤 **파일 → 선택 CAD 부품을 BOM 행에 연결…**로 연결합니다. 연결은 부품을 복제하거나 치수를 변경하지 않습니다. 기존 제품 정보와 사용자 색상은 보존하고 충돌하는 제품 정보는 불일치로 표시합니다.

BOM과 행 연결, 원본 파일명·SHA256, 검토한 값은 `.pcad`에 저장되며 작업 기록과 실행 취소·복원에 포함됩니다. 이전 `.cad.json`도 읽습니다. 원본 표 파일을 덮어쓰지 않습니다. 지원 형상의 최종 외형은 CAD 커널로 확인하고, 제공하지 않은 스펙이나 검증할 수 없는 직경은 확정하지 않습니다. 유효한 개념 형상을 적용해도 미정 항목은 남습니다. BOM 대조는 제조사 실물 형상·강도·조립 가능성 인증이 아닙니다.

파일은 2 MB, 200행, 40열까지 검토할 수 있습니다. AI의 한 초안은 최대 64개 작업·32개 새 몸체 범위입니다. 큰 부품표를 한 번에 완성했다고 표시하지 않으며, 필요한 범위로 부품표를 나누어 검토하세요. 부품표 속 문장·링크는 참고 데이터로만 전달하고 수식·매크로·코드는 실행하지 않습니다.

큰 BOM이 한 번의 새 부품 한도를 넘거나 이미 연결된 부품의 제품/전장 등록이 원본 BOM과 충돌하면 AI 요청 전에 필요한 조치를 표시합니다. 불가능한 검증을 무한 재요청하지 않습니다. 제품 정보는 부품의 **제품 스펙 / 구매 링크**에서, 전장 모델은 **전장 등록**에서 확인하세요.
