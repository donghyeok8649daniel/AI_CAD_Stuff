# Prompt CAD Studio v3.0.2

Select an existing link in Joint limits / Motion links and use **Update selected motion link** to edit it. Ratio, offset and joint-limit fields retain the precision of saved numbers. A 5 mm/rev screw relation such as `5/360` is no longer rounded to five decimal places. Enter numeric values; scientific notation is supported.

Confirming an unchanged link or cancelling keeps the design values and journal intact. Explicit edits are included in project saves and journal restoration.

This update fixes input and editing behavior. It does not certify bearing, coupling or motor capacity, structural strength, firmware builds or hardware operation. The fatigue tester's physical redesign candidate is delivered separately for review.
