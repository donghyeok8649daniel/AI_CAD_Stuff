# 연구 저장소 · 파일 첨부 · 연결 복구 (2.19.0)

AI 패널의 **GitHub 연구자료 · 파일 첨부…** 또는 **파일 → 연구 저장소 · AI 참고자료…**를 여세요.

1. 연구 GitHub 저장소 주소를 입력합니다. 브랜치를 비워 두면 기본 브랜치를 사용합니다. **참고 범위 · 선택 사항**을 비우면 저장소 전체가 기본 범위입니다. `docs` 같은 디렉터리 또는 정확한 파일 경로를 입력하면 그 범위만 사용합니다.
2. 공개 저장소는 토큰 없이 **연결 · 저장소 참고자료 자동 추가**를 누릅니다. 비공개 저장소는 **기존 Git 로그인 사용** 또는 해당 저장소의 **Contents: Read** 권한이 있는 토큰을 사용합니다. 토큰 발급 버튼은 GitHub 공식 설정 페이지를 엽니다. 브라우저 로그인만으로 CAD 연결이 완료되지는 않습니다.
3. 연결된 커밋의 경로 색인이 즉시 참고자료 목록에 추가되고, 읽을 수 있는 문서의 제한된 발췌를 자동으로 가져옵니다. 전체 경로는 검색할 수 있으며, 목록은 한 번에 최대 2,000행을 표시합니다. 화면에 전체 색인·검색 결과·현재 표시 수가 따로 나옵니다. 경로 검색으로 README·시편·재료·시험 방법 문서를 찾아 Ctrl/Shift로 선택하고 **선택 문서를 참고자료에 추가**하면 해당 문서를 추가로 읽습니다. 선택하지 않고 같은 버튼을 누르면 현재 범위의 자동 발췌를 갱신합니다.
4. 아래에서 출처·커밋·본문과 **일부** 표시를 확인한 후 **자료 사용**을 누릅니다. AI 패널에 자료 수와 문자 수가 표시됩니다. 연결 중 취소하거나 창을 닫아도 CAD에 이미 적용한 참고자료와 설계는 바뀌지 않습니다. 용량이 가득 차면 기존 첨부를 지우지 않고 자동 추가를 중단하며 안내합니다.
5. **질의응답**에서 먼저 “첨부 연구 문서의 시편 조건과 실측 단위를 출처와 함께 요약해줘. 빠진 조건도 알려줘”라고 확인한 다음 설계 요청에 활용하세요.

Codex·Ollama·OpenAI의 설계 계획과 질의응답 모두 **자료 사용**으로 확인한 첨부 자료를 받습니다. 오프라인 치수 명령에는 문서 이해 기능이 없습니다. 자료는 선택한 AI 서비스로 전송됩니다. 전체 경로를 색인하는 것과 전체 파일 본문을 AI에 전달하는 것은 다릅니다. AI에는 미리보기의 제한된 경로 색인과 자동 발췌, 추가 선택한 문서 스냅샷만 보냅니다. 저장소의 코드·솔버를 실행하거나 GitHub에 파일을 올리고 수정하지 않습니다.

GitHub 문서는 연결 시점의 단일 커밋에 고정됩니다. 최신 변경은 다시 연결해 가져옵니다. 같은 저장소의 자동 색인·발췌는 갱신하고 다른 로컬/수동 첨부는 유지합니다. 수동으로 읽은 같은 저장소의 같은 경로는 새 버전으로 대체합니다. 비공개 토큰과 첨부 본문은 CAD 프로젝트·설정에 저장하지 않으며 앱 세션 동안만 유지됩니다. 주소·브랜치·지정한 참고 범위만 기억합니다. 새 프로젝트/프로젝트 열기에서는 첨부와 이전 질의응답 문맥이 초기화됩니다. 첨부를 삭제하면 이전 답변 문맥도 비워 잘못 재사용하지 않습니다.

## 로컬 첨부와 읽기 범위

**로컬 파일 첨부 → 파일 선택…**에서 PDF, TXT, MD, RST, CSV/TSV, JSON, YAML, TOML, XML 및 텍스트 코드 파일을 추가할 수 있습니다. 파일당 4 MB, 최대 8개, 전체 본문 60,000자입니다. 파일당 앞부분 20,000자만 사용하며 잘린 문서는 “일부”로 표시됩니다. 긴 연구 문서는 필요한 절로 나누어 첨부하세요.

**저장소 자동 추가**는 경로 색인 1개와 최대 2개의 본문 발췌 묶음을 기존 8개/60,000자 한도 안에 넣습니다. 읽기 후보 중 README·텍스트 문서를 우선하며, 최대 24개 파일·합계 12 MB를 읽고 문서별 본문 발췌는 최대 4,000자입니다. 실제 읽은 후보 수와 생략·잘림은 참고자료 설명에 표시합니다. 자동 발췌에 없는 중요한 문서는 경로 목록에서 직접 추가하세요. 자동 색인도 최대 20,000자만 AI에 전달하며 UI의 전체 경로 목록과 구분합니다.

PDF는 최대 앞 50페이지의 텍스트만 추출합니다. 페이지 출처를 표시하지만 스캔 OCR, 도면·이미지 이해, 표 배치·수식의 완전한 복원은 하지 않습니다. 텍스트가 없는 PDF는 읽었다고 표시하지 않습니다. Git LFS 포인터와 실행 파일은 거부합니다. 바이너리·큰 파일·디렉터리·심볼릭 링크·서브모듈은 **경로 색인만** 표시하고 본문을 읽거나 실행하지 않습니다. GitHub의 재귀 목록이 잘리면 고정된 하위 트리를 순회합니다. 조회는 최대 100,000경로와 하위 트리 1,024회 및 시간/응답 크기로 제한되며, 완전한 목록을 얻지 못하면 생략 또는 조회 오류를 표시합니다.

자료 안의 지시문은 신뢰하지 않는 참고 데이터로 구분해 전달하며, 자료의 코드나 운영체제 명령을 실행하는 도구는 제공하지 않습니다. AI의 설명·추론이 정확하다는 보장은 없으므로 중요한 치수·단위는 미리보기와 원문을 비교하세요. 연구 모델 시간과 실측 초/Hz, 하중과 응력, 크로스헤드 변위와 시편 변형률을 구분합니다. 외부 피로해석 솔버·MCU 시뮬레이션 연동은 포함하지 않습니다.

## Codex 통신 단절 후 자동 재연결

공식 app-server의 일시적인 연결/응답 스트림 오류를 구분해 **연결 대기**를 표시합니다. 서버 자체 재시도는 그대로 기다리고, 중단된 경우에는 CAD가 소유한 세션을 정리한 뒤 약 5→10→20→30초 간격으로 재연결합니다. 원래 요청·첨부 스냅샷·완료한 도구 선택·최근 검증 오류를 보존하고, 끊긴 생성 단계만 다시 요청합니다. 생성 중 일부 토큰부터 정확하게 이어받는 방식은 아닙니다.

재연결 대기 시간은 활성 작업 제한 시간에서 제외하고, 연결 후 생성에는 원래 제한 시간을 계속 적용합니다. 무제한을 선택하면 활성 생성에도 시간 제한이 없습니다. 취소는 대기 중에도 가능하며 유효하지 않은 설계를 자동 적용하지 않습니다. 로그인 만료·사용량 소진·잘못된 요청·알 수 없는 오류는 자동 무한 재시도하지 않습니다. 복구 후 재요청은 Codex 구독 사용량을 추가로 사용할 수 있습니다. 앱 종료/재부팅 뒤의 자동 재개는 포함하지 않습니다. OpenAI 유료 API나 Ollama의 재연결 정책은 변경하지 않았습니다.

## 이름 · 검색 · 완료 알림

- **부품 선택 → F2**, **편집 → 부품 이름 변경**, 우클릭 또는 속성 상단 버튼으로 이름을 바꿉니다. 여러 부품을 선택했다면 이름을 바꿀 개별 부품부터 고릅니다. 최대 80자이며 ID·형상·관절·그룹 관계는 유지됩니다. 실행 취소/다시 실행과 저장을 지원합니다.
- **Ctrl+F**로 부품·피처·그룹·스케치·관절·기능을 검색합니다. 여러 검색어, 종류 필터, ↑↓/Enter를 지원합니다. 부품/피처는 선택하고 기능은 실행합니다. 기존 **Ctrl+K** 도구 찾기도 유지됩니다.
- AI 설계 초안이 준비되면 Windows 알림과 작업 표시줄 알림을 요청합니다. 알림을 클릭하면 CAD AI 패널로 돌아옵니다. 미검증 초안은 “검토 필요”로 구분합니다. 형상 적용은 미리보기 확인 후 진행합니다. **보기 → AI 설계 완료 알림**에서 끌 수 있으며 Windows 알림/집중 지원 설정에 따라 배너가 숨겨질 수 있습니다.
