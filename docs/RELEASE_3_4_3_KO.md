# Prompt CAD Studio 3.4.3 · 같은 프로젝트 다시 열기

프로젝트의 전체 작업기록 검증은 매번 유지합니다. 전체 파일 바이트, 입력 설계, 앱 빌드, 네이티브 런타임과 표시 품질이 일치하고 앱이 만든 캐시의 무결성이 확인될 때만 이전에 끝낸 화면·간섭·구속 계산 결과를 재사용합니다. 파일명이나 수정 시각만으로 판단하지 않습니다.

캐시는 사용자 설정 폴더의 별도 영역에 보관하며 로그인·Codex 인증 키와 분리된 무결성 키를 사용합니다. 코드나 pickle을 읽거나 실행하지 않습니다. 파일·부품·전선 제외 태그·빌드·표시 품질 변경, 손상·잘림·알 수 없는 캐시에서는 기존 전체 계산을 다시 수행합니다. 캐시 오류가 정상 프로젝트 열기를 막지 않습니다.

캐시는 최대 4개·총 256MiB 범위로 관리합니다. 개별 캐시 크기 초과는 캐시를 만들지 않는 조건이며 프로젝트·부품 수·이력 제한이 아닙니다. 원본 프로젝트와 전체 기록을 변경하지 않습니다. 조립 계산으로 정리된 설계도 같은 결과와 함께 보존하며, 원본 파일의 모든 기록은 여전히 먼저 검증합니다.

수동 저장이 성공하면 현재 설계와 일치하는 검증된 화면 결과도 저장된 새 파일 바이트에 연결합니다. 저장·닫기·재열기에도 적용되며, 일치하는 화면 결과가 없거나 캐시 기록에 실패하더라도 완료된 프로젝트 저장을 실패로 바꾸지 않습니다. 이름·색상만 바뀐 경우에는 저장된 최신 이름과 색상을 사용합니다.

처음 여는 새 파일, 바뀐 파일, 새 앱 빌드와 새 표시 품질에서는 전체 계산이 필요합니다. 다시 열기 캐시는 native BREP를 디스크에서 복원하지 않으므로 첫 형상 편집·내보내기에서 원본 형상을 계산할 수 있습니다. 제작·강도·공차·장비 안전 승인을 뜻하지 않습니다. 실제 속도·Windows 화면·배포·설치는 별도 검증 기록을 따릅니다.
