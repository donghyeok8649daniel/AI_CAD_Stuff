# v2.22.0 · AI 배선과 CAD 부품 대응

상단 **선택 부품 색상** 바로 옆의 **회로도** 버튼으로 실물 배선 작업창을 엽니다. 기존 전장 작업창과 회로 기호 보기도 사용할 수 있습니다.

## AI로 실제 배선 변경

회로 부품이나 핀을 선택하고 **AI 배선 요청…**에 원하는 변경을 입력합니다. 예를 들어 “선택한 Raspberry Pi의 GPIO17을 등록된 드라이버 AIN1에 전선으로 연결해줘. 기존 전원과 CAD 형상은 유지해줘”라고 요청할 수 있습니다. 실제 모델과 등록된 단자를 기준으로 지정하세요.

요청은 선택 부품·핀의 ID와 함께 메인 AI 입력창에 준비됩니다. **초안 생성**을 누르면 선택한 Codex/Ollama/API가 설계 작업을 시작합니다. 편집 중인 회로도 안에서 요청했다면 바깥 창까지 **저장 · AI 요청 준비**로 확정한 뒤 전달됩니다. 취소하면 편집과 대기한 요청을 함께 버립니다.

AI는 기존 회로 부품과 CAD 부품의 대응, 실제 끝점을 가진 전선 추가·편집·삭제를 작업할 수 있습니다. 초안 미리보기의 **배선 / CAD 부품 대응** 탭에서 변경표와 **변경 전 / 후** 배선도를 확인한 뒤 적용합니다. 적용 전에는 원본이 바뀌지 않으며, 적용 후에는 작업 기록·실행 취소·다시 실행·프로젝트 저장에 남습니다. 전장만 바꾸는 작업은 그대로인 CAD 형상을 재사용합니다.

## 기존 회로 부품과 CAD 연결

회로 부품을 선택한 뒤 **CAD 대응 설정…**에서 실제 몸체를 이름·ID로 찾습니다. **대응 연결 · 미리보기 → 대응 변경 저장**으로 연결하면 기존 회로 ID·핀·전선·제품 자료를 유지합니다. 노란색 옵션을 켜지 않으면 사용자 색상도 유지합니다. **CAD 대응만 해제**는 회로와 전선을 지우지 않습니다.

CAD 부품 선택은 대응 회로 부품 선택과 연결됩니다. 회로의 **CAD 부품 보기**로 실제 형상을 찾아 확대할 수 있습니다. 스케치·변수·가져온 메시를 참조하는 CAD 부품도 전체 설계 맥락을 보존합니다. [상세 사용법](ELECTRICAL_LINKS_KO.md) · [English](ELECTRICAL_LINKS_EN.md).

## 모터 목록 확대

공식 자료를 확인한 DC 기어모터·스테퍼·DYNAMIXEL TTL/RS-485·피드백 액추에이터·Hall BLDC **12개 모델**을 추가했습니다. 기존 모델을 포함한 **15개 외부 단자도**를 추가해 전체 전장 목록은 **110개**, 등록 가능한 항목은 **68개**입니다. 모델별 권선·모터 전원·엔코더·Hall·피드백·통신 단자를 구분합니다. [제품별 목록과 출처](MOTOR_CATALOG_2_22_0_KO.md).

배선 연결을 저장하는 것과 실제 모터 구동 검증은 다릅니다. 미정인 소비전류·전선 길이·단면적은 임의로 채우지 않으며, 치수가 미정인 새 전선은 연결을 저장하고 DC 계산은 보류합니다. 내부 ESC/FOC·펌웨어·하드웨어를 실행하거나 시험기 정격을 승인하는 기능은 이번 변경에 포함되지 않습니다. [AI 작업 형식과 검토 범위](AI_WIRING_2220.md).

## 회로 편집 안정성

이미 전선이 붙은 핀을 단순 노드 재지정으로 옮겨 기존 케이블과 어긋나게 만드는 작업을 차단합니다. 전선을 선택해 끝점을 편집하거나 먼저 삭제하세요. 정상적인 분기 연결과 이전 노드 방식 회로는 유지합니다.

회로도를 다시 그릴 때 핀 그래픽의 역참조와 화면 경계 계산을 정리하고, 창 크기 조정 시 배선 그래픽을 다시 만들지 않도록 했습니다. 숨긴 전선 기호의 위치 때문에 미리보기가 지나치게 축소되던 문제도 수정했습니다. 회로 창 저장·취소·반복 종료와 실제 Qt 객체 삭제 후 메모리 정리를 검증합니다.

**회로도 크게 보기**에서 부품을 선택하거나 배선을 갱신해도 숨긴 CAD 패널이 다시 나타나지 않습니다. **CAD 부품 보기**로 설계 화면으로 돌아가면 이전 패널 표시 설정을 복원합니다.

## 설치와 기존 작업

처음 설치할 때는 릴리스의 `PromptCADStudioUpdater.exe`를 실행합니다. 기존 사용자는 작업을 저장하고 CAD 창을 모두 닫은 뒤 같은 업데이트 프로그램으로 기존 설치 폴더를 갱신합니다. 사용자 프로젝트와 설정은 보존합니다. 실행 중인 CAD 창을 자동 종료하지 않습니다.

검증 집계는 배포 패키지의 [native2220-validation.json](native2220-validation.json)에 기록됩니다. 오프라인 AI 계획으로 실제 전원·제어·모터 핀 전선 생성과 적용 전 비교, 저장·취소·실행 취소·다시 실행을 검사하며, 유료 AI 호출과 하드웨어 동작은 실행하지 않습니다.
