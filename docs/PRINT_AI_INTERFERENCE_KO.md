# v2.10.0 · 간섭 예방, 3D 프린팅, AI 대화와 비교

## 관절과 부품 간섭

뷰포트 위 **간섭 N · 확인** 버튼은 부품의 체적이 실제로 겹칠 때 나타납니다. 누르면 간섭 부품을 표시하고 이름과 겹친 체적(mm³)을 보여줍니다. 숨긴 부품과 그룹 안의 부품도 검사합니다. 그룹은 선택 묶음이며 강체 결합이나 하나의 솔리드가 아닙니다. 면이 닿기만 하고 체적이 겹치지 않는 접촉은 체적 간섭으로 세지 않습니다.

부품 배치·관절 구조·프린터 보정 등의 미리보기에서 새로 생기거나 커진 간섭은 적용할 수 없습니다. 기존 설계의 간섭을 줄이는 수정은 허용하지만 남은 간섭을 경고합니다. 수동 기본 편집·기존 파일의 간섭도 뷰포트 경고에서 확인할 수 있습니다. 불리언 합집합/교집합을 위해 보관한 도구 몸체는 검사 목록에는 남지만 조립 간섭 차단 대상과 구분합니다.

**조립 → 관절 구동**에서 현재 자세부터 입력 자세까지 중간 자세를 검사합니다. 독립 관절과 연결/폐루프 관절의 끝점 변화량을 기준으로 최대 2° / 0.5 mm 간격을 정합니다. 충돌하면 최초 발견 자세를 빨간 부품으로 미리 보여주고 적용을 막습니다. **마지막 확인 자세로 이동**을 누르면 그 자세를 다시 검사합니다. 시작 자세에 이미 간섭이 있으면 먼저 장착 위치·구멍·여유를 수정해야 합니다. 설정된 관절 운동 한계도 그대로 지킵니다.

이는 유한 개 자세의 검사이며 연속 운동 전체의 수학적 보증이 아닙니다. 얇은 장애물, 급격한 폐루프 운동, 변형과 제작 오차는 별도 검토가 필요합니다. 한 번에 1,440 구간보다 큰 이동은 건너뛰지 않고 나누어 이동하도록 안내합니다. 지형이나 부품 치수를 수정한 뒤에는 다시 검사해야 합니다.

새 실제 회전 관절의 기본값은 회전 지름 여유 0.2 mm, 하우징/부시 삽입 지름 여유 0.2 mm, 플랜지·칼라/축 삽입 지름 여유 0.2 mm, 축 방향 여유 0.2 mm입니다. 입력한 지름 여유 0.2 mm는 한쪽 반경 0.1 mm입니다. 켜진 프로젝트 프린터 보정은 여기에 추가로 적용되므로 미리보기의 실제 치수를 확인하세요. 기존 설계의 치수를 자동으로 바꾸지 않습니다. 핀/부시 삽입과 출력은 가능한 형상으로 분리하지만 체결 나사·키·베어링 선정, 하중 등급과 모든 조립 순서를 자동 설계/인증하지는 않습니다.

## 3D 프린팅 모드

상단 작업 공간에서 **3D 프린팅**을 선택하거나 **파일 → 3D 프린팅 · STL 미리보기**를 엽니다.

1. 출력할 부품을 체크합니다. 처음에는 선택 부품, 선택이 없으면 전체 부품을 체크합니다.
2. 출력용 X/Y/Z 방향과 프린터 출력 영역(mm), 부품 간격을 입력합니다. 부품은 조립 위치에서 분리되고 각각 Z=0 바닥에 놓입니다. 회전은 부품 원점 기준의 출력용 방향으로 선택 부품 모두에 적용합니다. 서로 다른 방향이 필요하면 나누어 내보내세요.
3. 미리보기에서 배치와 부품을 확인합니다. 출력 영역을 벗어나거나 겹치면 저장 버튼이 비활성화됩니다. 행 단위 배치이며 최적 네스팅은 아닙니다.
4. STL 메시 오차를 선택하고 **이 미리보기로 STL 저장**을 누릅니다. 미리보기와 같은 솔리드에서 하나의 STL을 생성하며 원본 설계·관절·작업 기록을 변경하지 않습니다. 부품별 별도 파일은 기존 **부품별 내보내기**를 사용할 수 있습니다.

STL 자체에는 단위 메타데이터가 없으므로 슬라이서에서 **mm**로 불러오세요. 프로젝트에서 이미 적용한 프린터 여유를 다시 더하지 않습니다. 서포트·인필·레이어·G-code는 슬라이서에서 설정하며 이 모드는 슬라이서나 강도/최소 벽두께 인증 도구가 아닙니다.

## AI 질문과 적용 전 비교

AI 패널 상단에서 **설계 / 질의응답**을 전환합니다. 질의응답은 일반 질문이나 현재 설계에 대한 설명을 받고, CAD 형상을 변경하지 않습니다. Ollama·Codex·OpenAI 연결을 사용할 수 있으며 연결 방식의 사용량/요금이 그대로 적용됩니다. 최근 5회 질문·답변 문맥을 유지하며 모델이나 제공자를 바꾸면 새 문맥으로 시작합니다. 질문 당시의 설계 요약을 사용하고 자산 바이너리나 API 키를 문맥에 넣지 않습니다. 웹 검색 기능은 없습니다.

설계 초안은 **미리보기 / 적용**에서 **변경 전 / 변경 후**를 번갈아 확인하고 작업 요약을 읽은 뒤 적용합니다. 미리보기 닫기는 원본을 바꾸지 않습니다. 생성 이후 원본을 수정했다면 이전 초안은 적용하지 않고 다시 생성해야 합니다. 새 부품 간섭이 있으면 AI에 수정 원인을 전달하며, 최대 3회 형상 검증을 통과하지 못하면 현재 설계를 보존하고 실패를 알립니다. AI 생성 품질이나 실제 제작 가능성을 보증하는 기능은 아닙니다.

## Codex 연결 체크

Codex 연결 창에서 기존 로그인을 확인하고 사용할 모델을 선택하거나, AI 패널의 **Codex 연결 상태 확인**을 누르세요. 실제 계정 조회와 선택 모델 확인을 통과하면 초록색 **✓ Codex 연결 완료**가 나타납니다. 저장된 모델 이름만으로 체크 표시를 띄우지 않습니다. 확인 중/실패/재확인 필요에는 체크 표시가 없습니다. 앱을 다시 열면 다시 확인하며, 상시 연결이나 남은 사용량 보증을 뜻하지는 않습니다. 연결 조회는 설계 생성을 요청하지 않습니다.

## 격자와 축 모양

**보기 → 격자 · 축 색상 / 밝기 / 선 굵기**에서 격자 색, X/Y/Z축 색, 밝기(0~100%), 선 굵기(0.5~5 px)를 고릅니다. 스케치와 3D 화면에 즉시 반영하며 **모양 저장**으로 다음 실행에도 유지합니다. **취소**하면 열기 전 모양으로 돌아가고 **기본 모양으로**로 초기값을 복원할 수 있습니다. 표시/숨김과 스냅 설정은 별개로 유지합니다.


## 축 / 구멍 동심 정렬
조립 → **관절 축 · 구멍 동심 정렬…** 또는 관절 속성의 같은 버튼을 사용합니다. 기존 회전/원통 관절을 고른 뒤 기준 부품의 구멍 원통과 이동 부품의 축 원통을 선택하세요. 목록에는 실제 지름, 면 번호, 부품 좌표의 원통 시작점이 표시됩니다. 정렬 전 편심 거리와 각도 차, 정렬 후 형상·간섭을 확인하고 적용합니다. 실행 취소할 수 있습니다.

실제 원통의 중심선을 조인트 기준으로 저장하므로 기울어진 조립과 회전 뒤에도 같은 축을 사용합니다. 축 방향 위치/각도 유지가 기본이며 해제하면 간격·각도를 입력할 수 있습니다. 기존 운동 한계는 보존합니다. 연결된 하위 부품은 함께 이동하며, 잘못 배치된 칼라·다른 체결부까지 자동으로 재설계하지는 않습니다. 새 간섭은 적용을 막습니다. 잘린 원통, 면이 모호해진 형상, 폐루프 수동/모션 종속 관절은 재선택 또는 연결 편집이 필요합니다.

AI가 만든 구멍 있는 면에서 면적 중심과 외곽 치수 중심의 차이 때문에 축이 약 1.5 mm 밀리는 결함을 재현했습니다. 새 AI 구멍/돌출/포켓은 **선택 면의 경계 상자 중심**을 좌표 원점으로 사용합니다. 실제 원통 선택으로 기울어진 관절을 연결하며, 존재하지 않는 중심선/지름을 지정하면 검증에서 거부합니다. 이미 저장한 설계는 조용히 형상을 바꾸지 않습니다. 기존 편심은 위 정렬로 검토하거나 원래 축 스케치 중심을 편집하세요.
