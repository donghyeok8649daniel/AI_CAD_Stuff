# 로컬 AI에서 기대할 수 있는 설계 수준

현재 앱의 qwen3:8b는 **치수가 명시된 단순 부품의 초안을 만드는 보조 도구**를 목표로 합니다. 물건 이름만으로 제조 가능한 완성 설계를 만드는 수준으로 검증되지 않았습니다. 복잡한 로봇의 기구 배치, 베어링·체결부 선정, 공차 누적, 강도·수명까지 스스로 책임지는 설계자로 기대하면 결과가 크게 부족할 수 있습니다.

| 요청 | 현재 기대 수준 |
|---|---|
| 외경·내경·폭이 정해진 바퀴, 축, 판, 구멍, 단순 브래킷 | 검토할 수 있는 초안 생성 목표. 형상 및 치수 확인 필요 |
| 기존 부품의 지정 치수, 위치, 색 변경 | 제한된 변경에서 실측 성공 사례 있음 |
| 몇 개 부품의 간단한 회전/고정 조립 | 실측 성공 사례가 있지만 관절 해석 실패도 있었음 |
| 사진과 같은 외형, 복잡한 곡면, 기어·베어링 시스템 전체 | 품질·성공률을 검증하지 않음 |
| 실제 로봇 전체 설계, 제조 도면·공차·하중·피로수명 자동 결정 | 현재 검증 범위 밖 |

앱이 할 수 있는 작업 도구를 AI가 조합합니다. 도구가 없는 형상은 모델 크기나 대기 시간을 늘려도 만들 수 없습니다. 형상이 CAD 검증을 통과했다는 것은 요청한 기능·외관·제조 적합성까지 맞다는 뜻도 아닙니다. 화면의 CAD 계산 치수와 피처·관절을 직접 확인해야 합니다.

2026-09-24에 이 PC의 **qwen3:8b, CPU 실행**으로 기록한 실제 사례입니다. 표본이 적고 프롬프트가 한정되어 일반 성공률이나 속도 보장을 뜻하지 않습니다.

- 80×50×25 mm, 벽·바닥 2 mm의 열린 상자: 약 **141초**. CAD 체적 19,592 mm³ 확인.
- 기존 부품 색상·위치 편집: 약 **169초**. 형상과 기존 피처 유지 확인.
- 간단한 조립 생성: 약 **223초**, 기존 축 높이 편집: 약 **164초**.
- 다른 조립 요청에서는 반복 수정이 필요하거나 실패한 기록도 있습니다. 성공 사례만으로 “뭐든 설계한다”고 말할 근거는 없습니다.

무제한 대기는 느린 실행이 시간 초과로 중단되는 문제만 줄입니다. 추론 정확도나 설계 품질을 올리는 옵션은 아닙니다. 현재는 치수와 필요한 기능을 명확히 적고, 작은 부품부터 생성한 뒤 기존 부품을 수정하는 용도로 쓰는 것이 적절합니다.

예: “외경 80 mm, 폭 20 mm인 바퀴. 축 구멍 지름 8 mm. 단일 부품으로 만들고 중심 구멍을 관통시켜 줘.” 임의의 물건 이름도 입력할 수 있지만 누락된 치수나 구조는 모델이 추정하므로 결과를 확인하세요.

더 큰 모델과 GPU는 별도로 비교 검증해야 합니다. 이번 2.5.0은 선택·조립 확인·그룹·편집 사용성을 개선한 버전이며, AI 모델 자체의 설계 실력이 향상됐다고 주장하지 않습니다. 피로해석 외부 모듈 연결은 추후 별도 작업입니다.

## Astra / OpenAI 연결 개선

개발판은 **OpenAI API → Astra 모델 선택**으로 `gpt-6-astra`를 지정할 수 있습니다. 공식 API에서 Responses와 구조화된 출력을 지원합니다. 복잡한 요청 해석과 작업 계획은 로컬 8B 모델보다 좋아질 것으로 기대하지만, 이 앱에서 두 모델의 품질을 비교 측정한 결과는 아직 없습니다. 계정별 모델 접근 권한도 별도로 확인해야 합니다. [공식 Astra 모델 문서](https://developers.openai.com/api/docs/models/gpt-6-astra)

네이티브 OpenAI 연결은 기존 설계 전체를 다시 쓰는 대신, 로컬 AI와 같은 CAD 작업 도구로 계획을 실행합니다. 구멍·돌출·색상·조립·변수 등의 작업별 기록과 기존 설계가 유지됩니다. 실제 CAD 형상을 확인하고 실패 시 최대 두 번 수정하여, 한 번의 초안 생성에 최대 네 번의 API 요청을 보냅니다. 사람의 **검증된 초안 적용** 전까지 현재 설계는 바뀌지 않습니다.

추론 강도를 빠르게 / 균형 / 깊게 중에서 선택할 수 있습니다. Astra에는 추론 옵션을 전달하고 기존 `gpt-4.1` 선택도 유지합니다. **AI 최대 대기 / 무제한 / 생성 취소**는 OpenAI와 Ollama 모두에 적용합니다. 무제한은 시간 제한을 없애며 출력 토큰 수와 수정 횟수 제한은 유지합니다.

OpenAI는 유료 API이며 프롬프트와 현재 설계 정보가 전송됩니다. 가져온 파일의 바이너리·표시 메시·전체 작업 기록은 AI 입력에서 제외합니다. 키는 현재 실행 중에만 사용하고 저장하지 않습니다. 취소하면 연결을 닫고 초안을 버리지만 이미 처리된 사용량은 청구될 수 있습니다. API 키나 사용료 동의 없이 개발 중 유료 요청을 보내지 않았습니다. 현재 검증은 모의 통신, 실제 CAD 커널, 네이티브 창의 취소·편집 보존 검사이며 실제 Astra 품질 평가를 대신하지 않습니다.

개발판은 기존 피처의 실제 치수와 현재 선택한 피처도 AI에 전달합니다. 기존 구멍 지름의 축소·확대, 막힌 구멍의 깊이, 돌출 깊이, 필렛·모따기·셸·패턴·나사 치수와 피처 억제를 `edit_feature` 작업으로 수정할 수 있습니다. 새 절삭을 덧붙이지 않고 기존 피처를 다시 계산하므로 구멍을 작게 만드는 요청도 표현할 수 있습니다. 이 도구의 검증은 모의 AI 응답과 실제 CAD 형상 검증이며, 로컬 모델이 모든 문장에서 올바른 피처를 고르는 성공률을 측정한 것은 아닙니다.

변수로 제어되는 치수는 원래 변수를 수정해야 합니다. 연결된 원본 스케치의 지름과 복잡한 기하 구속은 스케치 편집이 필요합니다. 서로 구분하기 어려운 여러 구멍은 피처 이름과 위치를 명시하세요. 기존 면·모서리 참조와 조립을 보존하며, 뒤쪽 피처가 유효하지 않게 되면 전체 초안 적용을 막습니다.

기존 관절의 자세는 `edit_joint` 도구로 수정할 수 있습니다. 현재 각도·이동량·단위·운동 한계와 모션 연결의 구동 관절을 모델에 알려 줍니다. 독립 운동 축만 편집하며 다른 관절에 종속된 축과 폐루프 수동 관절은 계산 결과를 보존합니다. 고정 연결이나 운동 한계를 임의로 해제하는 기능은 제공하지 않습니다. 이 기능 역시 실제 기하·조립 및 모의 통신으로 검증했으며, 자율 로봇의 충돌 회피나 경로 계획을 수행하는 도구는 아닙니다.
