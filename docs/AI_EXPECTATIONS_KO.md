# 로컬 AI에서 기대할 수 있는 설계 수준

현재 앱의 qwen3:8b는 **치수가 명시된 단순 부품의 초안을 만드는 보조 도구**를 목표로 합니다. 물건 이름만으로 제조 가능한 완성 설계를 만드는 수준으로 검증되지 않았습니다. 복잡한 로봇의 기구 배치, 베어링·체결부 선정, 공차 누적, 강도·수명까지 스스로 책임지는 설계자로 기대하면 결과가 크게 부족할 수 있습니다.

| 요청 | 현재 기대 수준 |
|---|---|
| 외경·내경·폭이 정해진 바퀴, 축, 판, 구멍, 단순 브래킷 | 검토할 수 있는 초안 생성 목표. 형상 및 치수 확인 필요 |
| 기존 부품의 지정 치수, 위치, 색 변경 | 제한된 변경에서 실측 성공 사례 있음 |
| 몇 개 부품의 간단한 회전/고정 조립 | 실측 성공 사례가 있지만 관절 해석 실패도 있었음 |
| 사진과 같은 외형, 복잡한 곡면, 기어·베어링 시스템 전체 | 품질·성공률을 검증하지 않음 |
| 실제 로봇 전체 설계, 제조 도면·공차·하중·피로수명 자동 결정 | 현재 검증 범위 밖 |

앱이 할 수 있는 작업 도구를 AI가 조합합니다. 도구가 없는 형상은 모델 크기나 대기 시간을 늘려도 만들 수 없습니다. 형상이 CAD 검증을 통과했다는 것은 요청한 기능·외관·제조 적합성까지 맞다는 뜻도 아닙니다. 화면의 CAD 계산 치수와 피처·관절을 직접 확인해야 합니다.

2026-09-24에 이 PC의 **qwen3:8b, CPU 실행**으로 기록한 실제 사례입니다. 표본이 적고 프롬프트가 한정되어 일반 성공률이나 속도 보장을 뜻하지 않습니다.

- 80×50×25 mm, 벽·바닥 2 mm의 열린 상자: 약 **141초**. CAD 체적 19,592 mm³ 확인.
- 기존 부품 색상·위치 편집: 약 **169초**. 형상과 기존 피처 유지 확인.
- 간단한 조립 생성: 약 **223초**, 기존 축 높이 편집: 약 **164초**.
- 다른 조립 요청에서는 반복 수정이 필요하거나 실패한 기록도 있습니다. 성공 사례만으로 “뭐든 설계한다”고 말할 근거는 없습니다.

무제한 대기는 느린 실행이 시간 초과로 중단되는 문제만 줄입니다. 추론 정확도나 설계 품질을 올리는 옵션은 아닙니다. 현재는 치수와 필요한 기능을 명확히 적고, 작은 부품부터 생성한 뒤 기존 부품을 수정하는 용도로 쓰는 것이 적절합니다.

예: “외경 80 mm, 폭 20 mm인 바퀴. 축 구멍 지름 8 mm. 단일 부품으로 만들고 중심 구멍을 관통시켜 줘.” 임의의 물건 이름도 입력할 수 있지만 누락된 치수나 구조는 모델이 추정하므로 결과를 확인하세요.

더 큰 모델과 GPU는 별도로 비교 검증해야 합니다. 이번 2.5.0은 선택·조립 확인·그룹·편집 사용성을 개선한 버전이며, AI 모델 자체의 설계 실력이 향상됐다고 주장하지 않습니다. 피로해석 외부 모듈 연결은 추후 별도 작업입니다.
