# 2.24.2 · Windows 파일 열기 인자 호환

Windows에서 PromptCADStudio.exe를 직접 선택해 `.pcad`를 더블 클릭하면 아무 창도 나타나지 않을 수 있었던 실행 인자 처리를 수정했습니다. 이전에는 `--open` 없이 전달된 파일 경로를 거부했습니다. 이제 Windows가 전달하는 파일 경로와 기존 `--open` 양식을 같은 프로젝트 열기 경로로 처리합니다. 한글과 공백이 있는 경로도 지원하며, 파일을 두 번 지정하거나 알 수 없는 옵션을 전달하면 오류로 처리합니다.

```text
PromptCADStudio.exe "C:\설계\조립체.pcad"
PromptCADStudio.exe --open "C:\설계\조립체.pcad"
```

파일 연결 등록은 기존 `UserChoice`와 최신 Windows의 `UserChoiceLatest`를 모두 읽어 확인하고 보존합니다. 보호된 선택이나 해시를 직접 수정하지 않습니다. 일반 `.json` 기본 앱과 이전 `.cad.json`의 파일명에 한정된 우클릭 열기는 기존 동작을 유지합니다. [Windows 연결 안내](FILE_ASSOCIATIONS_KO.md).

관련 소스 테스트 43개를 통과했습니다. 새 Windows EXE에 한글·공백이 있는 파일 경로만 전달하여 실제 프로젝트 창과 원통 부품을 확인하고 정상 종료했습니다. 번들 CAD 모듈 210개와 실행 진입점은 검증한 소스와 일치합니다. 레지스트리 값이나 연결 정보 조회만으로 실제 더블 클릭 열기 검증이 완료됐다고 판단하지 않습니다.
