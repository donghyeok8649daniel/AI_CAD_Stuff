# 프린터 여유, 전장부품 자리, 제품 스펙 — 2.9.0

## 프린터별 전체 여유 / 공차

**파일 또는 조립 → 3D 프린터 · 전체 여유 / 공차**를 엽니다. 프로젝트 단위 설정이며 프린터·재료 이름과 보정값을 CAD 파일에 저장합니다. JSON 프로필 저장/불러오기로 다른 프로젝트에서도 재사용합니다.

- 요청한 PLA 시작값: **구멍 지름 +0.2 mm / 축 외경 감소 0 mm / 새 관절 축방향 여유 0.2 mm**. **모든 값 0**으로 초기화할 수 있습니다. 특정 프린터의 측정 정확도를 보증하는 값은 아닙니다.
- 지름 +0.2 mm는 반경 한쪽 +0.1 mm입니다. 축 10 / 구멍 10이면 기본 보정 후 축 10 / 구멍 10.2입니다. 원래 설계에 이미 여유가 있으면 그 위에 추가됩니다.
- 목록에서 적용할 치수를 체크하거나 **전체 연결 / 선택 부품만**을 누릅니다. 원통 외경·내경, 기본 판/링크/브래킷 구멍, 스케치의 명시적 원형 구멍과 독립 원 하나로 만든 절삭 피처를 지원합니다. 전체 연결은 목록에 나온 항목 전체이며 모든 면을 일괄 오프셋하는 기능이 아닙니다.
- 기존 외경 중 하우징 외경 등 줄이고 싶지 않은 항목은 체크하지 마세요. 기본 축 보정은 0입니다.
- **실제 형상 미리보기 / 현재 지름 / 적용 후 지름**을 확인하고 적용합니다. 정상 솔리드와 조립을 확인하지 못하면 적용 버튼이 비활성화됩니다.
- 보정값은 변수 식으로 연결하므로 다시 열어 값을 바꿔도 누적되지 않습니다. 체크 해제는 원래 치수/식을 복원합니다. 보정 사용을 끄면 연결을 유지한 채 보정값만 0으로 계산합니다. Ctrl+Z/Y와 저장/열기도 지원합니다.
- `printer_hole`, `printer_shaft`, `printer_gap`은 프로필 전용 변수입니다. 프린터 창에서 값을 바꾸세요. 일반 치수 식에서 사용할 수도 있습니다. 이름이 같은 기존 사용자 변수가 있으면 덮어쓰지 않고 이름 변경을 요청합니다.
- 프로필이 있는 프로젝트에서 새 **직선 구멍**의 입력 지름은 기준 지름입니다. 구멍 보정을 더한 실제 형상이 미리보기에 표시됩니다. 자리파기/접시머리 구멍은 자동 연결하지 않습니다.
- 새 **실제 관절 구조**의 외경·구멍은 해당 프로젝트 프로필에 연결됩니다. 축방향 여유는 새 관절 생성 시 기본값이며 이미 조립된 관절 위치를 움직이지 않습니다.
- **검토용 지름 허용편차 ±**는 출력 후 허용 오차를 직접 입력하는 값입니다. 초기값 0은 오차가 없다는 인증이 아니라 입력되지 않은 검토값입니다. 새 축/구멍 끼워맞춤 계산창의 상한/하한 기본값에만 사용하고 형상을 바꾸지 않습니다. 기존 공차 검토표는 그대로 유지합니다.
- 출력은 미리보기에 표시된 보정된 실제 형상입니다. STEP/STL을 내보낼 때 다시 보정하지 않습니다. 부품별 ZIP의 `parts.json`에는 프로필과 연결 치수 식도 기록합니다.

나사 피처, 가져온 메시, 연결 복제, 원본 스케치에 연결된 형상이나 구속으로 결정된 스케치는 자동 보정 대상에서 제외합니다. 원본 스케치/변수/나사 여유 도구에서 편집하세요. 슬라이서에서도 같은 구멍 보정값을 사용하면 이중 보정이 될 수 있으므로 최종 시험 출력 치수를 확인하세요. 모든 재료·출력 방향의 수축을 자동 해석하거나 공차 등급을 인증하는 기능은 아닙니다.

## 전장부품 장착 자리

1. 기존 부품의 **평평한 면**을 선택합니다.
2. **모델링 또는 조립 → 전장부품 장착 자리**를 엽니다.
3. 사각/원형 자리, 부품 폭·길이, 파낼 깊이, 전체 여유, 면 위의 위치를 입력합니다. 원형은 폭을 지름으로 사용합니다.
4. 필요하면 **4개 체결 구멍**의 중심 간격과 지름, **전선 통과 구멍**의 위치와 지름을 입력합니다. 각각 독립적으로 켜고 끕니다.
5. 실제 형상 미리보기를 확인하고 적용합니다. 자리 전체가 재료 안에 들어가지 않거나 유효한 절삭을 만들지 못하면 적용하지 않습니다.

자리와 구멍은 일반 스케치 절삭 피처로 저장되어 수정·억제·실행 취소·내보내기가 가능합니다. 체결·전선 구멍은 프린터 보정에 연결됩니다. 사각 자리의 여유는 입력한 자리 치수에 반영되는 값이며 기존 자리의 폭/길이를 프로필 변경만으로 재계산하지는 않습니다. 실제 제품의 장착 간격은 이름으로 추정하지 않습니다. 커넥터 돌출, 배선 굽힘, 냉각, 배터리 팽창 공간, 체결부 하중과 절연은 별도 설계 항목입니다.

## 제품 페이지 → 치수 확인 → CAD 또는 AI

장착 자리 창의 **제품 URL에서 스펙 가져오기** 또는 **조립 → 제품 스펙 · URL 가져오기**를 사용합니다.

- 공개 HTTPS 제조사/판매 페이지를 읽고, 치수 묶음과 주변 원문을 추출합니다. mm/cm/inch를 mm로 환산하며 세 치수·미터법 후보를 먼저 보여줍니다.
- URL·제품 제목·읽은 시각과 원문 근거를 보존합니다. 제품 옵션마다 크기가 다르거나 외경·내경·축 치수가 섞일 수 있으므로 **원문 열기**로 도면과 비교하세요.
- **선택 치수 가져오기**는 1번 값을 폭, 2번 값을 길이로 넣습니다. 반드시 축 순서를 확인하세요. 제품 높이를 포켓 깊이로 자동 사용하지 않고, 확인되지 않은 기본 체결 구멍도 끕니다. 적용한 출처는 작업 기록의 `product_source`에 남습니다.
- **AI 요청으로 보내기**는 출처·선택 치수·근거가 포함된 요청을 AI 입력칸에 준비합니다. 이를 누르는 것만으로 AI를 호출하지 않습니다. 사용자가 내용을 확인하고 **설계 초안 생성**을 눌러 현재 선택한 AI를 사용합니다. 웹 문구는 명령이 아닌 외부 참고 자료로 표시합니다.
- HTML 텍스트 페이지를 지원합니다. 로그인·쿠키·CAPTCHA 우회는 하지 않습니다. PDF·이미지·JavaScript로만 표시되는 도면은 원문을 열어 직접 확인해야 합니다. 자동 웹 전체 검색이나 모든 제조사 부품 라이브러리는 아닙니다.

실제 읽기 검증에 사용한 페이지: [Adafruit Raspberry Pi Pico](https://www.adafruit.com/product/4864), [Pololu Micro Metal Gearmotor](https://www.pololu.com/product/1099/specs). 같은 페이지의 여러 치수 후보를 구분해야 한다는 점도 확인했습니다.

## 버전, 언어, 격자

- 창 제목과 아래 상태줄에 **v2.9.0**이 표시됩니다. **도움말 → 버전 / 앱 정보**에서도 확인합니다.
- **보기 → 언어 / Language → English / 한국어**로 전환합니다. 설정은 다음 실행에도 유지됩니다. 주요 메뉴·도구·대화상자·이번에 추가한 화면과 영문 F1 가이드를 제공합니다. 기존 작업 기록과 사용자 부품 이름, AI 답변은 번역하지 않으며 일부 기존 트리 분류명과 상세 해석/오류 문구는 한국어로 남을 수 있습니다.
- 3D 화면과 스케치의 **1 grid = … mm**가 한 칸의 실제 길이입니다. 스케치 확대/축소에 따라 값이 바뀝니다. 3D 격자는 모델 크기에 맞춰 1/2/5 계열 간격을 선택합니다.
- **보기 → 격자 표시 / 좌표축 표시**를 각각 켜고 끕니다. 3D의 XYZ 시점 조작기와 스케치의 원점 축에 적용됩니다. 숨김은 표시만 바꾸며 스케치의 격자 스냅 설정은 별도입니다.

## 필렛과 Autodesk 파일

필렛은 모서리를 지정한 반지름으로 둥글게 연결하는 기능입니다. **모델링 → 3D 필렛 / 모따기**에서 모서리를 선택해 반지름을 정합니다. 형상에 비해 너무 큰 반지름은 만들 수 없습니다.

**파일 → 내보내기 → F3D / IPT**는 기존 Autodesk 변환을 사용합니다. IPT는 설치된 Inventor가 실제 파일을 만들고, F3D는 준비된 STEP과 스크립트를 Fusion에서 실행해 저장합니다. Fusion/Inventor가 없으면 준비 파일을 만들어 해당 앱이 있는 PC에서 변환합니다. STEP 형상 기반 변환이므로 원래 스케치·구속·피처 타임라인 전체가 Autodesk 타임라인으로 재구성되지는 않습니다. 전체 편집 기록은 `.cad.json`을 함께 보관하세요.
