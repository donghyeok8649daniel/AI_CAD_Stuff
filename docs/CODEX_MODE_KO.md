# Codex 연결 모드

CAD의 **설계 명령 / AI → Codex · ChatGPT 구독**을 선택합니다. **Codex 연결 → 기존 로그인 사용 · 모델 찾기**를 눌러 설치된 Codex의 ChatGPT 로그인을 확인하고 모델을 선택한 뒤 **Codex 모드 사용**을 누릅니다. 이미 로그인했다면 추가 로그인이나 API 키가 필요하지 않습니다. 연결한 모델은 다음 실행에도 기억합니다.

Codex에 로그인하지 않은 경우에만 **ChatGPT로 로그인**을 눌러 공식 브라우저 로그인 절차를 완료하세요. 이는 기존 Codex의 로그인 저장소를 사용합니다. CAD는 비밀번호·토큰을 읽거나 복사하지 않습니다. API 키로 로그인된 Codex는 이 모드에서 설계 생성을 거부하며, API로 자동 전환하지 않습니다.

**Pro는 구독 등급이며 모델 이름이 아닙니다.** 모델 목록은 Codex에서 조회합니다. 구독의 Codex 사용량과 모델 접근 권한이 적용되며, 무제한 무료 호출이 아닙니다. CAD 초안 한 건은 요청 분석과 설계 생성에 최소 두 턴을 사용하고, 형상 검증 실패 시 최대 두 번 추가 수정합니다. 취소 전 사용량도 소모될 수 있습니다.

## 설계 흐름

1. 만들 부품과 치수를 입력하고 **설계 초안 생성**을 누릅니다. 프롬프트와 현재 설계 정보가 Codex로 전송됩니다.
2. Codex가 기존 CAD 도구로 실행할 작업 계획을 반환합니다. 스케치·돌출·구멍·피처 편집·조립 등 현재 CAD가 지원하는 도구 범위 안에서 실행합니다.
3. CAD가 실제 형상과 치수를 검증합니다. 성공해도 현재 설계는 자동으로 바뀌지 않습니다.
4. 결과를 확인한 뒤 **검증된 초안 적용**을 누릅니다. 피처와 작업 기록에 반영되며 되돌릴 수 있습니다.

AI 최대 대기의 **무제한**은 대기 시간 제한만 없앱니다. Codex 구독 한도나 CAD 도구 제한이 없어지는 것은 아닙니다. 생성 중 **생성 취소**를 누르거나 CAD를 닫을 수 있습니다. CAD가 시작한 Codex 연결 프로세스만 정리하며, 사용자가 열어 둔 Codex 창은 종료하지 않습니다.

## 설치와 한계

- 별도 Codex CLI가 필요합니다. Windows npm 설치의 실행 파일을 자동 탐색하며, 자동 탐색에 실패하면 **찾기**에서 `codex.exe`를 선택하세요. 설치 버튼은 [공식 CLI 안내](https://learn.chatgpt.com/docs/codex/cli)를 엽니다. CAD 배포 파일에 Codex 전체를 중복 포함하지 않습니다.
- Codex app-server는 변경 가능성이 있는 실험적 인터페이스입니다. 검증한 CLI 버전은 **0.154.0**입니다. 호환 오류가 나면 CLI 업데이트 후 모델 목록을 다시 조회하세요.
- 연결은 로컬 stdio로 이루어집니다. 다른 Codex 창에 키보드 입력을 보내거나 브라우저 쿠키로 비공개 API를 직접 호출하지 않습니다.
- 기존 Codex 로그인을 재사용하지만, CAD 작업의 다른 MCP·플러그인·앱 도구는 임시 설정으로 끕니다. 생성된 코드를 실행하지 않고 기존 CAD 작업 계획만 실행합니다. 기존 Codex 설정 파일은 수정하지 않습니다.
- 좋은 모델을 선택해도 지원하지 않는 CAD 연산이나 설계 의도 검증의 한계가 해결되지는 않습니다. 제조 전에 치수, 간섭, 조립 관계와 공차를 직접 검토하세요.

공식 근거: [Codex app-server](https://learn.chatgpt.com/docs/app-server), [ChatGPT 로그인](https://learn.chatgpt.com/docs/auth).
