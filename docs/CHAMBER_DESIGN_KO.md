# 시편 습도 챔버 설계 초안

`모델링` 또는 `도면 / 해석 → 시편 습도 챔버 / 편집…`에서 시편·그립 주위의 실제 본체, 분리형 전면 도어, 관찰창, 가스켓, 정적 포트와 로드 인터페이스를 미리 볼 수 있습니다. 전체 조립에 새로 생기거나 증가한 체적 간섭이 있으면 적용할 수 없습니다. 관절이나 그룹 이름을 바꿔도 물리적 간섭을 숨기지 않습니다.

1. 시편과 그립을 선택하고 챔버를 엽니다. 선택 형상의 현재 위치와 전체 운동 보호 영역은 다릅니다. 보호 영역의 최소·최대 X/Y/Z에 그립의 전체 스트로크를 포함하세요.
2. 축별 내부 여유, 벽·도어 두께, 가스켓 두께·압축률, 관찰 개구와 포트 내경을 지정합니다.
3. 상부가 움직이지 않는 경우 정적 O링 홈을 사용할 수 있습니다. 하부 이동 로드는 벨로즈 인터페이스를 지정합니다. 실제 공급사의 압축·신장 한계가 미정이면 빈칸으로 유지합니다.
4. 전면 도어를 분리해 내부 보는 옵션은 표시만 바꿉니다. 본체·도어·창·체결 부품 전체가 간섭 계산과 적용할 설계에 남습니다.
5. 전체 조립 결과와 설치 장애물을 확인합니다. 벨로즈 전체 운동 공간 또는 지정한 구동기가 챔버 내부와 겹치면 적용이 차단됩니다. 체결 공구 접근 장애물도 표시됩니다. 분리해야 접근할 수 있는 보호 커버와 도어의 실제 설치 순서를 정하세요.

챔버 구성품을 다시 선택해 같은 명령을 열면 현재 기록 분기에 저장된 치수로 편집할 수 있습니다. 뒤에 있는 기록이나 다른 분기의 요구사항을 가져오지 않습니다. 구성품 전체의 ID를 유지하는 편집은 기존 이름·색·재질·제품 메타데이터와 외부 조립 참조를 보존합니다. 포트나 인터페이스를 제거해 구성품 ID 집합을 바꾸는 작업은 별도의 새 챔버 또는 명시적 조립 재설계가 필요합니다.

## 기생 하중 입력

미정 입력은 빈칸이며 0으로 대체하지 않습니다. 실제 0인 값은 `0`을 입력합니다.

| 입력 | 단위 | 의미 |
| --- | --- | --- |
| 내외 차압 | Pa | 부호를 포함한 압력 차이 |
| 벨로즈 유효 면적 | mm² | 공급사 또는 실측 값. 로드 단면적과 같다고 가정하지 않음 |
| 스프링 상수 | N/mm | 해당 벨로즈의 지정 조건 값 |
| 자유 길이 대비 변위 | mm | 부호를 포함한 변위 |
| 밀봉 마찰력 | N | 지정 조건의 비음수 크기 |
| 기타 예하중 | N | 부호를 포함한 값 |
| 비교할 시험 하중 | N | 기생 하중 비율을 비교하기 위한 사용자 입력 |

차압 항은 `Δp × A_eff × 10⁻⁶`, 스프링 항은 `k × δ`로 계산합니다. 두 항의 절댓값, 마찰력과 예하중의 절댓값을 모두 더한 값은 입력값에 대한 보수적 상한 추정입니다. 필요한 입력 하나라도 미정이면 전체 상한과 시험 하중 대비 비율을 만들지 않습니다. 이는 실물 시험·정격·측정 불확도 평가를 대체하지 않습니다.

## 파라미터 API

`cadstudio.chamber_design.build_chamber(ChamberRequirements | dict)`는 독립적인 BREP 구성품과 검사 결과를 반환합니다. 파일, 프로필, 기존 문서 또는 네트워크를 수정하지 않습니다.

```python
from cadstudio.chamber_design import build_chamber

chamber = build_chamber({
    "protected_swept_bounds": {
        "minimum_mm": [-30, -44, 364.7],
        "maximum_mm": [30, 32, 529.7],
    },
    "clearance_mm": [10, 10, 10],
    "wall_thickness_mm": 6,
    "door_thickness_mm": 6,
    "static_rod_seals": [{
        "id": "upper", "face": "top", "rod_diameter_mm": 25,
        "position_xy_mm": [0, 6], "cross_section_mm": 3,
        "radial_compression_fraction": 0.2,
        "cap_thickness_mm": 2, "cap_outer_diameter_mm": 46,
    }],
    "rod_interfaces": [{
        "id": "lower", "face": "bottom", "rod_diameter_mm": 25,
        "position_xy_mm": [0, 6],
        "bellows_inner_diameter_mm": 28,
        "bellows_outer_diameter_mm": 44,
        "installed_length_mm": 44,
        "stroke_min_mm": -5, "stroke_max_mm": 5,
    }],
})
candidate = chamber.append_to(existing_design)  # 기존 ID 충돌 시 거부
report = chamber.report()  # JSON 형식으로 저장 가능한 치수·검사·미정 항목
```

위 숫자는 조립 공간 검토 예제입니다. 하중·주파수·누설 정격을 정의하지 않습니다. 보호 영역의 중심은 `(0, -6, 447.2)`이고 로드·포트의 위치는 이 중심 기준입니다. 예제의 `[0, 6]`은 전역 `(X,Y)=(0,0)` 축입니다. 벨로즈 설치 길이에는 고정·이동 칼라 각 3 mm가 포함되지 않습니다. 예제의 전체 외부 길이는 공칭 50 mm이며 최대 신장 자세에서 55 mm입니다.

- `chamber.as_design()`는 독립 챔버 설계를 반환합니다.
- `chamber_rod_pose(chamber, "lower", stroke_mm)`는 지정 범위의 새 자세를 실제 형상으로 다시 만듭니다. 원본과 구성품 ID는 유지합니다.
- `inspect_chamber_interfaces(chamber, existing, drive_part_ids=...)`는 실제 조립 부품과 내부·벨로즈·공구 공간의 겹침을 보고합니다. 중앙 로드 통과 경로는 벨로즈 검사 영역에서 제외합니다. 이것은 그룹으로 부품 간섭을 제외하는 기능이 아닙니다.
- 외부 조립 구속이 생성 부품을 요청한 보호 영역과 다른 위치·방향에 고정하면 재편집을 거절합니다. 기존 중심·방향을 유지하거나 구속 위치를 먼저 재설정하세요. 기존 중심에서 벽·창 등의 치수를 바꾸는 편집은 가능합니다.
- `ChamberDialog(parent, raw, part_ids=..., requirements=..., replace_ids=..., drive_part_ids=...)`의 `checked`는 적용 가능한 전체 `Design`입니다. `report`는 최근 검사 결과의 딕셔너리 속성입니다. 기본 대화상자는 상부 정적 로드 한 개와 하부 이동 로드 한 개를 편집합니다.

`report["requirements"]`와 `report["parts"]`를 문서 작업 기록에 저장하면 재개·편집이 가능합니다. STEP/STL로 내보내는 형상과 `.cad.json`에 들어가는 BREP는 기존 CAD 가져오기 기능을 통해서도 사용할 수 있습니다.

## 구현된 것과 검증이 필요한 것

본체의 빈 내부 체적, 전면 개구부, 실제 포트 관통 유로, 도어/창 체결 구멍·별도 볼트 공간, 압축 가스켓 형상, 상부 정적 O링 홈·캡, 하부 벨로즈 형상과 축 방향 운동 공간을 생성합니다. 구성품이 유효한 단일 솔리드인지, 서로 체적 간섭이 없는지, 보호 영역에 들어오지 않는지 검사합니다. 구동기·로드셀은 챔버 외부에 배치해야 합니다.

실제 피팅의 나사·너트·용접 또는 접합 방법, 씰 재료와 표면 거칠기, 체결 토크·판 변형, 벨로즈 양끝의 실제 밀봉 접합·로드 결합은 아직 제품 선정과 제작 검토가 필요합니다. 벨로즈는 축 방향 공간을 확인하는 형상 초안이며 횡변위·회전·응력·피로 수명 또는 구조 변형을 해석하지 않습니다. 누설 시험·압력 정격·습도 유지 성능을 검증 완료라고 표시하지 않습니다.

이동 칼라는 고정된 부품으로 만들지 않습니다. 실제 로드와의 조립 구속은 따로 등록해야 하며, 강체 관절을 움직였을 때 벨로즈가 자동으로 변형되지는 않습니다. 호스트는 명시적인 `chamber_rod_pose` 재생성으로 선택 자세를 검사할 수 있습니다. 고정된 벨로즈 형상과 이동 칼라만 움직이는 경우의 간섭을 임의로 검사에서 제외하지 않습니다.

정적 O링 압축 형상은 원래 단면적을 보존하는 타원 단면 초안입니다. 초기 반경 압축률은 20%이며 30%를 초과할 수 없습니다. 홈 충진율은 60~85% 범위를 검사합니다. 실제 홈 치수와 재료는 공급사 조건을 확인해야 합니다. 정적 O링에 왕복 로드를 사용하면 안 됩니다. 짧은 게이지 구간 프리셋의 시편 통과 구멍은 **열린 누설 경로**로 보고하며 시편 어깨에 임의의 밀봉 성능을 부여하지 않습니다.
