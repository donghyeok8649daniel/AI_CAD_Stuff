# MCU 보드 선택과 핀 배선

**전장 회로 → 회로도 보기… → MCU 선택 / 핀 연결…**에서 보드를 선택하고 어떤 물리 핀을 어느 부품 단자에 연결할지 지정합니다. 노란색 CAD 부품이나 전장 역할만 지정한 상태에서는 회로와 MCU가 자동으로 등록되지 않습니다.

전장 편집창의 **MCU 선택 / 핀 연결…** 버튼으로 핀 편집기를 바로 열 수도 있습니다. 이 경로에서는 핀 연결 저장 후 전장 편집창에서 **설계에 저장**하면 됩니다.

1. **MCU 추가…**에서 정확한 보드 모델을 고릅니다. 이름, 실제 공급·리턴 노드, 전원 전압과 해당 운전 조건의 소비전류를 입력합니다. 제조사가 권장하는 어댑터 전류는 보드의 소비전류가 아닙니다. 소비전류가 미정이면 이를 확인한 뒤 저장합니다. 필요한 경우 해당 보드를 3D CAD 부품에 연결합니다.
2. 보드를 선택하면 양쪽 핀을 보여 주는 **핀 모식도**와 핀 목록이 나타납니다. 핀 이름, 물리 헤더·핀 번호, 표시된 기능과 이미 연결한 노드를 확인합니다. 모식도에서 핀을 클릭하거나 목록에서 선택합니다.
3. **연결할 부품 · 단자**에서 실제 회로 부품의 첫째/둘째 단자 또는 다른 MCU의 물리 핀을 고르고 **선택 핀 연결**을 누릅니다. 대상이 연결된 노드가 선택 핀에도 기록됩니다. 연결할 대상 부품이 없다면 전장 편집창에서 먼저 추가합니다. 직접 지정한 노드에 연결하는 방식도 사용할 수 있습니다.
4. 연결을 변경하려면 핀을 다시 선택해 새 대상을 지정합니다. **핀 연결 해제**는 선택 핀의 연결만 제거합니다. 핀 연결 창에서 저장하고, 회로도에서도 **회로도 변경 저장**한 뒤 전장 편집창의 **설계에 저장**으로 프로젝트와 작업 기록에 반영합니다. 어느 창에서든 취소하면 그 창을 열기 전의 저장된 회로는 변경되지 않습니다.
5. 회로도를 다시 계산해 전원·리턴 경로, 연결 상태와 경고를 확인합니다. `.cad.json` 프로젝트에는 보드 모델과 핀 연결을 함께 저장하므로 다시 열어 편집할 수 있습니다.

센서·엔코더·드라이버는 전원 두 단자 외에 신호 단자가 필요합니다. 부품 편집창에서 일반 부하 또는 모터 항목을 고른 뒤 **추가 신호 단자 = 노드 · 센서 / 드라이버**에 `OUT_A=ENCODER_A`, `PWM=MOTOR_PWM`처럼 한 줄씩 입력하세요. MCU 핀 연결 대상에서 해당 부품의 `OUT_A`·`PWM` 단자를 고를 수 있으며, 회로도에도 전원 분기와 별도의 신호 행으로 표시합니다. 단자 이름을 등록했다고 엔코더 파형이나 드라이버 논리가 자동으로 계산되는 것은 아닙니다.

## 내장 핀 모식도의 범위

| 보드 | 제공 범위 |
| --- | --- |
| Raspberry Pi 3 Model B+, 4 Model B | 40핀 J8 헤더, BCM GPIO 이름과 물리 핀 번호 |
| Arduino UNO Rev3 | 주 전원·디지털·아날로그 헤더 |
| Arduino Mega 2560 Rev3 | 주 전원·디지털·아날로그 헤더 |
| NUCLEO-F103RB, NUCLEO-F401RE, NUCLEO-F446RE | Arduino 호환 헤더. ST Morpho·ST-LINK 핀은 포함하지 않음 |
| Raspberry Pi Pico | 40개 가장자리 핀. SWD·보드 내부 GPIO는 포함하지 않음 |

예를 들어 Raspberry Pi 4의 `GPIO17`은 물리 `J8.11`이며, Arduino UNO의 `D2`와 같은 번호 체계가 아닙니다. 같은 물리 신호로 이어진 별도 헤더 핀은 원문에 확인된 연결 관계에 따라 취급합니다. 데이터가 없는 보드에는 공식 핀 번호를 추측해 그리지 않습니다. 기존 프로젝트의 사용자 정의 핀 이름은 보존하고 사용자 정의 핀으로 표시합니다. 정확한 모델이 있더라도 데이터에 없는 임의 핀은 공식 핀과 구분합니다.

모식도는 핀 관계를 설명하기 위한 도식이며 실제 PCB 외곽, 커넥터 위치·방향과 치수를 보장하는 기구 도면이 아닙니다. 보드별 공식 원문을 열어 실제 기판 개정·헤더 방향을 확인하세요.

핀 번호와 적용 범위의 원문은 [공식 자료와 확인 기록](MCU_PIN_SOURCES.md)에 정리되어 있습니다. Nucleo는 보드의 솔더 브리지 설정에 따라 신호 경로가 달라질 수 있으므로 모식도에 적힌 기본 매핑만 보고 실제 배선 상태를 단정하지 마세요.

## 검사 결과의 의미

핀 연결 검사는 저장된 노드와 전선·스위치의 연결 상태를 사용한 **수동 도통 및 DC 연결 검토**입니다. 같은 노드로 연결했다고 디지털 신호나 주변장치가 자동으로 작동하는 것은 아닙니다. 신호 전압이 다른 MCU를 연결할 때는 레벨 변환과 허용 입력 조건을 확인해야 합니다. GPIO를 모터 전원 단자처럼 큰 전류의 부하에 직접 연결해서는 안 됩니다.

펌웨어 실행, GPIO 입출력 설정, 대체 기능 선택, 통신 타이밍, 풀업·풀다운과 모터 드라이버 제어는 아직 계산하지 않습니다. 기능 목록에 `UART`·`I2C` 등이 표시되어도 코드나 보드 설정을 대신하지 않습니다. 실제 전원을 넣기 전에는 배선·극성·핀 허용 전압·전류·보호회로를 실제 부품 자료로 확인하세요.
