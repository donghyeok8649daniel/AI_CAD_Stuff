# 모델링 · 도면 · 해석 범위

## 설계 조작

- 스케치의 선 선택 → **E** 또는 **돌출**. 연결된 닫힌 영역이 하나면 자동 선택합니다. 인접 영역이 여러 개면 영역 안쪽을 클릭합니다. 열린 선은 솔리드 돌출의 대상이 아닙니다.
- 파랑: 남은 자유도 있음. 밝은 회색: 해석상 완전 구속. 초록: 명시적 전체 고정. 빨강: 해석 실패 시 구속에 참여하는 요소. 빨강은 최소 충돌 구속 집합을 특정하는 진단은 아닙니다. 선택은 주황, 커서 근처는 청록입니다.
- 격자 스냅은 현재 보이는 격자 간격을 사용합니다. 곡선과 격자의 교점도 추천합니다. 격자 자체에 영구 고정 구속을 자동 추가하지 않습니다.
- **I**: CAD 꼭짓점 두 개 사이 직선 거리, XYZ 차이 또는 모서리 곡선 길이. 스케치에서도 Ctrl로 점 두 개를 선택하면 거리와 XY 차이가 표시됩니다.
- 평면 선택 → **이 면에 구멍 뚫기** → 중심 XY, 직경, 깊이 또는 관통. 원형 절삭 스케치로 저장되며 트리에서 다시 편집합니다. 관통은 생성 시 모델 크기에 맞춘 깊이 값으로 기록됩니다. 이후 부품이 더 두꺼워지면 깊이를 다시 지정해야 합니다.
- **Ctrl+K**로 도구를 검색할 수 있습니다. 메뉴 전체를 기억할 필요가 없습니다.

## 스윕 · 로프트 · 모서리 마무리

스윕은 단면과 XYZ 경로 또는 저장한 스케치 경로를 사용합니다. 로프트는 순서가 있는 2~8개 단면을 사용합니다. 솔리드 옵션을 해제하면 쉘 곡면을 생성하며, 열린 스케치 단면도 사용할 수 있습니다. 내부 구멍이 있는 로프트 단면은 지원하지 않습니다. 스윕에는 내부 와이어를 사용할 수 있습니다. 생성된 형상은 OCCT 유효성 검사를 통과해야 적용됩니다.

참조한 스케치의 형상·치수는 갱신됩니다. 단면 위치와 회전은 이 피처의 배치 값입니다. 다른 부품 면의 이동을 영구적인 위상 참조로 추적하지는 않습니다. 모서리 필렛·모따기는 선택한 모서리의 인덱스, 길이, 중심, 종류를 검증하며 참조 형상이 달라지면 재선택을 요구합니다.

## 폐루프 조립

트리 형태로 연결한 조인트에 폐루프 점 연결을 추가합니다. 자동 계산할 수동 회전/슬라이더 관절을 지정하고 나머지는 구동 값으로 유지합니다. XY 모드는 위치 2조건과 평행한 축을 사용하며 높이 차이를 허용합니다. 공간 모드는 XYZ 점 위치 3조건입니다. 공간 강체의 6조건 폐쇄나 일반적인 모든 기구 해석을 뜻하지 않습니다.

4절 링크 예제는 실제 구멍 중심과 회전 조인트, 2개 수동 관절, 닫힘 조건을 갖습니다. 닫힘 오차 0.0001mm를 만족하지 못하는 자세는 적용하지 않습니다. 특이점의 수치 순위와 조립 분기는 초기 자세의 영향을 받을 수 있습니다.

## 로봇 동역학

고정 베이스와 XY 평면의 2개 회전 관절, 양단 링크, 지정한 구멍 기준점을 지원합니다. 링크와 강체로 연결된 부품의 CAD 체적·질량중심·관성에서 공통 밀도를 사용해 질량을 계산합니다. 끝단 점 질량을 추가할 수 있습니다. 수평 운동과 수직 운동 평면의 중력 방향을 사용자가 선택합니다.

SI 단위의 `M(q) q̈ + C(q,q̇) + G(q) + b q̇ = τ`를 계산합니다. 목표 자세 모드는 정지 시작/끝의 5차 궤적에 필요한 토크를 구합니다. 토크 입력 모드는 적응 시간 적분으로 운동을 계산합니다. XY 목표점의 두 IK 분기, 도달 반경, 시간별 각도·속도·토크·끝단 위치와 CSV를 제공합니다. 슬라이더 자세와 해석 조건을 작업 기록에 저장할 수 있습니다.

폐루프 동역학, 접촉/충돌 반력, 모터 제어기, 관절 제한, 기어 마찰, 링크 탄성은 계산하지 않습니다. 형상 간섭 검사는 CAD 조립 검사에 별도로 남아 있습니다. 모터 선정의 인증 도구가 아닙니다.

식의 근거: [MIT Underactuated Robotics — Manipulator Equations](https://underactuated.mit.edu/multibody.html). 구현은 링크 질량중심의 평면 위치와 관성을 반영하고, 이동 에너지 및 정적 중력 평형으로 검증합니다.

## 시편 응력과 변형

추가 피처가 없는 원통형/평판형 인장 시편의 3D TET4 유한요소 해석입니다. 기존 CAD의 평행부·Bezier 전이부·그립 치수에 맞춘 유한요소 근사 메시를 생성합니다. 한쪽 그립 면을 XYZ 고정하고 반대쪽 면에 분포 인장력을 적용합니다. 탄성계수, 푸아송비, 비교용 항복 강도, 힘과 메시 단계를 입력합니다.

등방성 작은 변형 선형 탄성 가정입니다. `σ = λ tr(ε) I + 2μ ε`에서 요소 강성 행렬을 조립하고 희소 선형계를 풉니다. 요소별 등가응력, 평행부 축응력, 절점 변위, 반력 및 에너지를 제공합니다. 모델은 탄성 범위에서만 적용되며 소성, 파단, 좌굴, 피로와 대변형은 포함하지 않습니다. 고정단 최대 응력은 메시의 영향을 받으므로 여러 메시 단계로 결과를 비교하세요. 기본 물성은 예시 값입니다.

식의 근거: [FEniCS — Linear Elasticity](https://olddocs.fenicsproject.org/dolfin/2019.1.0/python/demos/elastodynamics/demo_elastodynamics.py.html). 이 앱은 FEniCS를 설치하지 않으며 NumPy/SciPy 기반 자체 TET4 조립을 사용합니다.

## 시편 표점 규칙

표점 길이 L₀와 평행부 길이 Lc를 별도로 관리합니다. 사용자 표점 길이 또는 원통 시편의 ASTM E8 4D / E8M 5D 표점 규칙을 선택합니다. [ASTM E8/E8M-25 공개 범위](https://store.astm.org/e0008_e0008m-25.html)의 일반 원통 시편 규칙만 반영합니다. 재료별 예외가 있으며, 분말야금 시편 등에 이 비율을 그대로 적용해서는 안 됩니다.

이 검사는 표점이 평행부 안에 들어가는지 확인합니다. 전체 형상, 전이 반경, 공차, 가공 품질과 시험 절차에 대한 규격 인증이나 시험기관 인증을 발급하지 않습니다.

## 도면

A4/A3 가로 용지에 제3각법 상면·정면·우측면, 숨은선, 외형 치수, 축척, 표제란을 만듭니다. 선택 부품은 로컬 좌표, 전체 조립은 조립 좌표를 사용합니다. 조건을 저장한 후 형상이 변경되면 다시 계산합니다. SVG / 벡터 PDF / 폴리라인 DXF를 내보냅니다. 숨은선은 OCCT HLR로 계산하고 내보내는 곡선은 폴리라인으로 근사합니다. 상세 치수 배치, 기하공차, 단면도, 도면 표준 전체 준수는 포함하지 않습니다.

## 로컬 AI 설치

설계 명령 패널의 **로컬 AI 설치 / 모델 다운로드**, 또는 패키지의 `Local AI Setup.ps1`을 사용하세요. Windows 공식 Ollama 설치 파일의 SHA256을 검증한 뒤 실행합니다. 이미 설치돼 있으면 재설치하지 않습니다. 선택한 Qwen3 모델 1개를 로컬 Ollama 서버로 내려받고, 기존 모델은 공용으로 재사용합니다. CAD 배포 ZIP에 여러 GB 모델 파일을 중복 포함하지 않습니다.

Ollama 0.34.3 설치 파일 해시 출처: Microsoft winget `Ollama.Ollama` 패키지 메타데이터, 공식 릴리스 URL. 모델 출처: [Qwen3 8B](https://ollama.com/library/qwen3:8b), [Ollama API](https://docs.ollama.com/api).


## 축 · 구멍 공차와 간섭

공차는 기준 치수에 더하는 상한/하한 편차(mm)입니다. 두 편차 모두 양수 또는 음수인 경우도 지원합니다. 실제 원통의 외경/내경, 링크·판·브래킷 구멍, 원 하나로 만든 면 절삭 피처에 연결하거나 직접 기준 지름을 입력합니다. 형상은 기준 치수를 유지하고 허용 범위를 별도 저장합니다. 참조 형상이 삭제·변경되면 재선택을 요구합니다.

최소 틈새 = 구멍 최소 지름 − 축 최대 지름, 최대 틈새 = 구멍 최대 지름 − 축 최소 지름입니다. 반지름 틈새가 아닌 **지름 차이**이며 양수는 틈새, 음수는 간섭입니다. ISO H7/h6 같은 등급표를 추정하거나 자동 인증하지 않습니다. 온도, 원통도·동축도, 표면 거칠기와 변형을 포함한 3차원 공차 누적 계산은 아닙니다. CSV를 저장할 수 있고 도면의 빈 영역에 최대 4개 연결의 치수 한계표를 표시합니다. 더 많은 연결은 프로젝트/CSV에서 확인합니다. STEP에 제작 공차 PMI를 삽입하지는 않습니다.

간섭 검사는 OCCT 솔리드 교차의 실제 체적을 계산합니다. 화면에서 선택한 교차 영역을 강조합니다. 쉘 곡면, 체적이 없는 접촉 및 0.00001mm³ 이하 교차는 목록에 표시하지 않습니다.

작업 흐름 참고: [Autodesk Fusion 치수 공차](https://help.autodesk.com/cloudhelp/ENU/Fusion-Drawing/files/DWG-REF-DIMENSION-DLG.htm), [간섭 검사](https://help.autodesk.com/cloudhelp/ENU/Fusion-Model/files/GUID-A6629113-B137-4EDE-B3B2-C9F1F3BA83D1.htm).
