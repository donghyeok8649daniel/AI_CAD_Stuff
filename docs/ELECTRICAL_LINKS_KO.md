# CAD와 회로도 대응 · AI 배선 요청

상단 **선택 부품 색상** 바로 옆 **회로도** 버튼으로 저장된 실물 배선도를 엽니다. 기존 **전장 작업…**과 펼침 메뉴도 그대로 사용할 수 있습니다.

## 실제 부품 찾기

CAD 부품을 선택하면 열려 있는 회로도에서 연결된 회로 부품을 함께 선택합니다. 선택 부품 속성의 **회로도에서 이 부품 찾기**는 그 부품을 확대합니다. 회로 부품을 선택하면 CAD 대응도 선택되고, **CAD 부품 보기**를 누르면 설계 화면에서 실제 몸체를 찾아 확대합니다. 회로도에는 회로 이름·ID와 CAD 이름·ID, 등록 또는 기존 대응 상태를 표시합니다. 대응이 없으면 **CAD 대응 없음**으로 표시하며 다른 몸체를 대신 선택하지 않습니다.

## 기존 회로 부품을 CAD에 연결

1. 회로도의 기존 부품을 선택하고 **CAD 대응 설정…**을 누릅니다. CAD 속성의 **기존 회로 부품과 CAD 대응 설정…**, 전장 작업창의 **기존 회로 ↔ CAD 대응…**에서도 같은 창을 엽니다.
2. 기존 회로 부품과 실제 CAD 몸체를 선택합니다. CAD 이름·ID로 검색할 수 있으며 다른 회로 부품이 사용하는 몸체는 선택할 수 없습니다.
3. **대응 연결 · 미리보기**로 결과를 확인한 뒤 **대응 변경 저장**을 누릅니다. 기존 회로 부품 ID·모델·핀·전선·정격과 CAD 형상을 유지합니다. 대상 CAD의 역할은 전장으로 지정하며, 노란색 체크를 켜지 않으면 기존 색상을 보존합니다.

**CAD 대응만 해제**는 몸체와의 연결만 제거합니다. 회로 부품·핀·전선은 삭제하지 않으며, CAD 역할과 색상도 그대로 유지합니다. 실제 제품 모델과 물리 핀을 바꾸려면 기존 전장 등록 / 모델 편집 기능을 사용합니다.

저장이 적용되는 범위는 다음과 같습니다.

| 시작 위치 | 최종 적용 버튼 |
| --- | --- |
| 메인 / 별도 창의 저장된 회로도 또는 CAD 속성 | 대응 창의 **대응 변경 저장** |
| **회로 편집…** 안에서 연 대응 창 | 대응 저장 후 바깥 회로 편집창의 **회로도 변경 저장** |
| **전장 작업…** 안에서 연 대응 / 회로 편집창 | 자식 저장 후 가장 바깥 전장 작업창의 **전장 변경 저장** |

바깥 창을 취소하면 자식 편집창에서 저장했던 변경도 버립니다. 최종 저장은 한 작업 기록으로 반영되어 실행 취소·다시 실행과 `.cad.json` 저장 / 다시 열기를 지원합니다. 원본 스케치·변수·가져온 형상 자료를 유지합니다.

## AI로 배선 변경하기

**AI 배선 요청…**에 원하는 부품·핀·전선 변경을 입력합니다. 선택한 회로 부품 ID와 단자가 함께 전달됩니다. 저장된 회로도에서는 메인 AI 입력창으로 바로 준비하고, 편집창 안에서는 **전장 변경 저장 · AI 요청 준비**로 명시적으로 저장한 뒤 전달합니다. 바깥 전장 작업창이 있으면 그 창의 최종 저장까지 대기합니다. 취소하면 대기한 요청을 버립니다.

메인 AI는 설계 모드로 전환되며 이전 미적용 초안을 해제합니다. **초안 생성**을 눌러야 모델 요청이 시작됩니다. 진행 중인 AI 작업은 덮어쓰지 않습니다. 새 초안의 미리보기에서 **전장 변경** 목록과 **변경 전 / 후 배선도**를 확인하고 적용합니다. AI는 기존 회로 대응과 실제 끝점이 있는 전선을 수정할 수 있지만, 미입력 정격·전선 치수·제품 사양을 임의로 채우지 않습니다.

배선도와 CAD 대응은 문서상의 연결을 뜻합니다. 등록된 모터 모델이나 핀 모식도만으로 내부 ESC 동작·MCU 코드 실행·모터의 실제 구동이 검증되지는 않습니다. 실제 소비전류·전선 규격·전원 경로가 미정인 항목은 보류로 남습니다.
