# Prompt CAD Studio 사용 설명서

길이 기본 단위는 **mm**, 각도는 **°**입니다. 모든 적용 작업과 변수 변경은 작업 기록에 남습니다. **F1**로 이 설명서를 다시 열 수 있습니다.

## 스케치 → 3D 돌출

1. 기준 평면을 선택하고 **S**를 누르거나, 부품의 평평한 면을 클릭해 **이 면에서 스케치**를 누릅니다.
2. **L** 직선, **R** 사각형, **C** 원, **P** 점으로 그립니다. 화면 아무 위치나 사용할 수 있습니다.
3. **자유 배치 G**를 켜면 점·선·닫힌 영역을 그릴 때 스냅과 자동 구속을 사용하지 않습니다. **Alt**를 누르는 동안에도 자유 배치합니다. 기존 구속은 유지됩니다. 이후 **D** 또는 구속 탭에서 치수·일치·수평·원점 고정 등을 추가하세요.
4. 위쪽 **스케치 종료** 또는 **Ctrl+Enter**로 3D 화면으로 돌아갑니다. 열린 선과 점만 있어도 저장할 수 있습니다.
5. 3D 화면에서 저장한 스케치의 닫힌 영역에 커서를 대면 강조됩니다. 클릭 후 **E**를 누르면 3D 돌출 창이 열립니다. 부품에 가려진 스케치는 **선택 대상 → 스케치 영역**을 사용하세요.
6. 노란 화살표를 드래그해 늘리거나 줄입니다. 깊이를 직접 입력해도 됩니다. 위에서 보는 방향에서는 화살표를 위아래로 드래그합니다.
7. 면 위의 스케치는 바깥쪽으로 더하거나 안쪽으로 파낼 수 있습니다. 기준 평면의 스케치는 정방향 또는 반대 방향으로 새 부품을 만듭니다. 실제 형상 검사가 끝나면 **설계에 적용**을 누릅니다.

기존 돌출은 부품 선택 → **돌출 깊이 · 3D 편집**, 면 피처는 브라우저의 해당 피처 선택 → **돌출 깊이 · 3D 편집**으로 수정합니다. 스케치 편집 탭의 돌출 깊이 입력도 사용할 수 있습니다. 그룹을 만들려면 요소나 영역을 선택하고 **Ctrl+G**를 누르세요. 그룹은 돌출과 절삭에 재사용할 수 있습니다.

## 선택과 구속 상태

3D 화면 위쪽 선택 목록에서 **자동 / 점 / 선·모서리 / 면 / 체적·부품 / 스케치 영역**을 바꿉니다. **Shift+1~6**으로도 바꿀 수 있습니다. 점은 정확한 형상의 꼭짓점, 선은 CAD 모서리이며 곡선도 포함됩니다. 자동 모드는 저장 스케치 영역을 우선합니다. 면을 선택하려면 면 필터를 사용하세요.

스케치에서 파랑은 자유도가 남은 요소, 밝은 색은 완전 구속, 초록은 전체 고정, 빨강은 구속 충돌입니다. 중복 구속은 **과다 구속** 경고와 구속 목록의 **⚠ 중복** 표시로 알립니다. 모순되는 치수는 만족하지 못한 구속 ID와 함께 오류를 표시합니다. 해당 구속을 삭제하거나 **Ctrl+Z**로 되돌린 뒤 계속하세요. 오류를 해결하기 전에는 스케치를 적용하지 않습니다.

## 변수와 계산식

모델링 화면에서 **U** 또는 **편집 → 변수 / 연결 치수**를 엽니다. 예를 들어 `두께 = 5`, `폭 = 두께*4`를 만들고 적용하세요. 부품 속성 치수, 스케치 치수 구속, 돌출 깊이에 `두께`, `폭/2`, `두께+1 mm`를 입력할 수 있습니다. 입력란 옆에 계산값이 나타납니다.

변수 변경 시 연결된 치수와 형상을 함께 계산합니다. 잘못된 식·순환 참조·불가능한 형상은 적용하지 않습니다. `+ - * / **`, 괄호, `abs`, `min`, `max`, `sqrt`, `pi`를 지원합니다. `mm`, `cm`, `m`, `inch`, `deg`를 환산 상수로 쓸 수 있습니다. 길이와 각도의 물리 차원을 자동 추론하는 단위 해석기는 아닙니다.

숫자로 덮어쓰거나 화살표를 드래그하면 해당 치수의 변수 연결이 해제됩니다. 스케치 치수 식은 해당 구속을 더블클릭해 편집합니다. 변수를 쓰는 치수는 식을 먼저 숫자로 바꾼 뒤 변수를 삭제하세요. 현재 변수 입력은 일반 부품 속성·스케치 치수·돌출 깊이·나사 치수에 적용됩니다. 별도 로봇·해석 대화상자의 모든 입력란이 식을 받는 것은 아닙니다.

## 점 추천과 접선·법선 / 스케치 재편집

- **점·선·곡선 위:** P로 점을 그릴 때 선이나 곡선 가까이 가면 정확한 곡선 위 위치를 표시합니다. 교점, 직선·원호의 중점, 끝점, 원점과 격자 교점을 추천합니다. 빈 격자점보다 실제 곡선 위 위치를 우선합니다.
- **면의 참조 경계:** 면 스케치에 표시되는 경계선·교점에도 바로 점을 찍을 수 있습니다. 자동 구속을 켜 두면 사용한 경계를 보조선으로 투영·고정하고, 새 점에 점-곡선 구속을 붙입니다. 참조는 해당 시점의 투영 형상이며 임의의 3D 곡면 사이 교선을 새로 계산하는 명령은 아닙니다.
- **선을 그릴 때:** L → 시작점 → 커서를 원·원호·타원·스플라인 근처로 옮기면 접점/법선 접점을, 기존 직선 근처에서는 평행/수직 방향과 수선의 발을 추천합니다. 스케치 탭의 **선을 그릴 때 추천**에서 접선·법선·평행·수직을 지정하거나 끌 수 있습니다. 자동 구속이 켜져 있으면 채택한 관계도 저장합니다.
- **이미 그린 요소에 구속:** Ctrl 클릭으로 요소를 고르고 위쪽 **구속 ▾**에서 접선·법선·중간점·직각·평행 등을 선택하세요. 법선은 직선 하나와 기준 곡선이 필요하며, 직선의 접촉할 끝점을 선택할 수 있습니다. `수직`은 세로 방향, `직각`은 두 직선이 이루는 90°입니다. 중복·충돌 조건은 빨갛게 표시하고 적용을 막습니다.
- **추천이 안 보일 때:** **자유 배치 G** 또는 Alt는 추천과 자동 구속을 잠시 끕니다. G를 끄고 스케치 탭의 스냅을 켜세요.
- **스케치 편집:** 3D에서 저장 스케치를 선택 → **Shift+E**, 상단 **스케치 편집**, 또는 트리의 스케치 더블클릭. 요소를 클릭하면 좌표·반지름 등 속성을 바꿀 수 있고, 치수 표시는 더블클릭으로 수정합니다. **스케치 종료**로 편집을 저장합니다.
- **이미 돌출한 형상 편집:** 부품 트리의 **기본** 또는 구멍/돌출 피처를 선택 → **Shift+E**. 이 경로는 해당 솔리드를 다시 계산합니다. 별도로 남긴 원본 스케치는 재사용용 복사본이므로 그 복사본 편집이 기존 돌출을 자동으로 바꾸지는 않습니다.

## 나사산 · 수나사 / 암나사

1. 원통 축이나 원형 구멍을 만드세요. **H**는 선택한 평면에 구멍을 만듭니다.
2. 원통 면을 클릭 → **이 면에 수나사 / 암나사 만들기 · T**. 또는 부품 선택 후 **T**, **3D 도구 → 나사산**, **Ctrl+K → 나사산**을 사용하세요.
3. **원통 면 선택** 탭에서 바깥 축 또는 구멍 안쪽을 클릭합니다. 목록으로도 선택할 수 있습니다. 평면·원뿔·부분 원통은 대상이 아닙니다.
4. 호칭 지름·피치·나사 길이·시작 간격을 입력합니다. M2~M48 프리셋은 대표 미터 치수이며, 세목 나사는 피치를 직접 입력하세요. 수나사의 호칭 지름은 축 지름과 같아야 합니다. 다른 크기는 축 치수를 먼저 바꾸세요.
5. 암나사는 **권장 바탕 구멍 지름** 근처로 구멍을 먼저 만듭니다. 예: Ø5 mm 구멍 → M6 × 1. 실제 사용한 드릴 지름에 따라 꼭대기 폭이 달라질 수 있습니다.
6. **나사산 미리보기** 탭에서 확인하고 적용합니다. **반대쪽 끝에서 시작**, 우나사/좌나사, **반경 여유**를 바꿀 수 있습니다. 반경 여유 0.1 mm는 수나사 지름을 0.2 mm 줄이고 암나사를 반경 방향으로 0.1 mm 넓힙니다. 가공 공차 등급을 자동 부여하는 기능은 아닙니다.
7. 작업 트리의 나사산 피처를 더블클릭하면 재편집합니다. 시작 면·치수·방향·여유와 변경 기록은 `.cad.json`에, 실제 형상은 STEP·STL에 저장됩니다. 입력에 `나사길이*2` 같은 변수를 사용할 수 있습니다.

설치 폴더의 **examples/threaded-bolt-nut.cad.json**에는 M6 볼트와 육각 너트, 머리 돌출과 나사산의 작업 기록이 들어 있습니다. 열어서 치수를 바꿔볼 수 있습니다.

현재는 평면으로 절단한 60° 프로파일의 단일 시작 나사를 지원합니다. 계산량을 제한하기 위해 길이는 피치의 1~32배입니다. 원통 면 크기·위치나 앞선 피처가 변경돼 참조가 맞지 않으면 오류를 표시합니다. 형상이 달라진 원통 면은 다시 선택하세요. 나사 입구 모따기는 나사산을 만들기 전에 **3D 필렛 / 모따기**로 적용하세요.

ISO 6g/6H 등급, 나사 게이지 검사, 둥근 뿌리와 규격 인증을 제공하지 않습니다. 제조용으로는 사용할 규격과 가공 여유를 따로 확인하세요. 형상 방식은 [Autodesk의 원통 면 나사 작업](https://help.autodesk.com/cloudhelp/ENU/Fusion-Model/files/SLD-HOLE-THREAD.htm)과 [CadQuery의 helix/sweep API](https://cadquery.readthedocs.io/en/latest/classreference.html)를 참고했습니다.

## AI와 저장

시작하면 **로컬 AI · Ollama** 패널이 표시되고 설치된 모델을 찾습니다. 자동으로 설계를 생성하지는 않습니다. 프롬프트 입력 → **설계 초안 생성** → 형상 검증 → **검증된 초안 적용** 순서입니다. 생성 중에도 편집·취소·앱 종료가 가능하며, 현재 설계가 바뀌면 이전 초안을 무심코 덮어쓰지 않도록 막습니다.

기본 최대 대기 시간은 10분이며 패널에서 3·5·10·20분을 선택합니다. CPU로 큰 모델을 실행하면 명령을 읽는 단계도 오래 걸릴 수 있습니다. 앱은 스케치 표시용 좌표 캐시를 AI 요청에서 제외합니다. 모델의 설계 능력과 속도는 PC와 모델에 따라 다르므로 큰 조립은 부품 단위로 요청하세요. Ollama는 로컬 사용 시 API 키가 필요 없습니다.

편집 가능한 원본은 **.cad.json**으로 저장하세요. STEP은 CAD 형상 교환, STL은 메시 출력입니다. F3D·IPT는 Autodesk 프로그램을 이용한 변환 경로이며 형상 교환만으로 원본 작업 기록 전체가 Autodesk 기록으로 변환되지는 않습니다.
