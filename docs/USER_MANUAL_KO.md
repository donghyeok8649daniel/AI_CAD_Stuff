# Prompt CAD Studio 사용 설명서

길이 기본 단위는 **mm**, 각도는 **°**입니다. 모든 적용 작업과 변수 변경은 작업 기록에 남습니다. **F1**로 이 설명서를 다시 열 수 있습니다.

## 스케치 → 3D 돌출

1. 기준 평면을 선택하고 **S**를 누르거나, 부품의 평평한 면을 클릭해 **이 면에서 스케치**를 누릅니다.
2. **L** 직선, **R** 사각형, **C** 원, **P** 점으로 그립니다. 화면 아무 위치나 사용할 수 있습니다.
3. **자유 배치 G**를 켜면 점·선·닫힌 영역을 그릴 때 스냅과 자동 구속을 사용하지 않습니다. **Alt**를 누르는 동안에도 자유 배치합니다. 기존 구속은 유지됩니다. 이후 **D** 또는 구속 탭에서 치수·일치·수평·원점 고정 등을 추가하세요.
4. 위쪽 **스케치 종료** 또는 **Ctrl+Enter**로 3D 화면으로 돌아갑니다. 열린 선과 점만 있어도 저장할 수 있습니다.
5. 3D 화면에서 저장한 스케치의 닫힌 영역에 커서를 대면 강조됩니다. 클릭 후 **E**를 누르면 3D 돌출 창이 열립니다. 부품에 가려진 스케치는 **선택 대상 → 스케치 영역**을 사용하세요.
6. 노란 화살표를 드래그해 늘리거나 줄입니다. 깊이를 직접 입력해도 됩니다. 위에서 보는 방향에서는 화살표를 위아래로 드래그합니다.
7. 면 위의 스케치는 바깥쪽으로 더하거나 안쪽으로 파낼 수 있습니다. 기준 평면의 스케치는 정방향 또는 반대 방향으로 새 부품을 만듭니다. 실제 형상 검사가 끝나면 **설계에 적용**을 누릅니다.

기존 돌출은 부품 선택 → **돌출 깊이 · 3D 편집**, 면 피처는 브라우저의 해당 피처 선택 → **돌출 깊이 · 3D 편집**으로 수정합니다. 스케치 편집 탭의 돌출 깊이 입력도 사용할 수 있습니다. 그룹을 만들려면 요소나 영역을 선택하고 **Ctrl+G**를 누르세요. 그룹은 돌출과 절삭에 재사용할 수 있습니다.

## 선택과 구속 상태

3D 화면 위쪽 선택 목록에서 **자동 / 점 / 선·모서리 / 면 / 체적·부품 / 스케치 영역**을 바꿉니다. **Shift+1~6**으로도 바꿀 수 있습니다. 점은 정확한 형상의 꼭짓점, 선은 CAD 모서리이며 곡선도 포함됩니다. 자동 모드는 저장 스케치 영역을 우선합니다. 면을 선택하려면 면 필터를 사용하세요.

스케치에서 파랑은 자유도가 남은 요소, 밝은 색은 완전 구속, 초록은 전체 고정, 빨강은 구속 충돌입니다. 중복 구속은 **과다 구속** 경고와 구속 목록의 **⚠ 중복** 표시로 알립니다. 모순되는 치수는 만족하지 못한 구속 ID와 함께 오류를 표시합니다. 해당 구속을 삭제하거나 **Ctrl+Z**로 되돌린 뒤 계속하세요. 오류를 해결하기 전에는 스케치를 적용하지 않습니다.

## 변수와 계산식

모델링 화면에서 **U** 또는 **편집 → 변수 / 연결 치수**를 엽니다. 예를 들어 `두께 = 5`, `폭 = 두께*4`를 만들고 적용하세요. 부품 속성 치수, 스케치 치수 구속, 돌출 깊이에 `두께`, `폭/2`, `두께+1 mm`를 입력할 수 있습니다. 입력란 옆에 계산값이 나타납니다.

변수 변경 시 연결된 치수와 형상을 함께 계산합니다. 잘못된 식·순환 참조·불가능한 형상은 적용하지 않습니다. `+ - * / **`, 괄호, `abs`, `min`, `max`, `sqrt`, `pi`를 지원합니다. `mm`, `cm`, `m`, `inch`, `deg`를 환산 상수로 쓸 수 있습니다. 길이와 각도의 물리 차원을 자동 추론하는 단위 해석기는 아닙니다.

숫자로 덮어쓰거나 화살표를 드래그하면 해당 치수의 변수 연결이 해제됩니다. 스케치 치수 식은 해당 구속을 더블클릭해 편집합니다. 변수를 쓰는 치수는 식을 먼저 숫자로 바꾼 뒤 변수를 삭제하세요. 현재 변수 입력은 일반 부품 속성·스케치 치수·돌출 깊이·나사 치수에 적용됩니다. 별도 로봇·해석 대화상자의 모든 입력란이 식을 받는 것은 아닙니다.

## 점 추천과 접선·법선 / 스케치 재편집

- **점·선·곡선 위:** P로 점을 그릴 때 선이나 곡선 가까이 가면 정확한 곡선 위 위치를 표시합니다. 교점, 직선·원호의 중점, 끝점, 원점과 격자 교점을 추천합니다. 빈 격자점보다 실제 곡선 위 위치를 우선합니다.
- **면의 참조 경계:** 면 스케치에 표시되는 경계선·교점에도 바로 점을 찍을 수 있습니다. 자동 구속을 켜 두면 사용한 경계를 보조선으로 투영·고정하고, 새 점에 점-곡선 구속을 붙입니다. 참조는 해당 시점의 투영 형상이며 임의의 3D 곡면 사이 교선을 새로 계산하는 명령은 아닙니다.
- **선을 그릴 때:** L → 시작점 → 커서를 원·원호·타원·스플라인 근처로 옮기면 접점/법선 접점을, 기존 직선 근처에서는 평행/수직 방향과 수선의 발을 추천합니다. 스케치 탭의 **선을 그릴 때 추천**에서 접선·법선·평행·수직을 지정하거나 끌 수 있습니다. 자동 구속이 켜져 있으면 채택한 관계도 저장합니다.
- **이미 그린 요소에 구속:** Ctrl 클릭으로 요소를 고르고 위쪽 **구속 ▾**에서 접선·법선·중간점·직각·평행 등을 선택하세요. 법선은 직선 하나와 기준 곡선이 필요하며, 직선의 접촉할 끝점을 선택할 수 있습니다. `수직`은 세로 방향, `직각`은 두 직선이 이루는 90°입니다. 중복·충돌 조건은 빨갛게 표시하고 적용을 막습니다.
- **추천이 안 보일 때:** **자유 배치 G** 또는 Alt는 추천과 자동 구속을 잠시 끕니다. G를 끄고 스케치 탭의 스냅을 켜세요.
- **스케치 편집:** 3D에서 저장 스케치를 선택 → **Shift+E**, 상단 **스케치 편집**, 또는 트리의 스케치 더블클릭. 요소를 클릭하면 좌표·반지름 등 속성을 바꿀 수 있고, 치수 표시는 더블클릭으로 수정합니다. **스케치 종료**로 편집을 저장합니다.
- **이미 돌출한 형상 편집:** 부품 트리의 **기본** 또는 구멍/돌출 피처를 선택 → **Shift+E**. 이 경로는 해당 솔리드를 다시 계산합니다. 2.4.0에서 저장 스케치로 새로 만든 돌출은 원본 변경을 추적합니다. 이전 버전에서 남긴 복사 스케치는 자동 연결되지 않습니다.

## 나사산 · 수나사 / 암나사

1. 원통 축이나 원형 구멍을 만드세요. **H**는 선택한 평면에 구멍을 만듭니다.
2. 원통 면을 클릭 → **이 면에 수나사 / 암나사 만들기 · T**. 또는 부품 선택 후 **T**, **3D 도구 → 나사산**, **Ctrl+K → 나사산**을 사용하세요.
3. **원통 면 선택** 탭에서 바깥 축 또는 구멍 안쪽을 클릭합니다. 목록으로도 선택할 수 있습니다. 평면·원뿔·부분 원통은 대상이 아닙니다.
4. 호칭 지름·피치·나사 길이·시작 간격을 입력합니다. M2~M48 프리셋은 대표 미터 치수이며, 세목 나사는 피치를 직접 입력하세요. 수나사의 호칭 지름은 축 지름과 같아야 합니다. 다른 크기는 축 치수를 먼저 바꾸세요.
5. 암나사는 **권장 바탕 구멍 지름** 근처로 구멍을 먼저 만듭니다. 예: Ø5 mm 구멍 → M6 × 1. 실제 사용한 드릴 지름에 따라 꼭대기 폭이 달라질 수 있습니다.
6. **나사산 미리보기** 탭에서 확인하고 적용합니다. **반대쪽 끝에서 시작**, 우나사/좌나사, **반경 여유**를 바꿀 수 있습니다. 반경 여유 0.1 mm는 수나사 지름을 0.2 mm 줄이고 암나사를 반경 방향으로 0.1 mm 넓힙니다. 가공 공차 등급을 자동 부여하는 기능은 아닙니다.
7. 작업 트리의 나사산 피처를 더블클릭하면 재편집합니다. 시작 면·치수·방향·여유와 변경 기록은 `.cad.json`에, 실제 형상은 STEP·STL에 저장됩니다. 입력에 `나사길이*2` 같은 변수를 사용할 수 있습니다.

설치 폴더의 **examples/threaded-bolt-nut.cad.json**에는 M6 볼트와 육각 너트, 머리 돌출과 나사산의 작업 기록이 들어 있습니다. 열어서 치수를 바꿔볼 수 있습니다.

현재는 평면으로 절단한 60° 프로파일의 단일 시작 나사를 지원합니다. 계산량을 제한하기 위해 길이는 피치의 1~32배입니다. 원통 면 크기·위치나 앞선 피처가 변경돼 참조가 맞지 않으면 오류를 표시합니다. 형상이 달라진 원통 면은 다시 선택하세요. 나사 입구 모따기는 나사산을 만들기 전에 **3D 필렛 / 모따기**로 적용하세요.

ISO 6g/6H 등급, 나사 게이지 검사, 둥근 뿌리와 규격 인증을 제공하지 않습니다. 제조용으로는 사용할 규격과 가공 여유를 따로 확인하세요. 형상 방식은 [Autodesk의 원통 면 나사 작업](https://help.autodesk.com/cloudhelp/ENU/Fusion-Model/files/SLD-HOLE-THREAD.htm)과 [CadQuery의 helix/sweep API](https://cadquery.readthedocs.io/en/latest/classreference.html)를 참고했습니다.

## AI와 저장

시작하면 **로컬 AI · Ollama** 패널이 표시되고 설치된 모델을 찾습니다. 자동으로 설계를 생성하지는 않습니다. 프롬프트 입력 → **설계 초안 생성** → 형상 검증 → **검증된 초안 적용** 순서입니다. 생성 중에도 편집·취소·앱 종료가 가능하며, 현재 설계가 바뀌면 이전 초안을 무심코 덮어쓰지 않도록 막습니다.

생성·취소·적용 버튼은 AI 패널 하단에 고정되어 있습니다. 위쪽 설정·입력·결과 영역을 스크롤해도 버튼은 그대로 보입니다. 초안 생성이 끝나면 실제 CAD 계산 결과가 보이도록 스크롤합니다.

기본 최대 대기 시간은 10분이며 패널에서 3·5·10·20분 또는 **무제한 (취소 가능)**을 선택합니다. 무제한은 Ollama의 전체 대기와 응답 읽기 시간 제한을 해제합니다. 도구 선택과 설계 생성 모두 같은 전체 제한 시간을 사용합니다. 진행 중 경과 시간과 무제한 상태를 표시하며 **생성 취소** 또는 창 닫기로 중단할 수 있습니다. 출력 길이와 치수·형상 검증은 유지합니다. CPU로 큰 모델을 실행하면 명령을 읽는 단계도 오래 걸릴 수 있습니다. 앱은 스케치 표시용 좌표 캐시를 AI 요청에서 제외합니다. 모델의 설계 능력과 속도는 PC와 모델에 따라 다르므로 큰 조립은 부품 단위로 요청하세요. Ollama는 로컬 사용 시 API 키가 필요 없습니다.

**CAD 작업 계획:** 물건과 원하는 치수를 설명하면 Ollama가 필요한 부품 생성, 돌출, 절삭, 구멍, 셸, 필렛, 패턴, 나사, 조립 작업을 선택합니다. 임의 윤곽 돌출·회전·스윕·로프트도 같은 계획에서 사용합니다. 바퀴처럼 특정 물건만 처리하는 별도 경로가 아닙니다. 단품 계획은 기본 형상 하나와 같은 부품에 적용하는 피처로 구성하며, 별도 부품 여러 개나 떨어진 솔리드로 바뀌면 거부합니다. 한 계획은 최대 32개 작업이며 각 단계는 실제 CAD 커널로 검증합니다. 오류가 있으면 실패한 단계와 치수 관계를 전달해 최대 두 번 수정합니다. 먼저 필요한 도구·형상을 선택하고 그 범위에서 작업 계획을 만듭니다. 선택은 필수 작업 목록이 아니므로 불필요한 도구를 전부 실행하지 않습니다. Qwen3는 두 단계 모두 비추론 모드로 실행합니다. 모델이 계획을 잘못 세우면 여전히 실패할 수 있으며 최종 원인을 표시합니다.

예: `80 x 60 x 5 mm 판에 지름 5 mm 관통 구멍 4개를 X 간격 60 mm, Y 간격 40 mm로 배치해`. 치수가 없는 요청은 모델이 정한 치수를 꼭 확인하세요. 생성된 작업 목록을 검토하고 **초안 적용**을 누르면 설계와 작업 기록에 반영합니다. 생성 중에 사람이 설계를 바꾸면 이전 설계 기준의 초안은 적용하지 않습니다. 실패·취소된 중간 형상도 현재 설계를 덮어쓰지 않습니다.

조립은 어떤 부품을 고정하고 어떤 부품이 회전·이동하는지 함께 적으세요. 먼저 추출한 관절 종류와 부모·자식 부품 관계를 생성 규칙과 실제 CAD 결과에서 확인합니다. 불일치하면 수정 요청을 보내며, 이미 관절이 유지하는 동일 위치를 다시 지정하는 명령은 관절과 작업 기록을 보존합니다. 이 검사는 모델이 요청을 올바르게 해석했다는 보증은 아니므로 적용 전 관절 종류·부품 관계·치수를 확인하세요.

초안 맨 위의 **CAD 계산 결과**에는 실제 생성된 형상의 X·Y·Z 방향 외곽 크기, 체적과 부품별 색상이 표시됩니다. 아래 **AI 설명**은 모델의 문장이므로 치수나 색상을 잘못 설명할 수 있습니다. 외곽 크기는 축 방향 전체 크기이며, 지름·벽 두께 등 개별 치수는 부품·피처 속성과 측정 기능에서 확인하세요. 설명 반복으로 응답이 길어지지 않도록 설명 길이를 제한하며 실제 모델링 작업 수는 유지합니다.

**실행 장치 확인:** 모델 목록 아래에서 실제 로드된 모델의 CPU/GPU 배치 상태를 확인합니다. 아직 로드되지 않았으면 미확인으로 표시합니다. 이 표시는 Ollama가 보고한 상태이며 CAD 앱이 GPU 사용을 강제로 설정하지는 않습니다.

**시작과 복구:** 앱은 부품 없는 새 설계로 시작합니다. 이전 자동저장은 보존하며 **파일 → 최근 자동저장 복구…**에서 명시적으로 불러옵니다. 복구한 파일은 저장 위치를 정해 저장하세요. 빈 창을 열거나 닫는 것만으로 이전 자동저장이 지워지지 않습니다.

편집 가능한 원본은 **.cad.json**으로 저장하세요. STEP은 CAD 형상 교환, STL은 메시 출력입니다. F3D·IPT는 Autodesk 프로그램을 이용한 변환 경로이며 형상 교환만으로 원본 작업 기록 전체가 Autodesk 기록으로 변환되지는 않습니다.


## 2.4 확장 도구

**도구 찾기 Ctrl+K**에서 아래 이름을 입력하면 메뉴를 직접 찾을 수 있습니다. **Ctrl+Shift+I**는 CAD 부품 가져오기입니다.

### 스케치 연결과 솔리드

- 저장한 스케치의 영역 → **E** → 돌출. 같은 스케치로 여러 피처를 만들면 원본 스케치의 수정이 함께 반영됩니다. 깊이·방향·선택 영역은 각 피처에서 따로 지정합니다. 원본을 사용하는 피처가 있으면 원본 삭제는 오류로 막습니다.
- **모델링 → 스케치 회전**: 단면과 회전축의 원점·방향, 각도를 지정합니다. 축은 부품 로컬 좌표입니다.
- **셸 / 구배 / 몸체 연산 / 패턴**: 셸은 열린 면과 안쪽 벽 두께를, 구배는 기울일 면·중립 평면 원점·법선과 각도를 지정합니다. 몸체 연산은 다른 부품을 도구로 사용하고 도구 부품을 보존합니다. 필요하면 브라우저에서 숨기세요.
- 분할/대칭의 원점·방향은 평면의 원점·법선입니다. 직선 패턴은 첫 반복 축의 X/Z 간격, 두 번째 축의 Y 간격을 사용합니다. 원형 패턴의 360°는 원본과 마지막 복제를 중복하지 않습니다. 여러 몸체를 같은 부품에 만들며 피처 자체를 복제하는 패턴은 아닙니다.
- **피처 순서 / 삽입 / 억제**: 피처 선택 후 위/아래 이동, 체크 해제로 억제, 선택 위치 앞에 솔리드 작업 삽입. 결과 형상이 검증돼야 적용할 수 있습니다. 전체 작업기록의 순서를 변경하는 기능과는 다릅니다.
- 새 면·모서리 참조는 방향과 상대 위치도 비교합니다. 단순한 치수 변경을 추적하지만, 후보가 여러 개이거나 형상 의미가 달라지면 재선택 오류를 냅니다. 완전한 위상 이름 추적은 아닙니다.

### 돌출과 구멍

**E → 범위**에서 한 방향, 대칭(입력값이 전체 길이), 양방향, 면 기반 전체 관통, 같은 몸체의 평행한 면까지를 선택합니다. 면까지를 고른 뒤 3D의 목표 평면을 클릭하세요. 다른 부품·비스듬한 면까지 종료는 아직 지원하지 않습니다. 관통 깊이는 몸체 두께가 바뀌면 다시 계산합니다.

테이퍼는 내부 구멍 없는 단면에 적용합니다. **얇은 벽**은 0이면 채운 솔리드, 양수면 닫힌 단면 안쪽에 해당 두께의 벽을 만듭니다. 열린 선의 얇은 벽 돌출은 아직 지원하지 않습니다. 화살표는 주 깊이를 조정하고 반대쪽 깊이는 입력란에서 바꿉니다.

**면 클릭 → H**에서 직선 구멍, 원통 자리파기, 접시머리를 고릅니다. 기본 지름·깊이와 머리 지름·자리 깊이 또는 접시 각도를 입력합니다. 피처의 **돌출 깊이 · 3D 편집**에서도 마감값을 수정할 수 있습니다. 머리 치수는 사용자 입력이며 체결품 규격을 자동 인증하지 않습니다.

### 가져오기와 연결 복제

**파일 → CAD 부품 가져오기**: STEP/STP, IGES/IGS, STL, BREP. 입력은 64 MB 이하이고 STL은 20,000면까지입니다. 형상은 압축 BREP로 프로젝트 안에 저장되므로 원본 파일 이동 후에도 열립니다. 전체 기록 포함 프로젝트의 저장 한도는 32 MB입니다. STL은 삼각형 면이며 자동으로 편집 가능한 매끈한 솔리드로 역설계하지 않습니다.

**조립 → 연결 복제**는 원본 형상 수정과 피처를 추적합니다. 위치·색·재질은 따로 정합니다. 형상을 바꾸려면 원본을 수정하거나 속성에서 **연결 해제**를 누르세요. 원본을 사용하는 복제가 있으면 원본 삭제는 막습니다. 하위 조립 트리·외부 파일 자동 갱신·부품 구성 억제는 아직 없습니다.

### 관절과 검사

볼(RX/RY/RZ), 평면(X/Y/RZ), 핀 슬롯(X/RZ)을 추가했습니다. **관절 운동 한계 / 모션 연결**에서 축별 최솟값·최댓값과 `따라갈 값 = 구동값 × 비율 + 오프셋`을 지정합니다. 각도 단위는 °, 이동은 mm입니다. 한계를 벗어나거나 연결이 순환하면 적용을 막습니다. 수동 폐루프 관절의 중복 구동도 막습니다. 접촉에 의해 움직임을 정지시키는 물리 엔진은 아닙니다.

**각도 / 간격 / 질량 / 단면 검사**는 실제 CAD 형상으로 계산합니다. 직선 두 개 또는 평면 두 개를 클릭해 방향 각도와 작은 교차각을 봅니다. 간격은 두 몸체의 가장 가까운 위치입니다. 질량은 속성의 **재질 / 물성**에서 밀도를 입력해야 계산됩니다. 무게중심은 세계 좌표, 관성은 무게중심 기준 세계 축입니다. 단면에는 세계 좌표의 평면 원점·법선을 입력합니다.

### 구성표·도면·판금

- **편집 → 설계 구성표**: 먼저 U에서 변수를 만들고 치수와 연결합니다. 구성 이름과 변수 식을 저장하고 목록으로 전환합니다. 적용할 때 CAD를 다시 계산하고 기록을 남깁니다. 피처 유무·재질 구성까지 관리하는 표는 아닙니다.
- **도면 / 해석 → 정투상 도면**: 보조 도면에서 단면 A-A 또는 상면 확대 상세 A를 선택합니다. 한 시트에는 보조도 한 개입니다. 단면 위치는 부품 도면이면 로컬, 조립 도면이면 세계 좌표입니다. 상세 중심은 상면 XY입니다. 상세 배율은 기본 축척의 배수입니다.
- **부품별 시트 포함 · 다중 PDF**를 켠 후 계산하면 시트를 선택해 봅니다. PDF는 전체 시트, SVG/DXF는 선택 시트를 저장합니다. **부품표 CSV**에는 부품 ID·원본 ID·수량·재질·질량·체적·색상을 기록합니다. 연결 복제는 부품별 한 행입니다. GD&T와 연관 상세 치수 편집은 아직 없습니다.
- **모델링 → 판금 · 단일 절곡 / 전개**: 바닥·플랜지의 직선 접선 길이, 판 폭, 두께, 안쪽 반경, 굽힘 각도, K 계수를 지정합니다. 굽힘 여유는 `각도(rad) × (안쪽 반경 + K × 두께)`입니다. 전개 DXF의 CUT 층은 외곽, BEND 층은 굽힘 구간의 양쪽 경계입니다. 임의 솔리드 변환·다중 플랜지·릴리프·추가 절삭 피처의 전개는 아직 지원하지 않습니다.

판금 계산의 정의: [Autodesk Sheet Metal Rule](https://help.autodesk.com/cloudhelp/ENU/Fusion-Sheet-Metal/files/SM-RULES-REF.htm), [전개 길이 계산식](https://help.autodesk.com/cloudhelp/2024/ENU/Inventor-Help/files/GUID-7B2525E4-8191-46F2-8CC3-FF422114EAE5.htm). K 계수는 소재·공구·공정에 맞게 입력하세요.
