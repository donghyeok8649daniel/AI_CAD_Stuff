# Prompt CAD Studio 2.23.0

기존 프로젝트·가져온 형상·작업 기록을 보존하면서 코드와 전장을 함께 검토하는 업데이트입니다. 기존 사용자는 `PromptCADStudioUpdater.exe`를 실행해 같은 설치 폴더를 업데이트합니다. 처음 설치할 때는 Windows ZIP을 풀고 `PromptCADStudio.exe`를 실행합니다.

## 코드와 실제 배선

상단 부품 색상 옆 **회로도 ▾ → 코드 업로드 · 배선 자동 시뮬레이션…**, 또는 전장 작업창의 **코드 · 배선 시뮬레이션**을 엽니다. 소스를 올리면 등록된 정확한 보드, 코드의 GPIO, 닫힌 전선과 수신 핀을 찾습니다. 보드가 여러 개면 해당 CAD 부품을 먼저 선택합니다. 파일명·UTF-8 소스·SHA-256·보드 연결을 프로젝트에 보관하므로 원본 코드 파일을 옮겨도 첨부가 유지됩니다. 명시적으로 적용·저장해야 기록에 반영되고, 바깥 작업창에서 취소하면 자식 창의 변경도 버립니다.

Arduino GPIO/PWM, Raspberry Pi GPIO/gpiozero와 STM32 HAL GPIO의 제한된 명령을 추적합니다. 모르는 구문을 조용히 건너뛰지 않습니다. 보드·핀·전원·배선이 모호하거나 지원하지 않는 코드가 있으면 이유를 표시합니다. HIGH와 GND의 충돌, 서로 다른 GPIO 출력, 외부 전원과 GPIO 연결, GPIO로 모터 전력을 공급하는 연결 등을 검사합니다. [지원 명령과 범위](PROGRAM_SIMULATION_2_23_0_KO.md).

**이 기능은 전체 펌웨어·운영체제·실제 FOC의 실행기가 아닙니다.** 사용자 코드를 Python·쉘로 실행하거나 실제 보드에 업로드하지 않습니다. 코드 추적 완료만으로 실제 모터 속도·전류·온도·시험 하중이 검증되는 것은 아닙니다. 입력 센서·통신·인터럽트·동적 분기·ELF/HEX와 Linux 실행은 남아 있습니다.

## 쇼트·정격·발열

**회로도 ▾ → 쇼트 / 정격 / 발열 점검…**에서 회로별 정격을 선언하고 현재 DC 회로를 평가합니다. 저저항 전원 단락, 서로 다른 전원 연결, 허용 전류·전압·전력, 퓨즈의 AC/DC 구분과 전선 조건을 확인합니다. 기동 전류는 입력한 별도 시나리오로 다룹니다. 실제 손실·주위 온도·해당 조립의 열저항이 있어야 정상 상태 온도를 계산하며 조건이 없으면 미확정으로 남깁니다. 정격·경고·미확정 항목은 각각 표시합니다. [계산 범위](ELECTRICAL_SAFETY_2_23_0_KO.md).

퓨즈의 차단 시간, 실제 열전달·PCB 온도 분포, 전원 과도응답과 안전 인증을 추정하지 않습니다. 시험 PCB에서 측정된 열저항을 임의의 조립체에 자동 대입하지 않습니다.

## 제품 자료와 응답성

제조사 출처가 연결된 카탈로그는 **235개**, 실제 등록 가능 모델은 **164개**, 제품 단자 자료는 **49개**입니다. MCU/MPU 보드, 액추에이터, 퓨즈, 저항·콘덴서·인덕터와 전원·드라이버·센서 자료를 늘렸습니다. 제품군 참고 항목 71개는 실물 등록 모델과 구분하며, 미확인 핀·소비전류·운전 전류는 만들어 넣지 않습니다. [카탈로그](ELECTRONICS_CATALOG_2_23_0_KO.md).

관절 이동 검사에서 조립체가 지속 캐시의 32개 형상보다 커도 한 검사 동안 최대 256개 로컬 형상을 재사용합니다. 검사 종료·취소 시 임시 참조를 해제하고 지속 캐시는 늘리지 않습니다. 불리언 도구의 상대 위치나 치수가 바뀌면 다시 계산합니다. 실제 간섭 검사와 시작 자세 검사도 유지합니다.

## Codex 오류 구분

인증·사용량·요청 형식·지원되지 않는 모델/프로토콜·네트워크 오류를 구분합니다. 서버 오류 문장에 단순히 `model`이 들어있다는 이유로 모델 미지원이라고 표시하던 경로를 수정했습니다. Windows 연결 초기화, DNS 실패와 서버 과부하를 네트워크 재연결 경로로 분류합니다. 인증·잔여 사용량·잘못된 요청은 무한 재시도하지 않습니다. 모델을 몰래 바꾸거나 유료 API로 전환하지 않습니다.

**Codex 연결 → 최근 연결 오류 진단**에는 오류 범주·안전한 숫자 상태·호출 단계·시각만 최근 32건까지 보관합니다. 서버 원문·키·토큰·프롬프트는 저장하지 않습니다. 현재 설치된 CLI 0.154.0과 구독 로그인에서 모델 조회·작은 응답·작은 허브 설계 생성이 실제로 통과했습니다. 사용자가 겪은 복잡한 설계의 원래 연결 오류가 재현됐거나 모든 상위 서비스 장애가 해결됐다는 의미는 아닙니다.

관련 소스 회귀 검사, Windows EXE의 자동/소프트웨어 렌더링, 실제 코드 파일 업로드·배선 추적·저장·재열기·실행 취소·다시 실행, 자식 적용/부모 취소와 작업 중 창 닫기를 검증합니다. 최종 수치는 [공개 집계](native2230-validation.json)에 기록합니다. 공개 패키지에는 개인 CAD 작업물·연구 자료·계정 정보가 들어가지 않습니다.
