# 전장 작업창

상단 **전장 작업…**은 CAD 부품 등록, 정확한 제품 찾기, 핀·전선 편집과 전원 설정의 시작점입니다. 옆 펼침 메뉴에서 회로도·MCU·전원·하중 계측·구동 검토를 직접 열 수도 있습니다. **도면 / 해석 → 전장 작업…**과 도구 검색에서도 찾을 수 있습니다.

## 작업물 정리

첫 목록은 전장 역할의 CAD 부품과 실제 회로에 연결된 CAD 부품, 회로 전용 항목을 함께 보여줍니다. 형상만 있고 전장 등록이 없는 부품도 표시합니다. 이름·부품 ID·모델을 검색하고 종류·등록 상태·점검 상태로 좁힙니다. 다른 역할의 부품을 등록하려면 **모든 CAD 부품**을 켭니다. 노란색만으로 모델을 추정하거나 자동 등록하지 않습니다.

항목을 선택하면 등록 상태, 모델, 물리 단자, 신호·전원 노드와 필요한 다음 작업이 보입니다. **선택 부품 등록 / 편집…**에서 정확한 제품 또는 사용자 정의 회로를 지정합니다. **회로도 · 핀 / 전선 연결…**에서 실제 핀을 연결하거나 전선을 추가·삭제하고, **전원 · 정격 · 배선 편집…**에서 공급·귀환·동작점 입력을 정리합니다. **CAD에서 보기**는 해당 3D 부품을 선택합니다.

자식 편집창의 저장은 전장 작업창 안의 사본에 반영됩니다. 마지막 **전장 변경 저장**을 눌러야 전체 변경이 CAD의 한 작업 기록으로 적용됩니다. 취소하면 그 사본의 변경을 버립니다. 실행 취소·다시 실행과 기존 `.cad.json` 저장은 그대로 사용합니다. CAD 형상과 조립 위치, 기존 사용자 색·제품 자료는 등록 작업 때문에 자동으로 바뀌지 않습니다.

## 제품 목록

제품 카탈로그 탭에서 모델명·제조사·분류로 검색합니다. 현재 총 98개 자료 중 실제 등록 모델 55개를 지원합니다. 보드 핀맵 11개·제품 단자 모식도 25개·수동 정격 등록 모델 19개와 탐색용 제품군 43개를 구분합니다. **보드 핀**, **제품 단자**, **수동 단자**, **자료 전용**의 범위를 구분합니다. 제품군이나 정확한 변형을 확인하지 못한 항목은 자동 등록할 수 없습니다. 제품 자료 수와 실제 등록 가능한 모델 수를 따로 표시합니다. 지원하는 제품 단자 모식도가 있어도 MCU 펌웨어나 동작 시뮬레이션 지원을 뜻하지 않습니다.

CAD 제품 자료의 제조사와 모델이 정확히 일치하면 **제품 자료에서 찾기**로 해당 카탈로그를 열 수 있습니다. 참고 모델을 찾을 뿐 등록이나 배선은 자동 변경하지 않습니다. [추가 모델과 공식 출처](ELECTRICAL_CATALOG_2_21_0_KO.md)를 확인하세요.

출처가 확인된 동일 IC를 사용해도 사용자 캐리어 PCB 전체를 그 IC로 바꾸지 마세요. 예를 들어 전압 기준 IC 주위의 버퍼·원격 감지 회로는 칩의 공식 핀과 다릅니다. 제품 변경으로 기존 단자를 지워야 한다면 기존 등록 편집창에서 그 변경을 확인해야 합니다.

## 점검 범위

미등록·중복 CAD 링크, 없는 CAD 부품, 미확인 모델/단자, 배선 끝점과 저장 노드 불일치, 고립된 할당 단자, 전원·귀환의 명시적 경로와 누락된 동작점을 표시합니다. 사용하지 않은 GPIO 전체를 오류로 만들지 않습니다. 전장용 함체나 장착 예약 공간을 전력 소비 부품으로 자동 바꾸지 않습니다.

점검은 저장된 연결의 정적 검토입니다. DC 계산은 별도 창에서 명시한 동작점으로 실행합니다. 배선 색, 제품 등록, 전압 레일 이름 또는 문서상 전원 경로만으로 GPIO 호환성·내부 레귤레이터·모터 정류·펌웨어 실행·실물 구동을 확인할 수 없습니다. 미확인 값은 보류로 남고, 제외된 부하의 0 A를 실제 소비전류로 해석하지 않습니다.

AI에도 제한된 등록·물리 전원 경로 점검 결과를 전달합니다. 원본의 부품이나 배선을 삭제해서 점검 항목을 숨기거나 소비전류·내부 회로를 추정해 완료 상태로 바꾸도록 하지 않습니다.
