# 검증 기록 · 2.0.0 Native

2026-09-23, Windows 64비트 / Python 3.12.14 / PySide6·Qt 6.10.2 / VTK 9.6.2 / CadQuery 2.8.0 / Open CASCADE 7.9.3.

## 자동 시험

- Python 시험 **110개 통과**. 이전 기하·구속·프로젝트·AI 모의 시험 90개와 네이티브 기하·기록·Ollama 시험 20개입니다.
- 이전 웹 클라이언트의 JS 기하·기록 시험 **12개 통과**. 웹 UI는 네이티브 패키지에 포함하지 않습니다.
- Starlette의 anyio 별칭 폐기 예정 경고 1건이 있으며 시험 실패는 없습니다.

새 시험은 13개 스케치 도구의 유효한 실제 솔리드, 교점·트림·대칭 원호, 간격띄우기·필렛의 닫힌 윤곽, 원점 고정+직경의 자유도 0, 디스크 저장 후 기록 분기 보존, Ollama의 고정 루프백 주소·JSON 스키마·오류 재시도 1회·외부 리디렉션 거부를 포함합니다.

## 네이티브 앱 시험

`native_desktop.py --smoke-test report.json` 및 배포한 `PromptCADStudio.exe --smoke-test report.json`으로 앱 자체의 Qt 위젯·이벤트 루프·OpenGL 렌더러를 실행했습니다. 입력은 QtTest의 네이티브 버튼 클릭과 앱 동작으로 수행했습니다.

1. Qt 메인 창 표시.
2. 스케치 도구와 X/Y 입력으로 60 × 40 사각형 및 중심 반지름 5 원 생성.
3. 깊이 8 돌출: 정확한 체적 **18,571.681469 mm³**와 비교.
4. OpenGL 화면의 실제 메시 셀을 피킹하여 평평한 면 식별.
5. 선택 면에 반지름 3, 깊이 4 포켓 생성: 제거 체적 **113.097336 mm³**와 비교.
6. 면 번호·이전 피처 참조·스케치 도구 전후·타임라인 2단계 보존.
7. CAD JSON 저장 후 기록 일관성 검증과 재불러오기, STEP 저장.
8. 실행 취소로 포켓 제거, 다시 실행으로 복구.
9. 5부품 조립과 4개 연결 생성, 유효한 형상 검사.
10. 과거 기록으로 포켓 설계 복원.
11. OpenGL 프레임버퍼의 유효한 형상 렌더링 확인.

Qt 위젯 테스트 화면과 VTK가 직접 렌더링한 프레임으로 [작업 공간](docs/native-workbench.png), [스케치 화면](docs/native-sketch.png)을 생성했습니다. QWidget의 이미지에는 네이티브 OpenGL 자식 창이 포함되지 않아, 작업 공간 검증 이미지에는 해당 자식의 실제 프레임버퍼를 같은 위치에 넣었습니다. 다른 데스크톱 앱의 화면을 수집하지 않았습니다.

컴퓨터 제어 도구를 통한 별도의 수동 입력 검증은 앱 승인 대기가 만료되어 완료하지 못했습니다. 위 결과는 앱 자체의 자동 Qt 시험이며 외부 도구로 모든 메뉴와 Windows 파일 대화상자를 조작했다는 의미는 아닙니다.

## 배포 확인

- Python·Qt·VTK·OCCT를 포함한 PyInstaller 폴더형 EXE.
- HTML/JS 화면, QtWebEngine, pywebview, Uvicorn을 포함하지 않는 네이티브 경로.
- 초기 패키지에서 빌드 환경 Poppler의 ICU DLL이 Qt용 Windows ICU를 가리는 문제를 발견했습니다. 패키지에서 해당 DLL을 제외하고 Windows의 ICU를 사용하도록 수정한 후 배포 EXE 시험을 통과했습니다.
- 자동 저장 경로는 기존 웹 앱과 구분한 `native-autosave.cad.json`입니다.
- 1.x의 편집 가능한 CAD JSON과 이력 스키마를 그대로 읽습니다.

## 실제 실행하지 않은 범위

OpenAI 유료 호출, 설치된 Ollama 모델의 실제 추론, Fusion/Inventor 내부 F3D/IPT 실변환은 시험하지 않았습니다. 외부 공급자는 모의 응답과 오류·형상 재검증 시험으로 확인했습니다. F3D/IPT 변환은 STEP 기반 솔리드 전달용이며 Autodesk의 스케치·구속·피처 타임라인을 재구성하지 않습니다.

영구 위상 추적, 폐루프 조립, 동역학, 제조·강도·규격 인증은 지원 범위가 아닙니다. 미완료 스케치의 앱 충돌 복구는 지원하지 않습니다.

1.2 버전의 기존 커널 및 웹 화면 시험은 [이전 검증 기록](docs/legacy-validation-1.2.md)에 별도로 보존했습니다.
