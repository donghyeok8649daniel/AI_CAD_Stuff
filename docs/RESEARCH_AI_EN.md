# Research and AI update · 2.12.0

- **Unlimited repair**: AI → Model / wait settings → Unlimited. Codex and Ollama now continue geometry-validation revisions beyond the old three/six-attempt ceiling, until validation passes or you cancel. A fully executed, renderable draft is retained during the current app session when available. Invalid geometry cannot be applied. Authentication, connectivity and quota errors stop requests until resolved. Paid OpenAI API repair remains limited to three plans per request, even with unlimited waiting.
- **Codex weekly usage**: choose Codex and click **Refresh Codex connection / usage**. Remaining percentage, available short-window limits, reset time and lookup time are shown. Limits are shared across the account. Exact remaining token counts are unavailable. This read-only check neither generates a model response nor buys credits or resets limits.
- **Part roles / colors**: select one or multiple parts, then **Part role / default color** in Properties. Structures/guards are white, electrical parts/motors/sensors yellow, drive/load-transfer parts/grips/shafts green, specimens gray. Uncheck the color option to keep custom colors. Existing projects are not recolored on load; undo and project save preserve roles.
- **Cylinder-bound sliders**: the joint alignment dialog and AI tool can bind sliders to actual shaft/bore faces, including tilted axes. Translation limits and fixed clocking are preserved. A kinematic slider is not proof of physical anti-rotation hardware.
- **Experiment handoff**: File → Export → **Fatigue test protocol / data template**, or specimen Properties. The ZIP contains specimen STEP geometry, a protocol/snapshot JSON with checksums, empty measurement CSV headers and notes. Undecided force, frequency and peak-to-peak stroke remain blank.

The handoff is not an instrument controller, machine rating, fatigue solver or `.ftgsim` importer. Physical seconds/Hz are not mapped to research model time. Measured force, crosshead displacement and independently measured gauge strain are separate channels. Base-specimen areas are nominal, not a check of feature-altered sections. Aluminum and silicon wafer are separate materials; wafer test method/fixtures remain unverified. Circuit/MCU simulation and external fatigue solver execution remain deferred.
