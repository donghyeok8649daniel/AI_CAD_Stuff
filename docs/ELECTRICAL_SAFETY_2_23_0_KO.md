# 쇼트·과전류·열 검토

전장 작업창의 검토는 저장된 배선도와 입력된 동작점을 사용합니다. 검토를 누르면 부품을 움직이거나 전원을 켜지 않고, 배선과 정격을 다시 확인합니다. 원래 프로젝트에 정격이 없다면 해당 항목은 **미검증**으로 표시합니다.

## 자동으로 확인하는 것

- 전원 양극과 리턴이 부하 없이 전선·닫힌 접점으로 이어지는 쇼트 경로. 전선의 길이·단면적이 아직 없는 경우에도 물리 결선에 있는 쇼트는 표시합니다. 이 경우 전류를 임의 계산하지는 않습니다.
- 서로 다른 전압 또는 반대 극성 전원이 직접 병렬 연결된 경우와 전원으로 전류가 역류하는 경우.
- 입력한 허용 전류를 넘는 전선·접점·전원·부품의 정상 전류와 별도로 입력된 모터 기동 전류.
- 확인된 DC 전압 상한 초과, 극성 캐패시터와 보드 전원 역극성, 저항·코일·전선의 허용 열 손실 초과.
- 퓨즈 전류 정격 초과와 연결된 전원 전압에 비해 퓨즈 DC 전압 정격이 부족한 경우. 같은 GND를 쓰는 별도 고전압 회로를 낮은 전압 회로의 퓨즈에 잘못 귀속하지 않도록 검사합니다.

## 온도는 어떤 때 계산하는가

온도 칸은 다음 값이 모두 명시된 경우에만 표시합니다.

1. 실제 열 손실(W). 저항·전선·코일·닫힌 접점은 저항 손실, 배터리는 내부저항의 `I²R` 손실을 사용합니다. 모터·MCU·일반 부하는 입력 전력 중 실제 열이 되는 비율이 필요합니다. 모터의 기계 출력까지 열이라고 가정하지 않습니다.
2. 해당 조립과 냉각 환경에서의 열저항(K/W).
3. 주위온도(°C).
4. 선언한 듀티(0–1).

이 값으로 `주위온도 + 열 손실 × 듀티 × 열저항`이라는 정상상태 평균 손실 추정을 표시합니다. 입력한 허용 온도를 넘으면 오류를 표시합니다. 기동 순간의 온도·열 과도·국부 과열은 이 계산으로 판단하지 않습니다. 캐패시터의 정상상태 DC 전류가 0 A여도 ESR·리플·누설 손실을 모르는 상태이므로 온도를 0이나 주위온도로 대신 표시하지 않습니다.

[TI의 Semiconductor and IC Package Thermal Metrics](https://www.ti.com/lit/an/spra953c/spra953c.pdf)는 열저항이 패키지만의 상수가 아니라 PCB·배치·냉각 환경에 따라 달라진다고 설명합니다. 다른 시험 PCB의 데이터시트 열저항을 실제 조립에 자동 적용하지 않습니다.

## 정격 편집과 저장

부품을 선택하고 확인한 정격·출처를 입력한 뒤 **입력으로 다시 점검**을 누릅니다. 빈 칸은 0이라는 뜻이 아니라 미입력입니다. 숫자 0이 의미가 있는 듀티·주위온도는 빈 칸과 구별합니다. **정격 변경 저장**은 이 창의 작업 사본에만 변경을 돌려줍니다. 부모 전장 창에서 변경을 저장해야 CAD 프로젝트에 반영됩니다. 닫기·취소하면 원래 결선과 정격을 유지합니다.

퓨즈는 확인한 전류 정격과 DC 전압 정격을 검토하는 닫힘·개방 접점입니다. 시간-전류 곡선·차단용량·온도 보정 없이 자동 용단 시간이나 보호 성공을 만들어내지 않습니다. AC 전압 정격만 알려진 제품은 DC 정격을 미검증으로 남깁니다. 모든 항목이 입력되더라도 이 결과는 입력 모델의 검토이며 실물 장치의 안전 인증이 아닙니다.
