# 2.12.0 사용법

- **무제한 AI 수정**: AI 패널 → 모델·대기 설정 → 무제한. Codex·Ollama는 기존 3/6회 검증 제한을 넘겨 수정합니다. 취소 시 가장 나은 계산 가능한 초안이 있으면 미리보기로 보존합니다. 간섭이 남은 초안은 적용할 수 없습니다. [자세한 동작](AI_REPAIR_KO.md).
- **주간 잔여 사용량**: AI 패널에서 Codex 선택 → **Codex 연결·사용량 새로고침**. 주간 잔여율, 제공되는 단기 한도, 초기화 시각과 조회 시각이 표시됩니다. 연결 창에서도 확인할 수 있습니다. 계정 전체 공유 한도이며 실제 잔여 토큰 개수는 제공되지 않습니다. 자동 구매·사용량 초기화·유료 모델 호출은 하지 않습니다. 조회 실패는 0%나 100%로 표시하지 않습니다.
- **부품 기본색**: 부품 선택 → 속성 → **부품 역할 / 기본색**. 여러 부품도 Shift/범위 선택 후 한 번에 바꿀 수 있습니다. 구조/보호는 흰색, 전장/모터/센서는 노란색, 구동/하중 전달/그립/축은 초록색, 시편은 회색입니다. 역할 기본색 적용을 끄면 사용자 색상을 유지합니다. 되돌리기와 저장/열기가 지원됩니다. 기존 파일을 여는 것만으로 재색칠하지 않습니다.
- **실제 원통 가이드의 슬라이더**: 조립 → 관절 축·구멍 동심 정렬에서 슬라이더도 선택할 수 있습니다. 두 원통 면의 실제 중심선을 사용하며 기울어진 가이드에서도 Z 이동과 고정된 회전 방향을 보존합니다. AI도 같은 도구를 사용합니다. 하나의 원형 축만으로 물리적인 회전 방지가 입증되지는 않습니다.
- **연구 준비 패키지**: 시편 속성 또는 파일 → 내보내기 → **피로시험 조건 / 데이터 양식**. 시편·재료·시험 계획을 확인하고 ZIP으로 저장합니다. 시편 STEP, 형상/치수/해시와 계획 조건 JSON, 측정 CSV 머리글 양식, 설명서를 포함합니다. 계획한 하중·Hz·왕복거리가 없으면 빈칸을 유지합니다.

연구 패키지는 실험 데이터 교환 준비용입니다. 실측 초·Hz와 연구 모델 시간은 자동 연결하지 않습니다. 실제 힘 N, 크로스헤드 변위 mm, 독립 측정한 변형률은 별도 채널입니다. 단면적은 기본 시편 치수에 따른 명목값이고 피처가 있는 실제 단면 검증을 대신하지 않습니다. Al과 Si wafer 재료를 구분하며 wafer 방식은 미정으로 보존합니다. 연구 솔버 실행·.ftgsim 자동 가져오기·MCU/회로 시뮬레이션은 포함하지 않습니다.

무제한 수정은 임의의 요청이 반드시 해결된다는 보장은 아닙니다. 형상 검증, 간섭 검사와 기존 설계 보존 조건을 완화하지 않았습니다. 구독 한도나 연결 문제가 발생하면 복구 후 이어가야 합니다.
