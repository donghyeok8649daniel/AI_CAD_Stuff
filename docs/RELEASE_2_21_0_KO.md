# 2.21.0 · 전장 부품, 배선과 작업창

전장 작업의 첫 화면을 새로 만들었습니다. 미등록 CAD 부품·등록 모델·물리 단자·전원과 배선을 한 곳에서 찾고 편집합니다. 제품 목록은 제품군 참고자료와 실제 등록 가능한 모델을 분리해 보여줍니다. 공식 자료로 확인한 정확한 제품 12개와 추가 보드 핀맵 2개를 넣었습니다. 목록은 총 98개이며 실제 등록 가능한 모델은 43개에서 55개로 늘었습니다. 보드 핀맵 11개·제품 단자 모식도 25개·수동 정격 등록 모델 19개와 제품군 탐색 자료 43개를 구분합니다.

현재 작업물의 고립된 단자, 빠진 제품 등록, 전원·귀환 연결, 배선 끝점과 노드 불일치를 별도로 표시합니다. 전장 함체나 미사용 GPIO를 전력 부품·오류로 자동 바꾸지 않습니다. 등록·모식도·전원 편집을 사본에서 진행하고 마지막 저장으로 한 작업 기록에 반영합니다. 취소·실행 취소·기존 프로젝트 저장을 검증합니다.

AI에도 등록과 물리 전원 경로의 누락 상태를 전달합니다. 부품 삭제나 임의 정격 입력으로 점검을 숨기지 않도록 안내합니다. 기존 프로젝트를 자동 수정하거나 사용자 정의 회로를 알려진 칩 모델로 바꾸지 않습니다.

지원 범위와 실제 사용 순서는 [전장 작업창 안내](ELECTRICAL_WORKSPACE_KO.md)를 확인하세요. 전원 공급기 HDR-60-5·LRS-600-24, REF5025AID 전압 기준 IC, 전류/환경 센서·ADC·GPIO 확장·PWM/모터 드라이버·AS5600 모듈을 추가했습니다. 확인한 출처와 단자 범위는 제품 자료 화면과 [추가 제품 출처 문서](ELECTRICAL_CATALOG_2_21_0_KO.md)에 표시합니다. 회로의 정적 점검·기존 DC/구동 검토와 실제 MCU 코드 실행·실물 구동 검증은 구분합니다.
