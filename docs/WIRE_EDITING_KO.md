# 전선 추가와 삭제 · 2.19.1

상단 **회로도** 버튼이나 메인 회로도 작업 공간에서 **전선 추가…**를 누릅니다. 시작·도착 부품의 실제 핀 또는 단자를 고르고, 이름·색·실제 전선 길이(mm)·도체 단면적(mm²)을 입력합니다. 먼저 핀을 선택하면 시작 단자에 반영됩니다. 보드 핀이 필요하면 해당 CAD 부품에 전장 제품 모델을 등록하세요.

저항률 기본값은 실온 구리 0.01724 Ω·mm²/m입니다. 다른 도체는 값을 바꿉니다. 허용 전류 0은 정격 미입력을 뜻합니다. 길이·단면적은 사용자가 입력해야 하며 도체 단면적은 피복 바깥 지름과 다릅니다.

추가한 전선을 클릭하고 **선택 전선 삭제 · Delete**를 누르거나 회로도에 포커스가 있을 때 **Delete**를 누르면 제거됩니다. 다른 부품·핀의 연결은 유지됩니다. 같은 노드에 있던 두 단자 사이에 전선을 넣으면 선택한 도착 단자만 분리해 전선으로 연결합니다. 따라서 전선을 삭제하면 그 연결이 실제로 끊어집니다.

전선 추가·삭제는 프로젝트의 전장 데이터와 작업 기록에 저장되며 **Ctrl+Z**로 되돌릴 수 있습니다. 기존 전장 편집 창에서도 전선 값과 색을 바꿀 수 있습니다. 기존 노드 연결선 중 별도 전선 부품으로 등록하지 않은 선은 핀을 선택한 뒤 연결 편집에서 해제합니다.

실물 배선 보기에서 저장된 핀 위치를 잇는 전선 색을 표시하고, 단선 또는 OFF 상태의 전선은 점선으로 표시합니다. 회로 계산은 기존 DC·도통·전압강하 모델을 사용합니다. MCU 펌웨어 실행이나 모든 과도 응답의 시뮬레이션을 뜻하지 않습니다.
