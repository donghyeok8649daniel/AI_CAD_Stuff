# 전원 연결 설계 · DC 배선 확인

전장 창의 **전원 연결 설계…**에서 배터리 + → 스위치 → 공급선 → 부하 → 리턴선 → 배터리 − 경로를 한 번에 작성할 수 있습니다. 기존 회로를 덮어쓰지 않으며, 새 노드와 부품 ID를 붙여 미리보기에서 계산한 뒤 **기존 회로에 추가**를 눌러야 반영됩니다. **회로도 미리보기…**는 실제 노드·단자·전원 OFF 상태를 보여 줍니다. CAD 부품 연결은 선택 사항이며 회로만 생성해도 됩니다.

배터리 개방전압, 부하의 정격 전압·작동점 전류, 양쪽 전선의 실제 길이·도체 단면적은 반드시 입력해야 합니다. 기본 0 Ω 내부저항은 **이상적 전원 가정**이고 기본 0.01 Ω 닫힌 접점저항과 0.01724 Ω·mm²/m 저항률은 근삿값입니다. 실제 배터리·스위치·전선 자료로 바꿔야 합니다. 전선 SKU를 고르면 공식 제조사 자료의 **명목 DC 저항**을 길이에 적용하고 제품 출처를 저장합니다. 해당 자료의 자유공기 전류를 케이스 내부 하네스의 허용 전류로 자동 적용하지 않습니다.

보고서의 `WARN · 용량 미검증`은 배터리·스위치·공급선·리턴선의 허용 전류가 입력되지 않았다는 뜻입니다. 입력 한계를 넘으면 `FAIL`을 표시합니다. `CHECK`는 **입력한 한계와 계산값의 비교**일 뿐 제품 정격이나 제작 안전 인증이 아닙니다. 계산은 배터리 개방전압×전류, 배터리 단자 출력, 내부저항 및 양쪽 전선의 `I²R` 손실, 부하 전압·전력을 구분합니다. 모터 기동 전류를 입력한 경우 정상 운전과 별도의 등가저항 시나리오에서 용량도 다시 확인합니다.

AI 설계에도 `power_path` 도구를 사용할 수 있습니다. AI에 실제 배터리 전압, 부하 전압·전류, 공급선 길이·단면적, 리턴선 길이·단면적의 **7개 값을 명시**하세요. 예: “실측 5 V 전원, 5 V 0.2 A 보드, 공급선 250 mm·0.5 mm², 리턴선 350 mm·0.5 mm²의 DC 전원 경로를 설계해 줘.” 이는 입력 형식을 보이기 위한 가상 예시로, 특정 제품 권장 사양이 아닙니다. 값이 빠졌다면 AI가 임의로 채운 경로를 적용해서는 안 됩니다.

이 기능은 **DC 저항 등가와 정적 도통**만 평가합니다. MCU 코드·GPIO 논리, 모터 드라이버/PWM, 퓨즈 작동, 배터리 수명, 커넥터 핀 배치, 실제 3D 전선 경로, 발열·안전 규격·SPICE/ANSYS 해석은 포함하지 않습니다. 부하 전압의 ±10% 알림도 데이터시트의 최소·최대 허용 전압을 대신하지 않습니다. 제작 전 실제 제품 자료와 측정값으로 결선·극성·용량을 확인하세요.
