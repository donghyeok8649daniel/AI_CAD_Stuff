# Prompt CAD Studio v3.1.1

BOM이 200행에서 막히거나, 기존 146행을 AI 설계 자료로 전달할 때 60,000자 제한에 걸리던 문제를 수정했습니다.

- CSV·TSV·Excel과 프로젝트의 BOM을 최대 512행까지 보존합니다. 서로 다른 행을 합치거나 기존 부품을 삭제하지 않습니다.
- AI에 전달하는 BOM 자료 한도는 300,000자입니다. 모든 행 ID·수량·제품·치수·출처·미확인 항목을 포함하며, 한도를 넘으면 오류로 알립니다.
- 원본 100,000자, 입력 파일 2 MB, 프로젝트 CAD 부품 256개와 한 번의 AI 작업으로 추가하는 부품 32개 제한은 유지됩니다. 512행은 BOM 용량이며 CAD 몸체 512개를 뜻하지 않습니다.

3.1.0의 선택 부품 출력 미리보기, 자동 자세 추천, 수동 이동·회전, 여러 출력판과 STL ZIP, 볼트·너트 제외 기능은 유지됩니다. 자동 자세는 형상 기반 추정이며 실제 서포트 생성·슬라이싱과 출력 성공 검증은 외부 슬라이서에서 수행합니다.

BOM 연결은 제조사 형상 일치, 실제 공차·강도·전기 정격이나 하드웨어 동작의 인증이 아닙니다. 제품 또는 수량이 미정인 행은 계속 미정으로 남습니다.
