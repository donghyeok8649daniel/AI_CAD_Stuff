# Prompt CAD Studio 3.0.0

기존 설계·회로·기록·PCAD 파일을 유지하면서 AI와 전장 개발 흐름을 개편했습니다.

아래 작업 단계 목록과 툴팁은 자동으로 붙던 `AI` 접두사 없이 기능 이름을 표시합니다. 기존 프로젝트의 단계에도 적용되며 원본 이력·실제 생성 모델·복원 정보와 직접 지정한 이름은 보존합니다.

## AI 창과 모델

상단 **설계 명령 / AI**, 보기 메뉴 또는 `Ctrl+Shift+A`로 AI 탭을 앞으로 엽니다. 뷰포트에서는 `A`도 사용할 수 있습니다. 계산 중이나 속성 입력란에 포커스가 있어도 명시적인 AI 열기가 작동합니다. AI 탭이 활성화돼 있으면 설계 대상을 선택해도 속성 탭으로 화면을 빼앗지 않습니다.

**Codex 연결·사용량 새로고침**으로 실제 계정의 모델 목록을 읽습니다. 자동 연결은 설치된 Codex 앱 CLI를 우선 찾고, 오래된 기본 경로를 갱신합니다. 사용자가 지정한 별도 경로는 보존합니다. 이 PC의 최신 CLI는 `gpt-6.1-sol`과 Low, Medium, High, Extra high, Max, Ultra를 실제 제공했습니다. 다른 환경에서는 반환된 모델·단계만 제공합니다. Max와 Ultra는 별도 설정입니다.

생성 중 모델·추론 단계를 바꿔도 응답과 초안은 보존합니다. 진행 중인 요청과 재시도는 기존 설정으로 마무리하고 다음 설계 계획·검증 수정 단계부터 새 설정을 사용합니다. 적용 기록에는 실제 생성 모델을 남깁니다. 설계 자체가 바뀐 경우의 오래된 초안 적용 차단은 유지합니다.

일시적인 통신 단절은 같은 입력·설정으로 재시도하고, 완성된 JSON 응답은 마지막 연결 종료 때문에 버리지 않습니다. 정상 서버의 모든 오류를 재시작으로 처리하지 않습니다. 인증·사용량·지원하지 않는 설정은 무한 재요청하지 않습니다. 생성 재시도는 구독 사용량을 사용할 수 있으며 유료 API로 자동 전환하지 않습니다.

## 펌웨어와 라이브러리

**도면 / 해석 → Codex 펌웨어 생성 / 검토… → 라이브러리**에서 외부 소스 폴더·ZIP을 가져옵니다. 정확한 버전/리비전·파일·해시를 기록하고 소스를 미리 봅니다. **의존성 추가…**는 고정 버전의 외부 패키지 정보를 기록하며, 설치·연결 미확인 상태를 유지합니다.

생성 시 실제 등록 보드·핀·배선과 선택 라이브러리의 목록·제한된 발췌를 전달합니다. 원본 라이브러리 소스는 생성 코드가 덮어쓰지 않으며 PCAD 저장·재열기와 내보내기에 포함됩니다. 내보낸 `firmware-dependencies.json`의 검색 경로와 `libraries/`를 함께 사용하세요.

명시적인 **소스 검사**는 Python 문법·확인 가능한 import/C include·보드/배선 대응을 점검합니다. 정확한 SDK·컴파일러·링커·OS·실기 조건이 없으면 전체 대상 빌드와 동작 성공으로 표시하지 않습니다. 소스는 자동 실행·설치·플래싱하지 않습니다. 기존 GPIO 추적은 전체 MCU/Linux/FOC 에뮬레이터가 아닙니다.

## 실물 전장 진단

AI 패널 또는 **도면 / 해석 → 실물 사진 / 증상 · 전장 진단…**에서 증상·운전 조건·관련 부품·사진·선택 계측값을 입력합니다.

- **회로·입력값 진단 (로컬)**은 저장 회로의 단선·전원 경로·쇼트·정격·발열 조건과 입력값을 비교하고 미확인 조건을 표시합니다.
- **Codex 사진·증상 진단 · 전송**은 선택 사진·회로·증상·계측값을 기존 ChatGPT 로그인으로 보내 확인이 필요한 가설과 추가 확인 방법을 제공합니다. 창 열기와 사진 첨부만으로 전송하지 않습니다.
- **보고서 저장…**은 근거와 미확인 사항을 별도 JSON/TXT로 저장합니다. CAD와 배선은 자동 변경하지 않습니다.

사진만으로 숨은 단선·실제 도통·전선 허용 전류·온도·안전한 동작을 확정하지 않습니다. 전원이 연결된 상태의 저항/도통 입력은 확인 대상으로 표시하고 사용자 입력 실측과 AI 가설을 구분합니다.

## 검증 범위

실제 구독 gpt-6.1-sol로 Pi 4 다중 파일 후보와 외부 순수 Python 파서 연동을 생성해 소스 검사·저장/재열기·내보내기를 확인했습니다. 생성 소스는 실행하지 않았습니다. Ultra 요청·합성 사진 시험·네이티브 흐름은 각각 검증 기록에 남깁니다. 실제 MCU 대상 SDK 빌드·장비 동작·실물 고장 진단 정확도는 별도 검증이 필요합니다.

[OpenAI 모델 문서](https://developers.openai.com/api/docs/models/gpt-6.1-sol)와 [Codex app-server 문서](https://developers.openai.com/codex/app-server)를 참고했으며, 선택 목록은 설치된 CLI가 현재 계정에 반환하는 값을 사용합니다.
