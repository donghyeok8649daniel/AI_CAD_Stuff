# 선택, 실제 관절 구조와 부품별 출력

## 선택 해제와 시점 회전

뷰포트 위 **회전 Esc** 또는 **Esc**를 누르면 선택과 범위 선택을 해제하고 시점 회전 모드로 돌아갑니다. 그룹 자체나 조립 구속은 삭제되지 않습니다. 회전 모드에서는 클릭으로 부품을 다시 잡지 않습니다. **회전 Esc**를 다시 누르거나 점/선/면/부품 선택 필터를 고르면 선택 모드로 돌아갑니다.

**그룹 선택**은 그룹 전체/개별 부품 선택 전환입니다. 전환하면 현재 선택도 비웁니다. **그룹 해제**는 저장된 그룹 자체를 없애는 별도 기능입니다. Shift+클릭으로 추가/해제, Shift+드래그로 범위 추가, B로 범위 선택을 사용할 수 있습니다.

아래 **XYZ 축**의 선이나 끝을 클릭하면 해당 축 방향으로 바라봅니다. 축 정면에서 가운데를 다시 누르면 반대 방향입니다. 등각 시점의 축 중심은 등각으로 복귀합니다. 축 위에서 드래그해도 자유롭게 시점이 회전합니다. 줌과 바라보는 중심은 유지되며 실제 부품의 위치는 바뀌지 않습니다. 부품 자체 이동·회전은 M을 사용하세요.

## 실제 관절 CAD

**조립 → 실제 관절 구조**에서 회전 관절의 축 지름, 부시 내경 여유, 하우징 길이·벽 두께, 플랜지·장착 구멍과 축 방향 여유를 입력하세요. **설계에 적용**하면 다음 7개 일반 CAD 부품을 생성합니다.

- 고정 장착 플랜지, 하우징
- 하부·상부 부시
- 회전 축, 출력 장착 플랜지, 축 고정 칼라

별도 숨겨진 운동 모델 대신 기존 **회전 구속과 강체 구속**으로 연결합니다. 생성 후 브라우저에서 부품과 피처를 편집하고, **관절 구동**에서 회전할 수 있습니다. 기존 회전 관절을 선택하면 그 축에 같은 구조를 장착하고 기존 기준 부품과 움직이는 부품에 각각 연결합니다. 기존 부품을 자동 절삭하지 않으므로 미리보기의 간섭을 확인하세요.

내장 구조는 편집 가능한 기구 초안입니다. 축·칼라·출력 플랜지의 체결 나사/키, 베어링 규격, 가공 공차 등급, 윤활과 하중 정격을 완성한 제품은 아닙니다. 입력하는 여유는 형상 간 지름 차이이며 공인 끼워맞춤 등급이 아닙니다.

## AI에 커스텀 관절 요청하기

**설계 명령 / AI**에서 부품 구성, 실제 치수, 여유와 움직임을 함께 적으세요. 고정 템플릿으로 분기하지 않고 일반 부품 생성·구멍·돌출·조립 구속 도구를 조합합니다. 예:

> 하우징 외경 32, 내경 12.3, 길이 24 mm. 지름 12 mm 축이 회전하는 관절을 실제 부품으로 만들어줘. 출력 플랜지는 40×28×5 mm로 하고, 축에 고정 연결해줘. 회전 범위는 ±90도.

수정할 때는 부품이나 피처를 선택하고 변경 치수를 요청하세요. 축만 굵게 바꾸면 상대 구멍과 간섭할 수 있으므로 상대 부품도 함께 지정하는 편이 좋습니다. 조립 위치 변경은 관절 구동 도구를 쓰도록 연결되어 있습니다. AI가 요청한 구조를 모두 충족하는지는 결과와 가정을 확인한 뒤 **검증된 초안 적용**으로 반영하세요.

## 따로 보기와 부품별 파일

뷰포트 위 두 번째 도구 줄과 부품의 우클릭 메뉴에 기능이 있습니다.

| 버튼 | 사용 방법 |
| --- | --- |
| 선택만 보기 | 선택 부품만 표시. 다시 누르면 이전 표시 상태로 복귀 |
| 모두 보기 | 숨긴 부품 전체 표시 |
| 분해 보기 | 선택 부품들을 X/Y/Z로 벌려서 검사. 선택이 없으면 전체. 간격 0은 조립 상태. 원본 위치·구속은 유지 |
| 부품별 내보내기 | 선택 부품을 각각 STEP, STL 또는 둘 다 저장하고 ZIP으로 묶음 |

개별 출력은 **부품별 원점 / 바닥 Z=0**과 **현재 조립 위치 유지** 중 고를 수 있습니다. 전자는 부품의 원래 로컬 축을 기준으로 XY 중심과 바닥을 정렬합니다. 프린터의 최적 출력 방향을 자동 결정하는 기능은 아닙니다. ZIP의 `parts.json`에 부품 ID, 이름, 원래 위치, 체적과 파일 목록이 있습니다. 외부 부품을 참조하는 절삭도 전체 조립에서 평가한 최종 형상으로 출력합니다. 원본 CAD는 수정하지 않습니다.

전체 형상의 F3D/IPT 변환은 기존 Autodesk 연결 내보내기를 사용하세요. 새 부품별 ZIP은 STEP/STL을 지원합니다.
