Prompt CAD Studio v3.2.1

부품 수가 많아 프로젝트를 열지 못하는 문제를 수정했습니다. v3.1.1의 부품·형상 자산 256개 제한을 제거했습니다. CAD 부품, 가져온 형상 자산, 조립 구속, 조인트 기준, 스케치, 치수 연결, 구동 연결, 그룹과 그룹 구성원에도 프로젝트 개수 상한을 두지 않습니다.

- 저장된 BOM 행 개수 제한과 BOM 설계의 오래된 프로젝트 256개 제한을 제거했습니다. AI 요청 한 번당 작업량은 별도로 관리하며 같은 프로젝트에서 묶음으로 진행할 수 있습니다.
- 깊게 연결된 조립 부품도 Python 재귀 깊이에 막히지 않도록 부모부터 순서대로 계산합니다. 순환 참조, 없는 부품 참조, 중복 ID 검사는 유지합니다.
- CW·CCW 회전 버튼에서 Qt 클릭 신호가 관절 ID를 덮어쓰던 오류를 수정했습니다.
- 기존 파일 형식과 전체 작업 기록, 가져온 형상 자산, 조립 위치를 보존합니다. 파일을 분할하거나 부품을 삭제해서 제한을 우회하지 않습니다.

검증: 실제 335개 부품·387개 자산·105개 기록이 있는 프로젝트를 열기→저장→재열기했으며, 1,025개 부품·자산·그룹과 1,024개 구속·조인트 기준, 깊은 조립 및 분기 기록도 검사했습니다. 새 소스 19개와 Windows EXE의 저장 경로 20개 검사가 통과했습니다. 이 수량 검사는 형상 메시를 생성하는 속도나 실제 장비 동작을 인증하는 검사가 아닙니다.

부품 개수의 고정 상한은 제거했지만 PC의 RAM, 파일 크기, 분석 작업량에 따른 자원 한계는 있습니다. PCB·회로 계산, 펌웨어 및 AI 요청별 작업 한도는 CAD 부품 개수와 별도로 적용됩니다.

Windows에서는 PromptCADStudioUpdater.exe로 업데이트하거나 ZIP을 새 폴더에 풀어 사용하세요. 실행 파일 하나만 옮기지 말고 ZIP의 전체 폴더를 사용하세요. 원래 PCAD 파일을 변경할 필요 없이 새 앱으로 열 수 있습니다.
