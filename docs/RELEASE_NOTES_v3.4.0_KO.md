# Prompt CAD Studio v3.4.0

기존 `.pcad`를 AI로 수정할 때 전체 작업기록과 분기를 유지하고, 현재 단계 뒤에 검증된 작업을 이어 붙이도록 개선했습니다. 업데이트는 한 정식 설치 경로를 교체하며 프로젝트·설정·로그인 자료를 보존합니다. PCB 작업창은 작은 화면에서도 버튼과 입력칸을 읽고 스크롤해서 사용할 수 있도록 수정했습니다.

- 기존 설계를 연 상태에서 평소처럼 설계 요청을 입력하면 현재 이력 단계의 요약을 함께 전달합니다. 파일의 전체 기록은 유지하며, 생성 중 문서나 이력이 바뀐 초안은 적용 전에 다시 확인합니다. 자동 이력 요약과 사용자가 첨부한 참고자료 한도는 분리됩니다.
- PCB 작업을 **부품 배치 → 배선 만들기 → 검사·최적화**로 나눴습니다. 제품 찾기, 대응 핀 정렬, 고정 부품을 보존한 배치 미리보기, 비아·현재 층 검사와 2·4·6·8층 비교를 제공합니다. 로컬 초안의 실행 취소와 전체 CAD 저장을 구분합니다.
- 저장된 실제 패드·핀 규격과 제품 참고정보를 연결합니다. 카탈로그 논리 핀을 실제 풋프린트 치수로 추정하지 않으며, 외부 보드 정렬에는 직접 확인한 기준면·자세·검토 기록이 필요합니다. 높이·뒤집기 등 미확인 정렬은 미리보기로 남깁니다.
- 제품·전원 조건과 BOM·가격 입력은 출처와 조건을 구분합니다. 수동 견적과 명시적으로 채택한 AI 추정은 별도로 다루며, 모르는 정격·가격을 자동으로 채우지 않습니다. 실제 공급업체의 현재 가격을 보장하는 기능은 아닙니다.
- 새 standalone updater를 다시 빌드했습니다. 소유 파일·해시와 실행 중 CAD를 확인한 뒤 기존 정식 설치를 교체합니다. 사용자 자료와 알 수 없는 파일을 일괄 삭제하지 않으며, Windows가 보호하는 기본 앱 선택을 임의로 덮어쓰지 않습니다. 검증용 사본을 별도 정식 앱이나 파일 연결로 등록하지 않습니다.
- 기존 4층 PCB 저장과 명시적으로 지정한 유연 전선의 기계 간섭 제외 기능을 유지합니다.

검증은 다음 범위에서 완료했습니다.

- 동결 소스 1,004개 파일과 새 EXE의 앱 모듈 298개 코드 일치, 새 updater 코드와 패키지 CRC·멤버 해시 확인. 이전 소스 검사는 근거로 연결했으며 다시 합산하지 않았습니다.
- 실제 저장 파일 두 개에서 기존 105개·359개 기록을 유지한 채 오프라인 시험 작업을 각각 하나 추가하고 저장·재열기했습니다. 원본은 수정하지 않았습니다.
- 새 PCB 화면은 Qt 검사에서 세 가지 창 크기를 확인했고, 실제 Windows 1435×900 창에서도 버튼·입력칸·스크롤·층 선택 목록을 확인했습니다. R1에서 발견한 화면 잘림은 수정한 R2에서 재확인했습니다.
- 실제 Windows 앱에서 기존 391개 부품·359개 기록의 시험기 사본과 원래 70×60 mm 4층 PCB를 열고 모델 전경·전장 확대 화면을 확인했습니다. 카메라와 임시 표시만 조정했고 설계는 저장하지 않았습니다. 검증용 앱 정상 종료와 자체 프로세스 부재를 확인했습니다.
- 새 updater는 실제 Windows 환경에서 창을 띄우고 스스로 닫는 검사를 통과했습니다. 이 검사는 다운로드·설치·재시작을 수행하지 않습니다.

라이브 AI 요청이나 실제 장비 구동은 검증에 사용하지 않았습니다. 큰 설계의 첫 열기에는 이력·현재 형상·메시·간섭·관절 상태 계산 비용이 남아 있으며, 일반적인 속도 개선이나 모든 화면·DPI를 보장하는 검사는 아닙니다. 정식 설치 반영과 탐색기 `.pcad` 더블클릭은 별도 확인 항목입니다.

층 수 비교는 보장된 최소 층수, 제조 적층 또는 Gerber 승인이 아닙니다. 정렬·간섭 표시·회로 계산·CAD 사진은 실제 결합, 강도·공차·전류·열·펌웨어·하드웨어의 실물 승인을 뜻하지 않습니다.
