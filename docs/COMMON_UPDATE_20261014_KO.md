# 공통 CAD 업데이트 사용 안내 · 2026-10-14

이 안내는 현재 통합 소스에 추가된 기능을 설명합니다. 실제 Windows 창의 네이티브 검수와 최종 EXE 제작·배포는 아직 완료되지 않았습니다. 기존 설치본에서 아래 도구가 모두 보인다는 뜻은 아닙니다. G474 보드·펌웨어 통합은 별도 진행 중이며, 이 업데이트 안내에서 완료된 기능으로 취급하지 않습니다.

## 선택 부품 숨김·반투명·복원

CAD 뷰포트 위의 선택 도구 근처에 **선택 수 / 숨김 / 반투명 / 복원 / 숨긴 부품** 줄이 있습니다. 먼저 부품을 선택한 뒤 사용하세요. 여러 부품을 함께 선택할 수 있습니다.

- **숨김**: 선택한 부품을 일시적으로 화면에서 숨깁니다.
- **반투명**: 기본 클릭은 불투명도 35%입니다. 옆 메뉴에서 35%, 60%, 100% 또는 **직접 조절…**을 선택합니다. 직접 조절을 취소하면 직전 불투명도로 돌아갑니다.
- **복원**: 선택 부품의 임시 표시 변경을 복원합니다. 옆 메뉴의 **임시 변경 전체 복원**은 임시로 변경했던 부품을 함께 복원합니다.
- **숨긴 부품**: 이름 목록에서 다시 표시할 부품을 골라 **선택 부품 표시**를 누릅니다. 현재 설계에 존재하는 숨긴 부품만 개수에 포함됩니다.

같은 도구는 선택 부품의 속성 영역과 **조립 → 부품 표시**에서도 사용할 수 있습니다. **선택만 보기 / 모두 보기**로 표시 범위를 바꾼 뒤에도 숨긴 부품 개수가 갱신됩니다.

이 도구는 보기만 변경합니다. 치수·조립 구속·부품 색·작업 기록을 저장된 설계 변경으로 만들지 않습니다. 숨긴 부품도 실제 간섭 검사에는 포함됩니다.

## 간섭 자동 조정안 확인하기

**조립 → 간섭 검사 / 조정…**을 열거나 뷰포트의 간섭 버튼을 누릅니다. 목록에서 겹친 부품 쌍을 선택하면 해당 영역이 빨갛게 표시됩니다. **자동 조정…**에서 이동할 쪽, 검색 축, 분리 여유와 최대 이동을 정한 뒤 **자동 조정안 찾기**를 누르세요.

검색은 기존 치수·구속·고정 상태를 유지하는 축 방향 이동 후보를 검사합니다. 연결된 부품이 함께 움직일 수 있으며, 고정을 자동 해제하거나 부품 삭제·그룹화로 간섭을 숨기지 않습니다. 기본 분리 여유 0.2 mm는 이동 제안용 간격입니다. 실제 프린터 공차나 조립 적합성의 확정값으로 사용하지 마세요.

제안에는 이동 부품과 ΔX/Y/Z, 이동 거리, 남은 간섭 수가 표시됩니다. 선택한 쌍의 간섭을 해소하고 새로 생기거나 증가한 간섭이 없는 후보만 적용 대상으로 제시합니다. 다른 기존 간섭이 남아 있다면 그 수를 계속 표시합니다. 정해진 후보 중 검사에 통과한 짧은 이동을 찾는 기능이며, 모든 설계의 전역 최적 해를 찾는 기능은 아닙니다.

미리보기를 확인하고 **설계에 적용**을 눌러야 원본 설계와 작업 기록에 반영됩니다. 설정이나 원본 설계가 달라지면 다시 검사해야 합니다. 현재 범위에 유효한 후보가 없으면 원본을 유지하고 이동 범위·치수·관절 배치를 검토합니다. 자동 회전·자동 절삭은 이 검색에 포함되지 않습니다.

**Codex로 조정안 재검토**는 연결된 Codex 계정·선택 모델로 설명을 요청하는 별도 자문입니다. 사용량이 적용되며 명시적으로 눌렀을 때 요청합니다. AI 답변은 정확한 형상 검사를 대체하거나 설계를 자동 변경하지 않습니다. 현재 자세의 검사만으로 전체 구동 범위·조립 가능성·공차·하중·강도를 승인하지 않습니다.

## 검사한 3D 관절 범위 재생하기

**조립 → 3D 관절 회전 재생…**에서 독립 회전 관절을 선택하고 종료 관절각을 입력합니다. 기존 회전·원통 관절의 RZ와 저장된 운동 한계를 사용합니다. 연결되거나 폐루프에서 수동으로 계산되는 관절은 선택한 구동 관절을 따라갑니다.

1. **선택 범위의 형상·간섭 검사**를 누릅니다.
2. 검사에 통과하면 **가장 큰 선택각도 기준 표시 RPM**을 입력합니다. 초기값 0에서는 재생하지 않습니다.
3. **1회 / 1바퀴 반복 / 검사한 범위 왕복**을 선택하고 **재생**을 누릅니다.
4. **중지 · 원래 자세**로 표시 자세를 복원합니다. 창을 닫아도 원본 위치·구속·이력은 바뀌지 않습니다. 중지하거나 속도·재생 방식을 바꾸면 현재 표시 RPM은 0으로 돌아가며 설정한 속도는 유지됩니다.

현재 자세에 체적 간섭이 있으면 재생을 시작하지 않습니다. 생성된 각 표본 자세를 실제 솔리드로 검사하며, 해결된 종속 관절의 실제 표본 변화도 회전 최대 2°, 이동 최대 0.5 mm 범위인지 확인합니다. 범위·표본 수·시간 한도를 넘으면 범위를 나누어 검사하세요. 표본 사이의 연속 충돌, 얇은 장애물, 공차는 별도 검토가 필요합니다.

초기 전체 검사를 마친 뒤 위치와 부품 형상이 정확히 유지된 두 부품의 간섭 판정은 재사용하고, 움직이는 부품이 포함된 쌍은 해당 자세에서 다시 검사합니다.

여러 독립 관절은 공통 진행 비율로 움직입니다. 선택 각도 범위가 짧은 관절은 비례해 느리게 움직이고, 상태 표시에는 각 관절의 현재 방향을 반영한 부호 있는 표시 RPM이 나옵니다. 왕복의 돌아오는 구간에서는 부호가 바뀌며, 1회 재생 종료 시에는 0으로 표시됩니다. 이는 화면 재생 속도입니다. 실제 모터 RPM·감속비·전원 인가·펌웨어 실행·전기구동·힘·발열·비행을 검증한 값이 아닙니다.

끝 자세가 시작 자세와 같을 때만 반복을 허용합니다. 360° 회전하더라도 나사 연결로 슬라이더가 이동해 끝 자세가 달라지면 왕복 또는 1회를 사용하세요. 몸체 간 불리언 연산처럼 구동에 따라 지역 형상이 달라질 수 있는 설계는 현재 강체 메시 재생에서 지원하지 않습니다. 원본 설계가 변경되면 검사 결과를 버리고 새 설계에서 다시 검사합니다.

## 모터 방정식과 상태 행렬 보기

**도면 / 해석 → 모터 방정식 · 상태 행렬…**은 기본적으로 기호식만 표시합니다. **도면 / 해석 → 코드 → 모터 RPM 검토…**에서 모터 입력·출처 JSON을 선택한 뒤 같은 이름의 버튼을 누르면 검증된 입력의 행렬 계수를 볼 수 있습니다. 이 행렬 창에는 파일 선택이나 시뮬레이션 실행 버튼이 없습니다.

상태는 전류 (i)[A], 각속도 ω[rad/s], 각도 θ[rad]입니다. 입력은 평균 모터 단자 전압[V]과 부하 토크[N·m], 출력은 RPM·전류[A]·각도[rad]입니다.

```text
dx/dt = A x + B u          y = C x + D u

A = [ -R/L   -Ke/L   0 ]  B = [ 1/L    0    ]
    [  Kt/J  -b/J    0 ]      [  0    -1/J  ]
    [   0      1     0 ]      [  0     0    ]

C = [ 0  60/(2π)  0 ]      D = 0
    [ 1     0      0 ]
    [ 0     0      1 ]
```

R[Ω], L[H], Kt[N·m/A], Ke[V/(rad/s)], J[kg·m²], b[N·m/(rad/s)]는 기존 DC 평균 모델과 같은 의미입니다. 양의 부하 토크는 가속도 항에서 차감됩니다. 서로 다른 상태 단위가 섞인 행렬이므로 모든 계수를 같은 1/s 단위로 해석하지 마세요.

숫자 계수에는 기존 전체 `ParameterRecord` 입력 계약이 필요합니다. 여섯 모터 상수뿐 아니라 부하·전원·전원 내부저항·초기 상태·시간 설정·출처와 선언 조건까지 해당 계약에 맞아야 합니다. 부분 입력, 잘못된 단위, 비유한 값은 받지 않으며 Kv·형상·질량으로 미입력 상수를 대신 채우지 않습니다. 저장된 JSON의 메모·출처는 데이터이며 실행하지 않습니다.

행렬 창은 선언 입력의 대수적 계수만 보여줍니다. 적분이나 RPM 응답 계산을 수행하지 않으며 실제 RPM·전류·시간은 계속 미확인입니다. BLDC/ESC/FOC, 스위칭, 발열, 전체 펌웨어/OS, 실제 장비 동작 검증은 이 행렬의 범위에 포함되지 않습니다.

## 독립 PCB 작업 공간

상단 작업 공간에서 **PCB**를 선택하거나 **도면 / 해석 → PCB 설계 · 배선 / 시뮬레이션 / BOM**을 누릅니다. PCB 초안은 같은 CAD 문서의 별도 데이터로 편집합니다. 기존 전장 배선·코드·CAD 형상이 자동으로 변경되지 않습니다.

- **배치 / 배선**: 빈 보드 또는 분압 예제로 시작합니다. 부품을 추가하고 핀·net·패드·모델을 편집합니다. 부품을 드래그해 배치합니다.
- **수동 배선**: 시작 패드 → 꺾임점 → 같은 net의 끝 패드 순서입니다. F.Cu/B.Cu를 선택하며, 서로 다른 층의 연결은 다층 패드를 통해 확인합니다. 우클릭 또는 Esc로 진행 중 배선을 취소합니다. 선택 배선을 삭제할 수 있습니다.
- **배치 / 구리 연결 검사**: 경계·간격·연결 상태 등의 기하학적 문제를 확인합니다. 원형 패드와 직선 선분을 지원하며 제조 규칙·정격의 최종 승인은 아닙니다.
- **시뮬레이션 / AI**: DC 또는 AC 주파수를 지정하고 **명시 실행 · Simulate**를 눌러 계산합니다. **Codex PCB 설계 자문**은 사용자가 누르는 읽기 전용 자문이며 자동 적용하지 않습니다.
- **BOM / 예산**: 부품 금액·통화·기준일·판매처·HTTPS 출처와 수량을 입력합니다. 미입력 가격은 미확인으로 유지합니다. 저장된 참고 가격·입력 견적이며 실시간 구매 가격이나 환율을 조회한 값이 아닙니다.

DC/AC 해석은 이상적인 선형 저항·커패시터·독립 전압원의 논리 netlist를 계산합니다. 구리 배선 검사와 논리 회로 계산은 별도입니다. 지원되지 않는 실장 소자·떠 있는 net·모순된 이상 전압원은 계산을 차단합니다. AC 진폭은 peak phasor 기준입니다. MCU/ADC/펌웨어 실행, 반도체 스위칭, 과도 응답, 노이즈, 발열, 전선·PCB 구리 정격이나 실물 기능을 검증하지 않습니다.

**CAD에 PCB 저장**을 눌러 초안을 문서와 작업 기록에 적용합니다. **PCB + 전장에 명시 적용**은 배치·구리 연결 문제를 해결한 PCB를 사용자가 명시적으로 기존 전장 그래프에 추가하는 기능입니다. 기존 전장 데이터·프로그램·펌웨어를 보존하며, 알 수 없는 IC를 작동하는 부하로 추정하지 않습니다. 같은 PCB를 중복 적용하면 충돌하는 등록 ID를 먼저 확인해야 합니다.

PCB 초안이 남아 있는데 CAD 문서가 변경되면 오래된 초안을 자동 덮어쓰지 않습니다. **PCB 내보내기**로 초안을 보존하거나 **문서에서 다시 불러오기**를 사용하세요. 내보내기는 PCB 데이터(.pcbp), BOM CSV, SPICE 참조 netlist를 지원합니다. Gerber 제작 파일이나 KiCad 가져오기는 현재 범위에 포함되지 않습니다.

PCB 캔버스의 단축키는 마지막으로 선택했던 CAD 몸체를 삭제·이동·잘라내기·그룹화하지 않습니다. Ctrl+C/V/X/Z/Y 등의 로컬 편집 키는 해당 PCB 입력 위젯에 전달되고, Esc는 수동 배선 취소에 사용합니다. PCB 자체의 모든 편집에 Undo가 구현됐다는 뜻은 아닙니다. CAD 문서에 명시 저장한 변경은 기존 작업 기록으로 관리합니다.

## G474 펌웨어 가상 실행

**도면 / 해석 → 코드 → G474 전체 펌웨어 실행…** 또는 전장 작업창의 ELF 연결 기능으로 저장된 정확한 보드·배선·ELF를 확인합니다. ELF 연결과 실행은 별도이며 사용자가 실행을 눌러야 Renode 자식 프로세스가 시작됩니다. 앱을 켜거나 창을 열 때 펌웨어를 자동 실행하지 않습니다.

현재 지원 범위는 NUCLEO-G474RE의 지정된 HSI16 프로파일입니다. Renode 1.17.0 실행 파일·주변 파일의 동결된 해시를 확인합니다. 각 실행의 설정·기록은 해당 실행 결과 폴더에 저장합니다. ARM ELF는 가상 장치 안에서 실행하며 실제 보드 플래시·직렬 포트·모터 전원은 사용하지 않습니다. 취소·연결 대상 변경·문서 변경·창 종료 후의 늦은 결과는 적용·내보내기·재생하지 않습니다.

원본 펌웨어와 CAD 가상 구동용 파생 펌웨어를 구분합니다. 가상 왕복·정지·가드·방향별 제한 예제는 선언된 가상 속도 서보와 시뮬레이터 입력으로 검사했습니다. 실제 전동기 R/L/Kt/Ke/J/b, 엔코더 보정, 물리 센서 극성, 실제 RPM·전류·발열·실제 배선의 합선·장비 동작은 미확인입니다. 전체 MCU 주변장치·운영체제·실물 구동을 검증했다는 뜻이 아닙니다. 지원하지 않는 MMIO나 실행 오류는 차단하며, 실제 장비에 그대로 적용하지 마세요.

## 검수 상태

새 기능의 소스·대수·모델·offscreen UI 및 취소·문서 변경 검사를 수행했습니다. 소유자의 실제 ARM 가상 실행과 형상 검사 증거는 공통 EXE 검사와 별도로 보존합니다. 최종 EXE·서명된 내부 근거·새 EXE의 가상 부팅·사용자 Windows 창/GPU·설치·배포의 완료 여부는 최종 인계 기록을 확인하세요. 내부 서명은 빌드 일치 증거이며 실물 안전 인증이나 Windows 코드 서명이 아닙니다.

실제 분리 부품이 많은 설계를 보존할 수 있도록 프로젝트 부품·임베디드 형상·한 그룹의 부품 한도를 각각 512개로 늘렸습니다. 단일 패턴 256개 및 기존 검사 시간·취소 한도는 유지됩니다.

구동 표본 검사에서는 동일한 지역 형상·정확히 동일한 자세의 고정 부품 world 형상과 경계를 재사용합니다. 처음의 전체 원시 간섭 검사는 유지하며 움직이는 부품은 모든 표본에서 다시 검사합니다. 같은 시작 자세의 미리보기에서 전체 간섭 검사를 중복 실행하지 않습니다. 메시 생성에도 취소·시간 확인을 전달하지만 C++ 단일 호출 중 강제 취소는 별도 프로세스 종료가 필요합니다.

256개를 넘는 대형 설계의 구동 검사 기본 한도는 180초이며, 그 이하 설계는 120초입니다. 명시한 시간 한도는 그대로 지키고 취소는 계속 사용할 수 있습니다. 시간 한도 연장은 간섭 검사를 면제하지 않습니다.
