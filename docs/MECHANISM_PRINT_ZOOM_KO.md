# 2.11.0 · 커서 확대, 실제 기어, 출력 배치와 관절 상태

## 커서 위치를 중심으로 확대 / 축소

3D 화면에서 마우스 휠을 돌리면 가리킨 실제 부품 표면을 화면의 같은 위치에 유지합니다. 빈 공간에서는 커서 아래의 카메라 초점 평면을 기준으로 확대합니다. 스케치도 커서 아래 좌표를 유지합니다. 등각·상면·정면·측면과 소프트웨어 렌더링에서 사용할 수 있습니다.

## 실제 기어 만들기

**조립 → 실제 스퍼 기어 구동…** 또는 조립 작업공간의 기어 도구에서 모듈, 입력/출력 잇수, 두께, 백래시, 축 지름과 지름 여유를 입력합니다. 미리보기에서 확인한 후 적용합니다.

- 외접 인벌류트 스퍼 기어 두 개, 각각의 일체형 축, 두 축 구멍이 있는 지지판을 실제 CAD 솔리드로 만듭니다. 개별 부품은 저장·편집·분리·STEP/STL 내보내기가 가능합니다.
- 두 회전 관절과 일반 모션 연결을 만들고 잇수비에 맞춰 반대로 회전합니다. 입력 관절을 선택한 후 **관절 구동**으로 확인합니다. 기어 쌍 중심 거리 = 모듈 × (입력 잇수 + 출력 잇수) / 2입니다.
- 모듈 0.5~10 mm, 18~80T, 압력각 20°(단품 데이터는 25°도 지원). 백래시 기본 0.2 mm는 쌍의 피치원 간격이며 두 치형에 나눠 반영합니다. 축 지름 여유 기본 0.2 mm는 지지판 구멍 − 축입니다. 반경 여유는 그 절반입니다.
- 기어와 축은 한 몸이므로 별도 키 없이 함께 회전합니다. 지지판 위에서 끼우는 초안입니다. 축 이탈 방지 덮개, 구동 모터 연결, 윤활과 하중에 맞는 베어링은 설계자가 추가해야 합니다. 프린터 보정은 이 창의 실제 치수로 확인하며 임의로 중복 적용하지 않습니다.
- AI에도 `spur_gear` 실제 형상과 `motion_link` 도구를 추가했습니다. 물건 이름별 예외 처리 없이 다른 형상·피처·조립 도구와 함께 사용할 수 있습니다. AI가 선택한 계획의 품질까지 보장하지는 않습니다.

치면은 인벌류트 샘플을 보간한 곡선이고 치저는 방사형 완화 형상입니다. 호빙 공구의 생성 치저 곡선, 헬리컬·베벨·내접 기어, 강도·수명 정격은 구현하지 않았습니다. 기어 치수 또는 축 위치를 나중에 개별 편집하면 상대 기어·관절 오프셋·모션 연결비도 맞춰야 합니다. 검사 실패는 적용 전에 수정하세요.

기본 치수 체계 참고: [KHK 스퍼 기어 기술 자료](https://khkgears.net/pdf/spur-tech.pdf). 특정 상용 기어의 인증 복제본은 아닙니다.

## 출력판에 직접 배치 → STL

**3D 프린팅 · STL 미리보기**에서 부품을 눌러 선택하고 드래그해 바닥 위로 이동합니다. 오른쪽 **배치할 부품**, **바닥 중심 X/Y**, **부품 X/Y/Z 회전**으로 숫자를 입력할 수도 있습니다. X/Y는 회전한 부품 바운딩 박스의 중심, 바닥은 항상 Z=0입니다.

- **상면에서 배치**: 출력판 전체를 위에서 봅니다. 빈 공간 드래그는 시점 회전, 휠은 커서 중심 확대입니다.
- **출력할 부품 선택**: 원하는 부품만 체크합니다.
- **프린터 / 자동 배치 설정**: 출력 영역 XYZ, 전체 초기 방향, 자동 배치 간격, STL 메시 오차를 조절합니다. 전체 방향·간격 변경은 수동 배치를 초기화합니다.
- **전체 자동 배치 / 방향 초기화**: 현재 전체 방향으로 다시 자동 배치합니다. 부품별 방향과 위치를 초기화합니다.
- 위치·회전을 바꾸거나 드래그하는 즉시 STL 저장이 비활성화됩니다. 최신 배치의 실제 형상 검사 후 다시 켜집니다. 영역 밖이거나 부품끼리 체적 간섭이 있으면 저장할 수 없습니다.
- **이 미리보기로 STL 저장**은 검사한 동일 형상을 내보냅니다. 설계 원본·조립 구속·부품 색상은 바뀌지 않습니다. 부품별 방향/배치는 이 출력 창에만 유지됩니다.

STL 단위는 mm입니다. 서포트·인필·레이어·G-code는 슬라이서에서 설정합니다. 바닥에 닿는 것이 서포트 없는 출력 가능성을 뜻하지는 않습니다. 일체형 기어 축은 기어 면이 바닥에 오도록 180° 뒤집는 방법을 검토하세요.

## 관절 상태 색상

**J / 관절 표시**를 켜고 표식이나 연결 목록을 누르면 검사 내용을 볼 수 있습니다. 실제 부품 외관 색은 유지하고 관절 표식 색만 바뀝니다.

- **초록 / OK pose**: 현재 자세에서 동심의 완전한 축·구멍 원통 면, 양의 지름 여유, 실제 축 방향 지지 겹침이 있으며 연결 부품의 체적 간섭이 없습니다.
- **노랑 / ?**: 관절 관계는 있지만 물리적 지지 형상을 확인하지 못했습니다. 미지원 관절 종류도 여기에 포함됩니다.
- **빨강 / !**: 연결 부품에 간섭이 있거나 자유 운동과 강체 연결이 충돌합니다.
- **회색 / fixed**: 강체 연결. **주황**: 폐루프 표식.

일반 회전/원통 관절과 그 양쪽에 강체로 연결된 부품의 실제 형상을 검사합니다. 초기 검사 기준은 0.1 mm보다 긴 축 방향 겹침과 0보다 크고 `min(2 mm, 축 지름의 15%)` 이하인 지름 여유입니다. 이는 하중별 적합 공차 인증이 아니라 지나치게 헐겁거나 지지가 없는 연결을 초록으로 표시하지 않기 위한 보수적 형상 조건입니다.

**초록은 현재 자세의 지지 형상 검사이며 전 구동 범위·이탈 방지·조립 경로·강도 인증이 아닙니다.** 관절 구동에서 변경한 경로는 기존처럼 최대 2° / 0.5 mm 간격으로 간섭을 검사하고, 발견하면 적용을 막습니다. 모델이 바뀌면 색을 다시 계산합니다. 판정을 프로젝트에 영구 인증처럼 저장하지 않습니다.
