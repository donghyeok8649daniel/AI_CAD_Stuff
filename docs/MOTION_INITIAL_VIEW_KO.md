# 관절 재생 창의 초기 형상 표시

관절 재생 창은 주 화면의 현재 프로젝트에 이미 준비된 형상 미리보기를 독립적으로 복사해 바로 보여줍니다. 새 형상 계산을 대신 실행하거나 다른 프로젝트의 메시를 가져오지 않습니다. 초기 형상에는 ‘보기 전용 · 구동 검사 전’이 표시됩니다.

초기 표시는 재생 허가가 아닙니다. 선택한 구동 범위의 현재 자세 전체 간섭, 모든 표본 자세와 마지막 미리보기 검사가 완료되어야 재생할 수 있습니다. 검사 취소나 실패 시 현재 모델은 남아 있지만 재생은 잠깁니다. 프로젝트나 기록 단계가 바뀌면 이전 표시와 검사 결과를 버립니다.

원래 미리보기의 엄격한 형상 해시와 원본 설계 전체 해시, 문서 식별·변경 번호·기록 커서를 확인합니다. 검증 시 기본값 0이 0.0으로 표현되는 경우에는 같은 원본에서 검증한 별도 해시를 연결합니다. 정확히 같은 숫자 표현 차이만 허용하며 문자열·참거짓 변환, 실제 치수·구속·구조 변경은 허용하지 않습니다. 일반 형상 캐시의 해시 규칙은 바꾸지 않습니다.

주 화면에 현재 형상의 유효한 미리보기가 없으면 표시할 수 없는 이유를 안내합니다. 부모 창의 VTK actor·렌더 창을 공유하지 않습니다. 원본 위치·구속·기록·파일을 수정하지 않으며 초기 미리보기로 간섭 없음이나 실제 장비 동작을 보증하지 않습니다.

이 변경의 자동 검사는 작은 합성 메시와 inert viewport를 사용하는 실제 Qt 위젯 검사입니다. 실제 프로젝트의 GPU 화면과 전체 회전 시연은 별도의 네이티브 검증이 필요합니다. 분할 검사도 전체 소요 시간을 보장하지 않으며, 실행 중인 단일 네이티브 계산의 한도와 취소 제약은 유지됩니다.
