# Prompt CAD Studio v3.4.0 — 기능과 검증 범위

이 문서는 기능과 적용 범위를 설명합니다. 코드·패키지 무결성, Qt offscreen 실행, 실제 Windows UI 확인 및 실물 제작 승인은 서로 다른 근거입니다. 실제로 확인된 항목과 미확인 항목은 별도의 릴리스 검증 기록을 따릅니다.

PCB 작업창에서 부품 배치, 핀 연결, 층별 배선과 검토를 단계별로 진행할 수 있도록 개선했습니다. 저장된 실제 패드·핀 규격을 입력하거나 제품 참고정보에 연결하며, 카탈로그의 논리 핀을 실제 풋프린트 치수로 자동 추정하지 않습니다. 2·4·6·8층 구리 모델과 제한된 배선 비교를 제공하며, 탐색 결과를 보장된 최소 층수나 제조 적층 승인으로 취급하지 않습니다.

배치 최적화는 부품 고정과 기존 배선을 보존한 사본에서 미리보기로 제안합니다. 대응 핀 정렬은 핀 쌍·전기 호환성·면·공차를 직접 지정하며, 확인되지 않은 조건은 미확인으로 남깁니다. 외부 PCB를 사용할 때에는 정확한 참조와 직접 확인한 기준면·자세·검토 기록을 연결해야 합니다. 높이·뒤집기와 미확인 등록은 3D 수치 미리보기로 표시하고 2D PCB에 강제로 적용하지 않습니다. 외부 보드 전체의 이동이나 실제 커넥터 결합·3D 간섭 검증을 수행하는 기능은 아닙니다.

미리보기 적용은 로컬 PCB 초안만 변경하고 되돌리기를 제공합니다. 전체 CAD에는 별도 저장 동작으로 적용합니다. 제품 전압·전류와 입력 견적은 저장된 규격·출처·조건을 구분하며, 모르는 정격과 실제 가격을 만들어 채우지 않습니다. 계산된 회로 또는 배선이 실물에서 안전하게 작동한다는 승인은 별도입니다.

저장한 CAD를 다시 열어 설계를 요청하면 현재 이력 단계의 제한된 요약을 참고합니다. 기존 전체 작업 기록과 분기를 보존하고 검증된 새 작업을 이어 붙이며, 작업 중 문서나 이력이 바뀐 초안은 적용 전에 다시 확인합니다. 사용자 파일 참고자료 한도와 자동 이력 요약은 분리됩니다.

설치·업데이트는 사용자 Programs/PromptCADStudio의 한 경로를 사용하도록 개선했습니다. 새 standalone 업데이트 EXE를 다시 빌드하며, 구버전 업데이트 EXE를 재포장하지 않습니다. 파일 교체는 소유 목록·해시와 실행 중 CAD 확인을 거치고, 사용자 프로젝트·설정·로그인 자료는 보존합니다. Windows가 보호하는 기본 앱 선택을 임의로 덮어쓰지는 않습니다.

이전의 4층 PCB 저장과 명시적으로 지정한 유연 전선의 충돌 제외 기능을 유지합니다. 회로도와 CAD 부품 연결, 실제 제품 규격, 제조 공차·강도·열·전류 정격 및 실측 상태는 각 입력과 검증 범위에 따라 달라집니다.

검증 범위: 기존에 완료한 소스 검사를 반복 집계하지 않습니다. 최종 소스 동결·새 EXE와 새 updater의 코드 일치, 실제 Windows UI, 공개 다운로드, 정식 설치와 .pcad 더블클릭 결과는 각각 별도로 기록합니다. 이 기능 설명만으로 검증·설치 완료를 주장하지 않습니다.
