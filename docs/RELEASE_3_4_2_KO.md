# Prompt CAD Studio 3.4.2 성능 개선 후보

공개·정식 설치 여부는 배포 검증 기록을 따릅니다. 이 문서만으로 업데이트 설치나 실제 Windows 화면 검증이 완료됐다는 뜻은 아닙니다.

- 자동저장의 전체 이력 검증·직렬화·디스크 쓰기를 별도 작업자로 옮겼습니다. 최신 요청 하나만 대기시키며, 이전 문서의 늦은 저장은 복구 파일을 덮어쓰지 않습니다. 종료 시 마지막 저장을 기다리고 실패하면 종료를 보류합니다.
- 수동 저장도 전체 이력과 원자적 저장을 유지하면서 화면 이벤트를 처리합니다. 저장 성공 여부를 확인한 뒤 열기·종료를 이어갑니다.
- 작은 편집에서는 실제 생성 입력과 자세가 같은 부품의 형상·미리보기·렌더링 객체를 재사용합니다. 이전 화면의 큰 배열을 다시 복사하는 메모리 급증을 줄였습니다. 형상 캐시의 약한 참조는 자체적으로 원본 형상을 계속 소유하지 않으며, 화면 캐시는 크기를 제한합니다.
- 간섭 검사는 현재 형상·자세와 네이티브 형상 식별이 일치할 때만 이미 계산한 정확한 두 부품의 교집합 체적을 재사용합니다. 변경된 형상·배치와 명시적 전선 제외 범위는 다시 확인합니다. 숨김·그룹으로 간섭을 숨기지 않습니다.
- 큰 메시의 부품·면 선택과 커서 기준 확대에는 삼각형 공간 인덱스를 재사용합니다. 실제 화면 반응 속도는 별도 Windows 화면 검증이 필요합니다.
- 보기 메뉴에 자동·정밀·빠름 표시 품질을 추가했습니다. 자동 모드는 100개를 넘는 조립품에서 스윕 곡면의 화면 삼각형 수를 줄입니다. 원본 BREP와 치수, 면 참조, 간섭 계산은 유지합니다.
- STL은 표시 메시를 복사하지 않고 원본 해석 형상에서 출력 정밀도로 생성합니다. 일반 STL·부품별 ZIP·프린팅 모드·여러 플레이트 내보내기에 공통 적용합니다.
- 파일 열기에서 전체 이력·형상 생성·메시·간섭 검사 단계를 표시합니다. 데이터 전용 실행 검사는 Windows 창이나 장비를 구동하지 않습니다.

기존 PCB·전장·펌웨어·AI·작업 이력 기능과 단일 설치 경로 및 `.pcad` 연결 갱신은 유지합니다. 실행 중인 CAD 창은 종료하지 않으며, 모든 CAD 창이 닫힌 것을 확인한 경우에만 정식 설치를 교체합니다.

최초 대형 파일 열기의 전체 검증은 여전히 CPU 작업입니다. 표시 품질은 출력 공차나 제조 적합성 인증이 아니며, 프로그램의 모든 네이티브 오류가 없어졌다고 보장하지 않습니다.
