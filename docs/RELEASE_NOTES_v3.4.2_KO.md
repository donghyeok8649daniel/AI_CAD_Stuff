# Prompt CAD Studio v3.4.2

대형 조립품의 반복 편집·저장·선택 비용을 줄였습니다. 부품이나 작업기록을 삭제하지 않고 기존 PCB·전장·펌웨어·AI·조립·프린팅 기능을 유지합니다.

- 자동저장의 전체 이력 검증·직렬화·디스크 쓰기를 별도 작업자로 옮겼습니다. 최신 요청 하나만 대기시키며, 문서 전환 뒤 이전 저장이 복구 파일을 덮어쓰지 않습니다. 종료할 때 마지막 저장을 확인합니다.
- 수동 저장 중에도 화면 이벤트를 처리하며, 실패하면 기존 문서·이력·수정 상태를 유지합니다.
- 작은 편집에서는 실제 생성 입력·자세가 같은 부품의 형상·화면 배열·렌더링 객체를 재사용합니다. 캐시는 용량을 제한하고 실제 압축 자산 바이트까지 식별에 포함합니다. 변경된 형상·배치·간섭은 다시 검사합니다.
- 큰 메시의 선택·커서 확대에 삼각형 공간 인덱스를 사용합니다. 자동·정밀·빠름 표시 품질을 선택할 수 있으며, 원본 형상·치수·면 참조·정확한 간섭 검사는 유지합니다.
- 표시 품질과 별도로 원본 해석 형상에서 STL을 생성합니다. 일반 STL·부품별 ZIP·프린팅 모드·여러 플레이트에 공통 적용합니다.
- 파일 열기의 이력·형상·메시·간섭 단계를 표시합니다. 업데이트는 정식 설치 경로 하나를 교체하고 앱 소유가 확인된 .pcad 연결도 같은 실행 파일로 갱신합니다. 사용자 파일·설정·로그인 자료와 보호된 Windows 사용자 선택을 보존합니다.

새 Windows EXE로 실제 391부품·359기록·47.3MB 파일 사본의 전체 저장·재열기 일치를 확인했습니다. 최초 형상·메시·간섭 계산 233.38초, 한 독립 부품 수정 1.71초, 최대 작업 집합 약 1.35GiB를 관찰했습니다. 편집에서 390부품의 화면 배열을 재사용하고 새 간섭 1건도 검출했습니다. 원본 사본은 수정하지 않았으며 정상 종료했습니다. 이는 해당 파일의 백엔드 측정이며 모든 조작이나 Windows 화면 반응 시간을 뜻하지 않습니다.

기존 수정 범위 132개 회귀 검사와 새 패키지 초기화 경계 8개 검사가 통과했습니다. 307개 앱 모듈의 포함 코드, 2,880개 재사용 런타임 파일, 새 업데이터를 검증했습니다. 새 앱의 내장 Windows 자체 검사는 작은 로봇 장면에서 하드웨어 렌더링 135프레임·저장·재열기·정상 종료를 통과했습니다. 공식 SDK의 읽기 전용 창 목록에서 새 빌드 제목을 확인하고, 별도로 앱이 내보낸 실제 VTK 프레임을 확인했습니다. 마우스·클릭·키 입력 주입은 사용하지 않았습니다.

최초 대형 파일의 전체 계산은 여전히 약 4분 걸립니다. 391부품의 실제 Windows 뷰포트 조작 속도·전체 창 레이아웃·더블클릭은 이번 명령줄 검사로 검증하지 않았습니다. 모든 네이티브 오류의 제거, 제작·강도·전류·열·펌웨어·장비·안전을 보장하지 않습니다. 설치 파일의 포장 당시 GUI 대기 표시는 별도 최종 릴리스 검증 기록과 구분합니다.
