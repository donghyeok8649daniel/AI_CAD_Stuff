# AI 초안 생성과 간섭 수정 · 2.11.1

AI가 계산 가능한 형상을 만들었지만 간섭이 남은 경우, 이제 그 초안을 버리지 않습니다. 원래 설계와 분리된 미리보기로 보존하고 수정 작업을 이어갑니다. Codex, OpenAI API, Ollama에 적용됩니다.

1. **초안 생성**을 누릅니다. 생성 후 실제 솔리드와 조립 간섭을 검사합니다.
2. 간섭이 있으면 AI에 부품 이름뿐 아니라 실제 겹침 체적, 전역 좌표 범위, 각 부품 로컬 좌표의 겹침 범위를 돌려줍니다. 처음 도구 선택에서 빠졌던 이동·구멍·포켓·피처 편집도 수정 단계에 제공합니다.
3. 자동 수정으로 해결되지 않아도 **미리보기 / 수정**에서 형상을 확인할 수 있습니다. 간섭 목록에서 부품 쌍을 고르면 두 부품이 강조됩니다. 변경 전/후를 비교할 수 있습니다.
4. 필요하면 추가 지시를 쓰고 **AI로 간섭 수정 계속**을 누릅니다. 처음 요청과 원래 설계를 유지하고, 보존된 계획에서 이어갑니다. 현재 설계가 변경됐으면 새 설계를 기준으로 다시 생성해야 합니다.
5. 검증을 통과하면 **확인 · 설계에 적용**이 활성화됩니다. 적용할 때도 실제 형상을 다시 검사합니다.

Codex는 한 묶음에서 최대 6회 계획을 생성합니다. 계산 가능한 후보를 전혀 얻지 못한 잘못된 계획은 3회까지 수정합니다. OpenAI API와 Ollama는 묶음당 최대 3회이며, 계속 수정은 사용자가 누를 때 진행합니다. OpenAI API는 계속 수정에도 요금이 발생할 수 있습니다. 대기 제한은 별도 설정이고 무제한 대기 중에도 취소할 수 있습니다.

이미 보존할 형상이 있으면 이후 수정의 연결 오류·시간 초과 때문에 그 초안을 잃지 않습니다. 사용자가 추가 수정을 취소해도 기존 미리보기를 다시 열 수 있습니다. 원본 설계와 저장 파일에는 적용 전 변경이 없습니다. 형상 자체가 만들어지지 않은 잘못된 JSON, 인증/네트워크 실패까지 성공한 설계로 표시하지는 않습니다.

## 함께 수정한 형상 안내

- 기본 평판 시편은 두께 방향도 중심 기준입니다. 두께 3 mm이면 로컬 Z 범위는 −1.5…+1.5 mm입니다. 일반 평판·원통의 바닥 Z=0 규칙과 구분합니다.
- 현재 부품의 실제 로컬 경계를 AI에 제공합니다. 원점 추측으로 클램프가 시편 내부에 겹치는 문제를 줄입니다.
- 회전은 고정 X → Y → Z 순서입니다. 기울인 기어에 전역 Z 회전을 주는 것과 그 기어의 축 주위로 회전시키는 것은 다릅니다. 축 방향을 유지하는 회전 방법을 안내합니다.
- 조립 설계는 최대 64 작업, 부품 선택·필수 연결은 각 32개까지 계획할 수 있습니다. 단일 부품은 기존의 작은 작업 계획을 유지합니다.

간섭이 없다는 결과는 **검사한 자세의 솔리드 겹침 검사**입니다. 피로시험기의 실제 하중, 시편 변형, 접촉 추종, 토크 전달 체결, 전장 정격, 안전장치와 수명 인증까지 보증하지 않습니다. AI용 조립 도구는 트리 구조의 관절과 운동비 연결을 지원하며, 수동 CAD의 폐루프 도구는 아직 AI 계획에 노출되지 않았습니다.
