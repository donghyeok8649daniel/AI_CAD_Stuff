# Prompt CAD Studio 3.3.0

4층 PCB와 명시적 유연 전선 간섭 분류를 하나의 정식 Windows 앱에 통합했습니다. 기존 `.pcad` 파일은 고정 설치 경로의 `PromptCADStudio.exe`에서 엽니다. 전용 시험판이나 별도 바로가기가 필요하지 않습니다.

## PCB

- 2층 및 4층 구리층: F.Cu / In1.Cu / In2.Cu / B.Cu. 층 표시와 배선 층 선택을 지원합니다.
- 패드의 실제 크기·회전·원형 드릴, 원형/직사각/타원/둥근 직사각 패드, 비아와 구리 영역의 외곽·구멍·저장된 채움·net 이름을 보존합니다.
- 최대 배선 1,024개를 지원하며, 기존 2층 PCB와 PCB가 없는 프로젝트의 전체 작업 이력을 보존합니다.
- PCB 작업창의 변경은 검토 후 명시적으로 설계에 적용합니다. 기존 저장 형상을 낮은 사양의 단순 도형으로 바꾸지 않습니다.

이 기능은 범용 KiCad 가져오기·Gerber 제조 출력·구리 영역 자동 재채움·제조용 DRC·적층/허용전류/열 검증을 의미하지 않습니다. 저장된 영역과 실제 제작 적합성을 구분합니다.

## 전선 간섭 분류

선택 부품의 **제품 스펙 / 구매 링크** 창에서 유연 전선 몸체의 기계 간섭 제외를 직접 켜거나 끌 수 있습니다. 분류는 부품의 제품 사양에 `간섭 분류: 유연 전선`으로 저장되어 프로젝트·작업 이력과 함께 유지됩니다.

명시적으로 분류한 전선 몸체만 체적 간섭 검사에서 제외합니다. 이름·색상·전장 역할·그룹·숨김·스윕 형상만으로 자동 제외하지 않습니다. PCB·볼트·단자·커넥터 같은 강체는 제외하지 마세요. 잘못 분류하면 그 부품의 기계 간섭도 빠집니다.

제외가 있으면 화면에 **고정부품 간섭 N건 · 전선 M개 제외**를 표시합니다. 분류가 바뀌면 기존 간섭 결과를 재사용하지 않으며, 구동 표본 검사에도 같은 정책을 적용합니다. 이 제외는 케이블 굽힘·마찰·움직임 여유·단선·합선·허용전류·과열의 안전 판정이 아닙니다.

## 설치와 기존 파일

기존 설치 위치를 업데이트하며, 기존 공식 3.2.1 프로필이 있으면 설정·로그인·복구 자료를 그 위치에서 계속 사용합니다. 새 설치는 사용자 LocalAppData 프로필을 사용합니다. 테스트용 명시적 프로필 지정은 우선 적용됩니다. 업데이트는 CAD 창이 모두 닫힌 상태에서 수행하며 사용자 프로젝트와 전체 이력을 덮어쓰지 않습니다.

릴리스 검증은 기존 드론·피로시험기 파일의 데이터/이력 호환성, 작은 실제 형상의 간섭 정책, 공개 EXE 내부 모듈 일치, 실제 네이티브 열기 및 고정 설치 앱의 파일 연결을 각각 구분합니다. 현재 자세의 형상 검사는 전 구동 범위·강도·실제 전장 동작·비행 또는 제작 승인을 대신하지 않습니다.
