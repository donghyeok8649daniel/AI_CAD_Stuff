# 전장 회로와 관절 구동 검사

## 역할별 부품 보기와 선택

3D 화면의 **전체**, **전장만**, **구조만**, **동력만** 버튼은 각각 모든 부품, 전장/센서, 구조/보호, 구동/하중 전달 역할의 부품을 보여 줍니다. 역할별 버튼을 누르면 해당 역할의 부품만 표시하고 선택합니다. 그룹에 다른 역할의 부품이 섞여 있어도 그 부품까지 함께 선택하지 않습니다. 역할은 부품 선택 후 **부품 역할 / 기본색…**에서 지정하거나 변경합니다.

역할별 보기에서는 알아보기 쉬운 역할 색을 임시로 표시합니다. **전체**로 돌아오면 저장된 부품 색과 이전에 직접 숨긴 상태가 복원됩니다. 숨긴 부품까지 모두 나타내려면 기존 **모두 보기**를 사용하세요. 예전 프로젝트에서 역할이 없는 부품은 정확한 기본 역할 색 또는 전장 회로에 연결된 CAD 부품 ID가 확인될 때만 분류합니다. 이름만 보고 역할을 추측하지 않습니다. 노란색 표시나 전장 역할 지정만으로 회로 항목이 생성되지는 않습니다.

## 전장 회로 작성

**도면 / 해석 → 전장 회로 · 배선 / 전압강하…**를 엽니다. 빈 설계에서는 오른쪽 **전장 회로 / 배선 설계**로 시작할 수도 있습니다. 저장한 회로는 설계 브라우저에 표시되며 더블클릭해서 다시 편집합니다.

1. **부품 / 전선 추가…**에서 배터리, 전선, 스위치, 저항, 일반 부하, 모터 또는 MCU / 보드 전원 부하를 고릅니다.
2. 배터리는 **배터리 + / 공급 노드**와 **배터리 - / 리턴 노드**, 다른 부품은 첫째·둘째 단자에 노드 이름을 입력합니다. 같은 이름의 단자끼리 전기적으로 연결됩니다. `GND`는 전압 기준입니다. 예를 들어 배터리 `VPLUS`–`GND`, 스위치 `VPLUS`–`SWITCHED`, 전선 `SWITCHED`–`MOTORPLUS`, 모터 `MOTORPLUS`–`GND`로 입력할 수 있습니다. 노드 이름에는 영문, 숫자, `_`, `-`를 사용합니다.
3. 제품 자료에서 배터리 전압·내부저항·허용 전류, 부하 정격 전압·전류, 전선 길이·도체 단면적 등을 입력합니다. 배터리의 **전원 인가 · 배터리 출력 켜기**를 확인하고, 전원을 차단해 보려면 체크를 해제합니다. 체크 해제는 배터리 정격을 0 V로 바꾸는 것이 아니라 출력 경로를 끊습니다. 모터 기동 전류는 아는 경우에만 입력합니다. **CAD 부품**을 선택하면 회로 항목과 3D 부품을 연결해 찾을 수 있습니다. 연결만으로 3D 전선 형상이나 실제 구동 연결이 생성되지는 않습니다.
4. **회로 다시 계산**에서 공급 노드에서 부하까지와 리턴 노드로 돌아오는 경로, 노드 전압, 각 항목의 전류·전압차·전력과 경고를 확인합니다. **설계에 저장**으로 회로를 프로젝트에 기록합니다. 회로 계산이 불가능한 배선 초안도 확인 후 저장할 수 있으며, 그 결과는 검증된 회로가 아닙니다.

전장 편집창에서 **회로도 보기…**를 누르면 **전장 회로도 · 배선 연결 보기**가 별도 창으로 열립니다. 왼쪽은 실제 입력한 부품·단자·노드의 연결, 오른쪽은 선택한 MCU의 핀 모식도를 표시합니다. **MCU 선택 / 핀 연결…** 또는 오른쪽 물리 핀을 클릭해 보드와 연결할 부품 단자를 고르세요. 변경은 핀 창의 **핀 연결 저장**, 회로도의 **회로도 변경 저장**, 전장 편집창의 **설계에 저장** 순서로 반영합니다. 취소하면 해당 창의 변경은 반영하지 않습니다. **전체 맞춤**, **확대**, **축소**로 살펴보세요. 선이 교차해도 접점 표시가 없다면 전기적으로 이어진 것이 아닙니다. [MCU 핀 연결 사용법과 지원 범위](MCU_PIN_CONNECTIONS_KO.md)를 참고하세요.

### 전선 단선과 MCU 연결 확인

- 전선 항목의 **전선 연결됨** 체크를 해제하면 그 전선을 단선된 상태로 기록합니다. 전선 모양이나 노드 이름을 그대로 두어도 DC 전류 경로에서는 제외됩니다. 다시 체크하면 이어진 전선으로 검사합니다. 저장한 기존 회로의 전선은 이전과 같이 연결됨이 기본입니다.
- 배터리 항목의 **전원 인가 · 배터리 출력 켜기**를 해제하면 공급 경로에서 제외합니다. 전압 입력값과 +/− 노드는 보존되므로 다시 켜서 비교할 수 있습니다. 회로 목록에서 배터리를 선택해 전원을 켜거나 끄는 버튼도 사용할 수 있습니다. 공급 경로가 끊기면 해당 전원에서 공급되는 전류와 MCU 전원 연결 검사를 다시 확인하세요.
- MCU 항목의 **첫 단자**는 VCC, **둘째 단자**는 GND/리턴입니다. 전원과 리턴이 실제 연결 경로로 이어지는지, 공급 전압이 입력한 정격과 비교해 적절한지 각각 확인합니다. `GND`는 회로 전위의 기준이므로 MCU의 리턴 단자도 돌아가는 배선 경로를 따라 연결해야 합니다.
- **MCU 선택 / 핀 연결…**에서 정확한 보드와 물리 핀을 고르고 부품 단자 또는 다른 MCU 핀에 연결합니다. 지원하지 않는 기존 사용자 핀은 공식 핀과 구분해 보존합니다. 기존 **신호 핀 = 노드** 텍스트 입력도 유지합니다. 해당 노드에서 다른 회로 단자까지 닫힌 스위치·연결된 전선을 통한 도통 경로가 있는지만 검사합니다. 작성하지 않은 핀은 검사하지 않습니다. 알려진 보드의 논리 전압 차이와 GPIO의 전원·모터 직결 위험은 경고하지만, 실제 핀 허용 전류나 전압 변환기의 동작을 계산하는 것은 아닙니다. MCU 신호 핀의 입력/출력 방향, 풀업·풀다운, 통신 프로토콜과 코드는 이 검사 범위가 아닙니다.
- 보고서의 **PASS**는 입력한 배선 모델과 수치에 관한 검사 통과이고, **WARN/FAIL**은 공급·리턴 단선, 지정 신호 핀 미연결, 전압 조건 등을 확인하라는 뜻입니다. 실제 기판의 납땜 불량이나 케이블 단선을 자동으로 감지하는 기능은 아닙니다. 회로 모델을 실제 제작 배선대로 입력해야 결과가 의미 있습니다.

**예시 회로 · 가상값**은 UI 연습용입니다. 기존 회로가 있으면 교체 여부를 묻습니다. 예시 수치를 실제 부품 사양으로 사용하지 마세요.

### 제품 자료 검색

부품 편집창의 **모델 찾기…**는 앱에 내장된 오프라인 카탈로그에서 제조사·모델·제품군을 검색합니다. 결과의 **공식 자료 열기**로 원문 사양을 검토할 수 있습니다. 확정된 특정 모델에 대해서만 이름·자료 링크와 출처에서 명확히 확인된 값을 채웁니다. 제품군처럼 변형이 여러 개인 항목이나 현재 DC 솔버가 지원하지 않는 다이오드·모터 드라이버·센서는 **자료만 열람**하며 회로 부품을 자동 생성하지 않습니다. 카탈로그는 실시간 웹 스크래핑이 아니므로 최신 개정·주문 코드·시험 조건은 반드시 원문으로 확인하세요.

내장 자료는 Raspberry Pi 3 B+/4/5/Zero/Pico, Arduino UNO·Nano·Mega, STM32 Nucleo·Discovery 및 칩 제품군, ESP32, 엔코더·모터·드라이버·전선·저항·콘덴서·MOSFET·다이오드·커넥터·퓨즈·전원장치의 대표 모델과 공식 제품군 선택기를 포함합니다. 모든 제조사의 모든 주문 코드가 등록된 목록은 아닙니다. 사용 중인 부품의 정확한 품번이 없으면 공식 선택기에서 찾은 뒤 **부품 / 전선 추가…**에 해당 사양을 직접 입력하세요. 'STM32 B…'처럼 부분 이름만 알 때는 검색 결과의 보드 후보를 비교하되 실제 보드라고 단정하지 마세요.

Raspberry Pi 3 Model B+와 4 Model B는 MCU가 아니라 컴퓨터 보드지만, 여기서는 전원 부하의 연결 검토에 사용할 수 있습니다. 문서에 확인된 **5 V 전원**만 초깃값으로 채우고 **보드 소비전류는 직접 입력해야 합니다**. 권장 전원 어댑터의 2.5 A 또는 3 A를 보드의 실제 소비전류로 간주하지 않습니다. GPIO 신호 핀은 수동 도통만 검사합니다.

계산은 지정한 DC 부품과 저항을 사용한 **정상 상태 근사**입니다. 전선 저항은 저항률 × 길이 ÷ 단면적으로 계산합니다. 초기 저항률은 실온 구리의 근삿값이며 재질·온도·접속 상태에 맞게 바꿔야 합니다. 모터의 정격 전압·전류는 등가 저항을 만들고, 입력한 기동 전류가 있으면 별도 기동 시나리오를 계산합니다. 실제 기동 파형이나 부하 변화는 계산하지 않습니다. 허용 전류 초과, MCU 전원 역극성, 부하 정격 전압 대비 ±10% 이상 차이, 전원이 없거나 기준 전위에서 분리된 노드를 점검합니다. 경고 기준은 부품 데이터시트의 허용 범위를 대신하지 않습니다.

현재 회로 검사는 DC 배선의 초기 검토용입니다. 기판 배선 설계, 배터리 방전·보호회로, 모터 토크·속도·제어기, 펌웨어 실행, 과도 응답과 SPICE 수준의 해석은 포함하지 않습니다. 전장 회로와 CAD 관절 운동도 자동으로 결합되지 않습니다.

## 관절 구동 범위 확인

**조립 → 관절 구동**에서 관절을 고르고 각도 또는 이동량을 조절합니다. 현재 자세에서 요청 자세까지 최대 **2° 또는 0.5 mm 간격**으로 부품 형상의 체적 간섭을 검사합니다. 발견한 간섭은 표시하고 해당 자세의 적용을 막습니다. **마지막 확인 자세로 이동**은 표본에서 간섭이 없었던 위치로 돌아갈 때 사용합니다.

**관절 구동 가능 범위 · 실제 형상 표본 검사**에서 구동 가능한 축을 선택하고 **선택 관절 양쪽 한계 검사**를 누르면 현재 자세에서 음·양쪽 설정 한계까지 각각 검사합니다. 첫 간섭 표본과 그 직전의 확인된 위치를 보여 줍니다. 이 검사는 읽기 전용이며 관절 한계를 자동으로 고쳐 쓰지 않습니다. 실제 사용 한계는 관절 설정에서 검토해 지정하세요. 모션 연결로 구동되는 축과 폐루프의 수동 축은 직접 검사 대상으로 선택할 수 없습니다.

**조립 → 실제 스퍼 기어 구동…**에서 만든 기어쌍의 입력 관절은 출력 기어의 연동 각도 한계가 허용하는 범위 안에서 최대 ±360°까지 설정됩니다. 잇수비에 따른 출력 회전이 따라옵니다. 기어 형상과 운동 연결을 만든 것이며 모터의 전류·토크·가속도와 연동한 동역학 계산은 아닙니다.

구동 검사는 표본 위치에서 실제 CAD 솔리드의 겹침을 확인합니다. 표본 사이의 매우 얇은 장애물, 탄성 변형, 제작 공차, 베어링·윤활·하중을 포함한 실제 구동 안전성은 별도 검토해야 합니다. 간섭이 없다는 결과만으로 제작이나 시험 운전 가능성을 인증하지 않습니다.
