직접 설계가 기본입니다

시작 형상 선택 → 치수 편집 → 치수 적용 → STEP/STL 내보내기. 부품 트리와 3D 형상을 클릭해 선택합니다. 부품 추가와 조립 구속으로 기준점과 관절을 연결합니다. 면 스케치를 누르고 3D 모델의 평면을 클릭하면 그 면에서 스케치·돌출·파내기를 시작합니다.

OpenAI 연결

시작 메뉴에서 “계정의 환경 변수 편집”을 열고 사용자 변수 OPENAI_API_KEY에 본인의 API 키를 저장하세요. 선택적으로 OPENAI_MODEL에 Structured Outputs를 지원하는 모델 이름을 지정할 수 있습니다. 기본값은 gpt-4.1입니다.

앱 서버를 종료한 뒤 바로가기로 다시 실행하세요. 키는 브라우저·프로젝트·GitHub에 저장되지 않습니다. 이 화면이나 채팅에 붙여넣지 마세요.

ChatGPT Plus/Pro 구독과 API는 별도입니다. AI 요청 시 프롬프트와 현재 설계가 OpenAI API로 전송되며 API 사용 요금이 발생할 수 있습니다. 치수·형상 오류 교정을 위해 요청당 최대 2회 호출합니다.

이번 버전의 범위

매개변수 부품, 면 스케치, 돌출·파내기, 점 고정·수평·수직·거리·각도 구속, 강체·회전·슬라이더·원통 조립 구속을 지원합니다. 구멍은 좌표와 직경으로 정의되며 자유도는 외곽점에 대해 표시됩니다. 조립은 트리 구조이며 폐루프·동역학·자유곡면·구조 해석은 포함하지 않습니다. 시편 전이부는 3차 베지어 곡선이며 특정 시험 규격을 자동 인증하지 않습니다.

STEP은 mm 단위 솔리드와 부품 이름·색상을 보존합니다. STL은 삼각형 메시이며 단위 정보가 없으므로 받는 프로그램에서 mm로 지정하세요. 조립 STL은 부품별 셸을 합쳐 저장하며 접합·융합하지 않습니다.

Windows 앱

Windows 앱 다운로드 ↗ · ZIP을 풀고 PromptCADStudio.exe를 실행하세요. Python 설치 없이 독립 창에서 사용할 수 있습니다.

저장과 단축키

저장은 앱의 로컬 프로젝트 보관함에 저장합니다. “설계 파일”은 다른 컴퓨터로 옮길 수 있는 JSON 파일입니다. 같은 브라우저의 마지막 적용 설계는 자동 복원됩니다. 작업 이력은 현재 세션에서 최근 30개를 보관합니다.

Ctrl S 저장 · Ctrl Z 되돌리기 · Ctrl Y 다시 실행 · F 화면 맞추기

Autodesk 형식으로 내보내기

Fusion → .f3d
변환 패키지의 STEP을 Fusion에서 열고, 함께 제공한 PromptCADImport 스크립트로 Fusion 아카이브를 저장합니다.

Inventor → .ipt
Inventor가 설치된 PC에서 ConvertToIpt.ps1을 실행하면 부품별 IPT를 저장합니다.

Autodesk 프로그램이 네이티브 파일을 생성합니다. 솔리드 형상이 전달되며 원본 치수·구속·피처 이력은 함께 내보내는 CAD JSON에 보관됩니다. 변환 도구는 Autodesk 내 실변환 미검증 상태입니다.
